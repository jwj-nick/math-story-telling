# se-people-pick — 인물 선정 스킬

본 스킬은 영상 제작 시스템의 첫 단계. 출력은 다음 단계 [서사] (`se-people-narrate`) 의 입력.

상위 frame: [INTEGRATED_PLAN](../../../11_video_gen_process/00_charter/INTEGRATED_PLAN.md) §5.0 skill chain / §5.2 단계 [선정] / §8 결정 1·2·3·4.

원칙:
- 본 스킬은 외부 자료를 **참조** 한다. 외부를 변경 X.
- 호출자가 입력 일부만 줘도 됨 — 동작 1·2 단계에서 보강.
- 동작 중 Q&A 2회 (입력 보강 / 후보 검토). 답변이 다음 동작을 바꿀 수 있다.

---

## 입력 (9개)

호출자가 제공. 부족 시 동작 2 에서 Q&A.

### 필수 3
- **교과서 chapter 목록** — 단원 N개 (예: math1 13단원). 참조: `../../../30_content/units/NN/meta.json`
- **정체성 결정** (시청자 + 약속 3겹) — INTEGRATED_PLAN §8 결정 1·2 참조 (스킬이 자체 확인)
- **시즌·시대 frame** — 시대를 묶는 단위 (예: 시즌 1 = ancient)

### 보조 4
- **학년·과정** — 예: 중1
- **기존 인물 풀** — 외부 `../../../30_content/people/*.md` 참조 (중복 회피 / 비교)
- **후보 수** — 1순위 1인 / top 3 / top 5
- **발굴 우선순위 frame** — 잘 알려진 vs 새 발굴 / 동서양 / 시대 분포

### 메타 2
- **학습자 (딸) 의 기존 반응** — `../../../.private/feedback/`
- **외부 리서치 허용 범위** — 웹 / Wikipedia / 학술

---

## 출력

`<범위>_selection.md` 형식. 다음 항목:

1. **매핑 표** — 단원 N ↔ 인물 1 (또는 N)
2. **인물별 선정 이유** — 정체성 약속 3겹과의 관계 (시대 감각 / 정서 인상 / 발견의 필연성)
3. **후보 비교** — 선정되지 않은 후보의 탈락 이유
4. **다음 단계 [서사] 입력 검증** — 사실 자료원 충분 여부 (인물별)

기본 보관 위치: `../../../11_video_gen_process/40_experiments/exp-NNN-selection-<범위>/output.md` (호출 시 override 가능)

---

## 동작 (7단계)

### 1. 입력 align
- 수신 입력 9개 중 있는 것·빠진 것 확인
- 정체성 결정 (입력 2) 은 항상 INTEGRATED_PLAN §8 의 최신 상태로 자체 확인
- 부족 입력 식별

### 2. Nick QnA  ← Q&A 1
- 빠진 입력 채우기 위한 질문
- 맥락 보충 — 예: "이 단원에서 학습자가 특히 어려워한 부분 있나"
- 답변이 다음 동작을 바꿀 수 있다

### 3. 리서치 판단
- 후보군 출처 결정
  - 기존 19인 풀 우선 검토 (중복 회피 또는 의도적 활용)
  - 신규 발굴 시 자료원 (Wikipedia / 수학사 자료 / 웹 검색)
- 리서치 깊이 결정 (얕은 / 중간 / 깊은 — § 리서치 패턴 참조)
- 리서치 시간 budget 추정

### 4. 리서치 수행
- 단원별 후보 N명 수집
- 각 후보의 minimum 정보:
  - 생몰·시대·국가
  - 업적·발견 1줄
  - 발견의 필연성 핵심 자료원 (그 인물이 마주한 질문 — § 리서치 패턴 결정적 순간 자료원 참조)

### 5. 후보 평가
정체성 약속 3겹과의 부합:
- **시대 감각**: 시대·장소 풍경이 영상으로 표현 가능한가
- **인물 정서**: 한 장면으로 압축 가능한 정서적 사실이 있는가
- **발견의 필연성 서사**: 그 인물이 그 발견을 *왜* 했는가의 자료가 있는가

추가 평가:
- 19인 풀 중복 체크
- 시즌 frame 안 시대·국가 분포
- 발굴 우선순위 frame (입력 7) 반영
- 광범 시청자 진입 매력
- 학습자 (중1) 수준 적합

### 6. Nick 검토 QnA  ← Q&A 2
- 후보 제시 (탈락 후보의 이유 포함)
- Nick 선택·이견 확인
- 이견 시 동작 4·5 재실행 (좁힌 frame 으로)

### 7. 선정 + 이유 출력
- 매핑 표 + 선정 이유 문서 작성
- 출력 위치 결정 (호출자 지정 / default = `40_experiments/exp-NNN-selection-<범위>/output.md`)
- 다음 단계 [서사] 의 입력 명세 작성 (각 인물의 사실 자료원 정리)

---

## QnA 패턴 시드 (스킬 내재화)

### 동작 2 — 입력 보강 Q
- 이 단원에서 학습자가 특히 어려워한 부분 있나
- 잘 알려진 인물 vs 새 발굴, 어느 쪽 선호
- 시대 분포는 시즌 frame 안에서 어떻게
- 한 단원에 2명 이상 가능 (대비) 인가, 1:1 매핑 유지인가

### 동작 6 — 후보 검토 Q
- 후보 N명 중 약속 3겹에 가장 부합하는 인물은
- 탈락 후보 중 다른 단원에 살릴 만한 인물 있는가
- 학습자 흥미 측면에서 우려되는 후보 있는가

---

## 리서치 패턴 시드 (스킬 내재화)

### 깊이별 patterns
- **얕은** (단순 사실): Wikipedia 한국어 + 영어 비교. 빠름.
- **중간** (정서·일화): + 수학사 도서 + 학술 자료. 정서적 사실 확보.
- **깊은** (동시대 비교): + 학술 데이터베이스 + 시대 풍경 자료. 발견의 필연성 서사용.

### 결정적 순간 자료원
**발견의 필연성 서사** 를 만들려면 "그 인물이 마주한 질문" 의 자료원이 핵심:
- 일반 위인전: "어떻게 발견했는지" 있음, "왜 그 질문을 했는지" 약함
- 필요한 것: 동시대 학자의 미해결 문제 / 그 시대가 요구한 실용적 필요 / 인물 개인 서신·일기

### 자료원 신뢰도
- 1차 자료 (원문·서신) > 학술 2차 자료 > 위키 > 대중 출판물 > 블로그
- 인물의 "왜" 에 관한 주장은 자료원 명시 필수 (스토리 단계의 fabrication 방지)

---

## 평가 기준 (스킬 내재화)

선정된 인물이 다음을 만족하는가:

- [ ] 약속 3겹 연결 가능 (시대 감각 / 인물 정서 / 발견의 필연성)
- [ ] 사실 자료원 충분 (다음 단계 [서사] 의 입력)
- [ ] 광범 시청자 진입 매력 (이름 모르는 시청자가 보고 흥미)
- [ ] 학습자 (중1) 수준 적합
- [ ] 시즌 frame 안 분포 균형 (시대·국가)

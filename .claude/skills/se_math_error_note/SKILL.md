# se_math_error_note — 중1 수학 오답노트 생성 스킬

## 인자 형태
```
/se_math_error_note               # 인터랙티브 (문제 번호 물어봄)
/se_math_error_note Q3            # 기본
/se_math_error_note Q3 unit01     # 단원 명시
```

## 디렉토리 매핑
- 문제 원문: `40_BaseDocs/` 또는 Nick이 제공하는 문제 텍스트
- 오답노트 저장: `50_units/NN_단원명/problems/`

## 절차

### 1. 정보 수집
- 문제 번호, 단원, 내가 쓴 답 (없으면 "미입력")
- 해당 단원의 40_BaseDocs 개념 파일 읽기
- 문제 원문 확인

### 2. 오답노트 .md 생성
**파일 경로**: `50_units/NN_단원명/problems/Q<번호>_<주제키워드>.md`

**7섹션 포맷** (순서·섹션명 변경 금지):

```markdown
# Q<번호> — [약점태그1] / [약점태그2]

> **[오답노트 포맷 v1]** — Q<번호>_app.html과 쌍을 이룸

---

## 문제 (원문)
[원문 그대로, KaTeX 수식 포함]
```

### 3. HTML 앱 생성
포**파일 경로**: `50_units/NN_단원명/problems/Q<번호>_app.html`

**반드시 APP_PRINCIPLES.md 준수.**
- 단일 HTML, 바닐라 JS, KaTeX CDN
- Page 0: 문제 원문 + 생각 유도
- Page 1~N: 단계별 풀이
- 요약: 정답 + 약점 태그
- 말투: ~해요, 함께 생각해봐요

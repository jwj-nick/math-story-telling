# /se_ncc_audit_concept — 개념 수준·범위 검토 Skill

## 역할
`40_BaseDocs/NN_단원명/`의 개념 MD가
중1 수준에 맞고 딸에게 적합한지 항목별로 점검.

---

## 인자 형태

```
/se_ncc_audit_concept unit01
/se_ncc_audit_concept 40_BaseDocs/01_소인수분해/
```

---

## 실행 절차

### 1. 기준 파일 읽기
- `10_docs/01_learner-profile.md` — 학습자 수준, 정서, 학습 스타일
- `20_research/01_R1-curriculum-map.md` — 중1 교육과정 매핑
- 해당 단원 `40_BaseDocs/NN_단원명/` 전체 MD

### 2. 체크리스트 검토

**[정확성]**
- [ ] 수학적 정의가 오류 없이 정확한가?
- [ ] 예시가 개념을 올바르게 설명하는가?
- [ ] 반례가 필요한 곳에 있는가?

**[수준 적합성]**
- [ ] 중1 교육과정 범위를 벗어나지 않는가?
- [ ] 고등 수준 개념이 불필요하게 포함되지 않는가?
- [ ] 선행 개념(중1 기준)이 충분히 설명되는가?

**[학습자 적합성]** (learner-profile 기준)
- [ ] 언어 난이도가 중1 수준인가?
- [ ] 서사적·시각적 요소가 있는가? (언어 우위형 학습자)
- [ ] "왜?"에 대한 답이 있는가?
- [ ] 부담 없는 분량인가?

**[커버리지]**
- [ ] 단원의 핵심 개념이 빠짐없이 포함되는가?
- [ ] 교육과정 학습목표 대비 누락 항목 없는가?

### 3. 판정

| 판정 | 기준 | 처리 |
|---|---|---|
| Pass | 전항목 충족 | 완료 |
| Warn | 보완 권고 (필수 아님) | chatlog에 메모 |
| Fail | 오류 또는 심각한 수준 불일치 | **1회 일괄 수정 후 종료. 재감사 금지** |

## ⚠️ 1-shot 원칙 (필수)

- BaseDocs MD를 한 번 Read → 모든 항목 batch 점검 → 모든 Fail 일괄 Edit → 종료
- 수정 후 동일 MD를 검증 목적으로 재읽기 금지 (Edit 결과 신뢰)
- 재감사 사이클은 시간·토큰의 주요 낭비 원인

### 4. 보고 형식

```
## /se_ncc_audit_concept 결과: unit01

### Pass 항목
- 수학적 정확성 ✅
- 중1 범위 준수 ✅
- ...

### 보완 권고 (Warn)
- [항목]: [내용]

### 수정 필요 (Fail)
- [항목]: [문제] → [수정 방향]

### 최종 판정: Pass / Warn N건 / Fail N건
```

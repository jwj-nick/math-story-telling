# /se_ncc_audit_problem — 문제 커버리지·난이도 검토 Skill

## 역할
생성된 문제 세트가 단원 핵심 개념을 빠짐없이 다루고,
난이도 분포가 딸의 수준에 맞는지 검토.

---

## 인자 형태

```
/se_ncc_audit_problem unit01 basic_app.html
/se_ncc_audit_problem unit01 types.md
/se_ncc_audit_problem 50_units/01_소인수분해/problems/basic_app.html
```

---

## 실행 절차

### 1. 기준 파일 읽기
- `40_BaseDocs/NN_단원명/` — 단원 핵심 개념 목록
- `10_docs/01_learner-profile.md` — 학습자 수준
- `50_units/NN/problems/types.md` — 유형 목록 (있는 경우)

### 2. 커버리지 체크 (basic_app.html 대상)

- [ ] 단원 핵심 개념이 모두 적어도 1문제씩 포함되는가?
- [ ] 정의 확인 문제 있는가?
- [ ] 계산 절차 문제 있는가?
- [ ] 응용·서술형 문제 있는가?
- [ ] 특정 개념만 과다 출제되지 않는가?

### 3. 난이도 분포 체크

| 구간 | 기준 | 적정 비율 |
|---|---|---|
| 기본 (개념 확인) | 공식·정의 직접 적용 | 40~50% |
| 중간 (절차 적용) | 2단계 이상 계산 | 30~40% |
| 응용 (심화) | 복합 개념 또는 역방향 | 10~20% |

- [ ] 너무 쉬운 것만 있지 않은가?
- [ ] 응용이 중1 범위를 벗어나지 않는가?

### 4. types.md 검토 (유형 목록 대상)

- [ ] 시험에 실제로 자주 출제되는 유형이 포함되는가?
- [ ] 너무 세분화되어 딸에게 부담이 되지 않는가?
- [ ] 유형 간 중복이 없는가?

### 5. 판정

| 판정 | 기준 | 처리 |
|---|---|---|
| Pass | 커버리지·분포 모두 적절 | 완료 |
| Warn | 한두 개념 누락 또는 분포 약간 불균형 | chatlog에 메모 |
| Fail | 핵심 개념 다수 누락 또는 난이도 심각 불균형 | **1회 보완 후 종료. 재검토 금지** |

## ⚠️ 1-shot 원칙 (필수)

- 문제 세트와 types.md를 한 번씩만 Read → 커버리지·난이도 batch 점검 → 누락 사항 일괄 추가/수정 → 종료
- 보완 후 동일 파일 재읽기·재점검 금지

# /se_ncc_audit_story — 스토리 적합성 검토 Skill

## 역할
1. **생성된 스토리** 검토: 역사 사실성, 중1 적합 톤, 수학 개념 연결성
2. **딸의 피드백** 분석: `feedback/` 내용 읽고 learner-profile 업데이트 권고

---

## 인자 형태

```
/se_ncc_audit_story unit01               # 스토리 검토
/se_ncc_audit_story unit01 feedback      # 딸 피드백 분석
/se_ncc_audit_story 50_units/01/story/unit01.md
```

## [모드 1] 스토리 검토

### 실행 절차

**1. 기준 파일 읽기**
- `10_docs/01_learner-profile.md`
- `20_research/02_R2-people-map.md` (인물 기본 정보)
- `50_units/NN/story/unitNN.md` (검토 대상)

**2. 체크리스트**

**[역사적 사실성]**
- [ ] 인물의 생몰년, 업적이 알려진 사실과 일치하는가?
- [ ] 수학적 발견·맥락이 역사적으로 가능한 설정인가?
- [ ] 명백히 잘못된 사실이 없는가?

**[중1 적합성]**
- [ ] 문장 난이도가 중1 읽기 수준인가? (너무 어렵거나 유치하지 않은가?)
- [ ] 분량이 부담 없는가? (2,000자 이하 권고)
- [ ] 수학에 대한 부정적 감정을 자극하지 않는가?

**[감성·공감]**
- [ ] 인물이 딸이 공감할 만한 상황에 처하는가?
- [ ] "수학을 잘하고 싶다"는 동기를 강화하는 요소가 있는가?

**[수학 연결]**
- [ ] 스토리와 이 단원의 핵심 개념이 자연스럽게 연결되는가?
- [ ] 수학이 스토리에서 어색하게 억지로 끼워지지 않는가?

**3. 판정 및 보고**

```
## /se_ncc_audit_story 결과: unit01 스토리

### Pass 항목
...

### 수정 권고
| 항목 | 문제 | 수정 방향 |
|---|---|---|

### 주의: 역사적 사실 최종 확인은 Nick이 직접 해주세요.
NCC가 확인한 항목: [목록]
NCC가 확인 불가한 항목: [목록]

### 최종 판정: Pass / Warn / Fail
```

## ⚠️ 1-shot 원칙 (필수)

- 스토리 MD를 한 번 Read → 체크리스트 전 항목 batch 점검 → 발견된 수정 권고는 chatlog에 일괄 기록
- Fail 수정은 1회만, 수정 후 재검토 금지
- 역사적 사실 확인 불가 항목은 Nick에게 위임 (반복 검색·검증 금지)

## [모드 2] 딸 피드백 분석

### 실행 절차

**1. 피드백 파일 읽기**
`50_units/NN/feedback/` 전체 파일 (원본 수정 절대 금지)

**2. 분석 항목**
- 어떤 내용에 긍정 반응을 보였는가?
- 어떤 내용이 어렵거나 지루했는가?
- 감정 표현이 어떤가? (자신감↑/↓, 흥미↑/↓)
- 반복 언급된 키워드가 있는가?

**3. learner-profile 업데이트 권고**

```
## 피드백 분석: unit01 / 딸

### 관찰된 패턴
- [긍정]: ...
- [어려움]: ...
- [감정]: ...

### learner-profile.md 업데이트 권고
업데이트 항목:
- [섹션명]: [현재 내용] → [업데이트 제안]

> 원본 피드백 파일은 수정하지 않았습니다.
> learner-profile 업데이트는 Nick 확인 후 진행해주세요.
```

**4. learner-profile 실제 업데이트**
Nick이 "업데이트해줘"라고 확인 → `10_docs/01_learner-profile.md` 수정
Nick 확인 없이 자동 수정 금지.

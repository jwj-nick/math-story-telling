# /se_type_explorer — 유형별 깊이 탐구 자료 생성 Skill

## 역할
Phase 5-d에서 unit-orchestrator가 호출하는 Skill.
`types.md`의 각 중간+ 난이도 유형에 대해 **심화 이해 자료 + 추가 문제**를 생성한다.

> 단원 제작 파이프라인의 일부 — 딸의 반응에 관계없이 단원 생성 시점에 만들어진다.
> 너무 쉬운 유형(L 문제만 있는 기본형)에는 생성하지 않는다.

---

## 인자 형태

```
# 단일 유형
/se_type_explorer [단원번호] [유형명]
/se_type_explorer unit01 소인수분해기본형

# 통합 앱 (관련 유형 여러 개를 하나의 탭 앱으로)
/se_type_explorer [단원번호] [유형A] [유형B] [유형C]
/se_type_explorer unit01 최대공약수 최소공배수 GCD_LCM관계식
```

---

## 통합 앱 결정 기준

unit-orchestrator가 types.md를 보고 판단 후 전달:

**통합 앱으로 제작:**
- 같은 개념 체계에 속하는 유형들 — 예: GCD/LCM/관계식, 비례식/비율, 이항/동류항 등
- 각각 별도 앱으로 만들면 학습자가 연결 관계를 놓치기 쉬운 경우

**별도 앱으로 제작:**
- 개념적으로 독립적인 유형
- 하나만으로도 내용이 충분히 복잡하고 독립 학습이 더 명확한 경우

**통합 앱 파일명:** `deep_유형A_유형B_app.html` 또는 의미 있는 통합명 (예: `deep_GCD_LCM_app.html`)

**통합 앱 내부 구성 (탭별):**
```
각 탭 = 각 유형
  섹션 1: 핵심 전략 (왜 어려운가 + 어떻게 접근하나)
  섹션 2: L/M/H 문제 스크롤 (정답·힌트 버튼)
  섹션 3: 자주 하는 실수 (2~3가지)
  섹션 4: 연결 개념 태그
```

---

## 생성 조건 (unit-orchestrator가 판단)

**생성함:**
- types.md에 M 또는 H 문제가 포함된 유형
- 개념 이해에 추가 설명이 의미 있는 유형

**생성 안 함:**
- L 문제만 있는 기본형 (단순 계산 확인 수준)
- 이미 basic_app.html에서 충분히 다룬 쉬운 유형

---

## 실행 절차

### 1. 컨텍스트 읽기
- `40_BaseDocs/NN_단원명/` — 해당 단원 개념 전체
- `50_units/NN/problems/types.md` — 유형 설명
- `50_units/NN/problems/type_NN_app.html` — 이미 생성된 연습 문제 (내용 파악)
- `10_docs/01_learner-profile.md` — 학습자 수준

### 2. 유형 분석
- 이 유형에서 학생이 막히기 쉬운 지점은 어디인가?
- 선행 개념 중 이해가 필요한 것은?
- 어떤 접근 순서로 설명하면 가장 자연스러운가?

### 3. 심화 자료 생성

**파일**: `50_units/NN/problems/deep_유형명_app.html`

HTML 앱 구성:
```
섹션 1: "왜 이 유형이 어려운가?" — 솔직하고 친근한 설명
섹션 2: 핵심 아이디어 (한 문장으로)
섹션 3: 단계별 풀이 흐름 (3~5단계, 클릭으로 단계 공개)
섹션 4: 자주 하는 실수 (2~3가지)
섹션 5: 추가 문제 3~5개 (아주 쉬운 것 → 점진적 난이도)
         각 문제에 단계별 힌트 (details, 3단계)
섹션 6: 이 유형을 알면 다음에 뭐가 쉬워지나 (연결 개념)
```

**원칙:**
- 딸에게 직접 말하는 톤 ("이 유형의 핵심은요...")
- 추가 문제는 type_NN_app.html과 겹치지 않게
- APP_PRINCIPLES.md 준수

### 4. 수학 검증
- `/se_ncc_audit_math` 실행 — 추가 문제 정확성 확인
- `/se_ncc_audit_app` 실행 — HTML 앱 품질 확인

### 5. 완료 보고
```
/se_type_explorer 완료 — unit01 / 소인수분해기본형

생성: deep_소인수분해기본형_app.html
  - 3단계 풀이 흐름 + 실수 패턴 2가지 + 추가 문제 4개
  - audit: 수학 Pass / 앱 Pass
```

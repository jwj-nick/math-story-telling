**선택: 카발리에리**

선정 이유:
1. **단원 핵심과 직결**: 카발리에리 원리 = **"같은 높이에서 단면적이 같으면 두 입체의 부피는 같다"**. 이것이 각뿔 부피 $V = \frac{1}{3}Sh$, 구 부피 $V = \frac{4}{3}\pi r^3$ 도출의 직관적 핵심. 단원 전체를 관통하는 단 하나의 원리.
2. **Unit 11 케플러와 자연스러운 계보**:
   - 케플러 「Stereometria Doliorum」 1615 — 술통 부피 (회전체 적분 선구)
   - 카발리에리 「Geometria Indivisibilibus」 1635 — 부피 측정 일반 원리
   - 두 사람은 동시대 (1571~1630 케플러 / 1598~1647 카발리에리)
   - 케플러가 회전체 부피의 씨앗을 뿌렸고, 카발리에리가 그것을 일반 원리로 정립
   - 결국 카발리에리 → 뉴턴/라이프니츠 → 적분의 정식 탄생
3. **갈릴레오의 직제자**: 갈릴레오 갈릴레이의 가장 아끼던 제자. 갈릴레오의 추천으로 1629년 볼로냐 대학 수학 교수 임명. 갈릴레오와 30년간 편지 교류. **사제 관계 + 후원 + 학문 계승의 따뜻한 일화** — 중1 여학생 정서 친화.
4. **시력 약한 천재 + 평생 통풍 투병**: 어릴 때부터 시력이 약했고 평생 통풍으로 고생. 그럼에도 30년 볼로냐 교수직 + 11권의 책 저술. Unit 11 케플러(천연두 시력 손상)와 정서적 페어링 — "보이지 않는 것을 본 사람" 메시지 강화.
5. **예수회 수도사 → 베네딕트회 수도사**: 종교적 삶 속에서 수학 연구. 17세기 이탈리아의 종교-과학 긴장 (갈릴레오 종교재판 1633이 카발리에리 「Geometria」 1635 직전). 학습자에게 시대적 깊이 제공.
6. **인물 다양성**: 17세기 이탈리아 + 수도사 + 갈릴레오 학파. 기존 그리스(01·07·08·10)·인도(02)·페르시아(03)·헬레니즘(04)·프랑스(05·06)·독일(09·11)과 다른 새 인물.
7. **"단면 쌓기" 직관의 중1 적합성**:
   - 종이를 쌓으면 책이 됨 → "두께가 거의 0인 단면을 무한히 쌓으면 입체"
   - 같은 모양 종이 더미를 비스듬히 기울여도 부피는 변하지 않음 → 카발리에리 원리
   - 동전을 쌓은 두 더미가 같은 높이면 부피 같음 (모양 달라도)
   - **중1도 직관적으로 받아들일 수 있는 시각적 원리**
8. **적분의 시조 메시지**: 카발리에리는 "indivisibilibus(불가분량, 무한히 얇은 단면)"을 도입. 이것이 200년 후 적분의 미분소(dx) 개념으로 발전. **딸이 고등학교에서 적분을 만날 때 "아, 카발리에리에서 본 거구나" 할 수 있는 씨앗**.

**보조 메시지**:
- "**원리는 단순할수록 강력하다**" — 카발리에리 원리는 한 문장: "같은 단면적 → 같은 부피". 그러나 이 한 문장으로 각뿔·구·회전체 모든 부피가 풀린다. 학습자에게 "수학은 복잡해 보여도 핵심은 단순하다" 격려.
- "**스승의 어깨 위에서**" — 갈릴레오 → 카발리에리 → 뉴턴/라이프니츠 → 현대 적분. 수학은 한 사람의 천재가 아니라 세대를 잇는 협업.

### 핵심 수학 개념 체크리스트

**각기둥의 겉넓이·부피:**
- [x] 겉넓이 = (밑넓이 × 2) + 옆넓이
- [x] 옆넓이 = 밑면의 둘레 × 높이
- [x] 부피 $V = Sh$ (밑넓이 × 높이)
- [x] 직육면체 겉넓이 $2(ab+bc+ca)$, 부피 $abc$
- [x] 정육면체 겉넓이 $6a^2$, 부피 $a^3$

**각뿔의 겉넓이·부피:**
- [x] 겉넓이 = 밑넓이 + 옆넓이 (옆면 삼각형들의 합)
- [x] 부피 $V = \frac{1}{3}Sh$
- [x] ★ 각뿔 부피 = 같은 밑면·높이 각기둥 부피의 $\frac{1}{3}$ (카발리에리 직관)

**원기둥의 겉넓이·부피:**
- [x] 겉넓이 $S = 2\pi r^2 + 2\pi rh$
- [x] 부피 $V = \pi r^2 h$
- [x] 옆면 펼치면 직사각형 (가로 $2\pi r$, 세로 $h$)

**원뿔의 겉넓이·부피:**
- [x] 모선 $l = \sqrt{r^2 + h^2}$ (피타고라스 — 중1에서는 도출보다 결과 인식)
- [x] 겉넓이 $S = \pi r^2 + \pi r l$
- [x] 부피 $V = \frac{1}{3}\pi r^2 h$
- [x] 옆면 펼치면 부채꼴 (반지름 $l$, 호 $2\pi r$)
- [x] 부채꼴 중심각 $\theta = (r/l) \times 360°$

**구의 겉넓이·부피:**
- [x] 겉넓이 $S = 4\pi r^2$ ($= 원의 넓이 \times 4$)
- [x] 부피 $V = \frac{4}{3}\pi r^3$
- [x] 반구: 겉넓이 $3\pi r^2$ (반구면 $2\pi r^2$ + 평면원 $\pi r^2$), 부피 $\frac{2}{3}\pi r^3$
- [x] 아르키메데스 원기둥-구 부피비 (1:2:3 비례) — Unit 10 연결 잡학

**카발리에리 원리 (스토리·앱 직관 도구):**
- 같은 높이에서 단면적 같으면 부피 같음
- 각뿔 부피 = 각기둥 부피의 1/3 도출 직관
- 구 부피 = 원기둥 - 원뿔×2 (반구 부분) 직관

### 시각화 핵심 포인트

- 1:2:3 부피비 시각화 (아르키메데스 원기둥-구-원뿔)
- 부피 슬라이더 ($r$ 슬라이더 → 식 자동 갱신)

### 자주 하는 실수 (사전 식별)
1. 각기둥 옆넓이 = 밑면 둘레 × 높이 잊음 (옆면 개별 계산 비효율)
2. 각뿔 부피 $\frac{1}{3}$ 빼먹기
3. 원뿔 겉넓이에서 부채꼴 옆면 = $\pi r l$ (밑면 둘레 × 모선의 절반) 식 혼동
4. 원뿔 부피의 높이 $h$ ↔ 모선 $l$ 혼동
5. 구 겉넓이 $4\pi r^2$ ↔ 부피 $\frac{4}{3}\pi r^3$ 혼동
6. 반구 겉넓이 = 구의 반인 $2\pi r^2$만 답함 (밑면 원 $\pi r^2$ 빠뜨림)
7. 회전체 부피 = 회전 전 평면도형 넓이 × 무엇? (★ 잘못된 일반화 — 실제는 단면 적분 필요)
8. 단위 (cm² vs cm³) 혼동
9. $\pi$ 빠뜨림 / 곱셈 순서 실수
10. 원기둥 부피 $\pi r^2 h$ vs 원기둥 겉넓이 $2\pi r^2 + 2\pi rh$ 식 혼동

- `problems/type_03_app.html` — 원기둥
  - L: 부피 ($\pi r^2 h$), 옆넓이 ($2\pi rh$), 반지름 변화 → 부피 변화
  - M: 겉넓이 분해, 전개도 가로=둘레 활용, 높이 역산
  - H: 관 모양 부피, 옆면 대각선 (피타고라스), 회전체 → 원기둥
- `problems/type_04_app.html` — 원뿔 (★ h vs l 함정)
  - L: 부피 ($\frac{1}{3}\pi r^2 h$), 옆넓이 ($\pi r l$), 겉넓이
  - M: 부채꼴 중심각 $\theta = (r/l)\times 360°$, 부피·옆넓이 동시 (★), 피타고라스 5-12-13
  - H: 두 공식 등가성 ($\pi rl = \frac{1}{2}\times 호 \times l$), 원뿔대, 회전 + 빗변→모선
- `problems/type_05_app.html` — 구
  - L: 부피 ($\frac{4}{3}\pi r^3$), 겉넓이 ($4\pi r^2$), 반구 부피
  - M: 반구 겉넓이 (★ $3\pi r^2$ 평면원 포함), 반지름 변화 (8배), 부피 역산
  - H: 원기둥에 꼭 맞는 구 (아르키메데스 2:3), 1:2:3 비율, 합성 입체
- `problems/type_06_app.html` — 회전체

# Round 0 (NCC) — 상세 설계 제안

## 0. 관통 컨셉 — 두 층 시스템 (어제와 이어짐)

```
   [이해]  개념 여정 페이지  ← 지금 설계하는 것 (화려·몰입·호기심)
      │      "왜?"에서 시작 → 인물/시대 → 시각적 개념 → 수학언어 → 아하 → 딸의 글
      ▼   (한 개념을 완전히 이해)
   [유창성] 드릴 (mid2/drill.html)  ← 이미 배포. 손에 익히기.
      ▼
   [Phase 2] 고급 문제·심화 콘텐츠  ← 기초 다 끝난 뒤
```

- **역할 분담**: 개념 페이지 = 축 A(이해)+B(흥미)+C(수학언어). 드릴 = 축 D(문제·유창성).
- **핸드오프**: 개념 여정 끝 → "이제 손에 익히자" → 해당 드릴 스킬로 딥링크.
- **계승**: concept.md의 "수학의 사람들"(실존 인물·가짜판타지 금지)·5단계·"진도 아닌 개념 그래프", literacy L1~L7, APP_PRINCIPLES(점진공개·빈칸·따뜻함) 그대로. 그 위에 **몰입도만 대폭 강화**.

- **단원 번호 리셋**: 중2-1 = **단원 1~6** (14·15 폐기). 표준 2022 개정 기준:
  | 중2-1 단원 | 개념 | 인물(연속성) |
  |---|---|---|
  | **1. 유리수와 순환소수** | 분수↔소수, 무한의 첫 만남 | (신규) 무한·표기 |
  | **2. 식의 계산** | 단항·다항식, **지수법칙** | 비에트/데카르트(기호, L4) |

  - 후보 테마: **"대수의 시대 — 기호와 관계의 세계"**(중1 '수·도형'에서 '문자·관계'로 도약하는 중2 성격과 정확히 일치). 색은 중1 흙빛/고대와 대비되는 **깊은 남색+청록+골드**(밤하늘·좌표·별자리 느낌 → 함수/관계 은유).

### 단원별 구체안 (호크·인물·핵심 인터랙션)

**1. 유리수와 순환소수**
- 훅: "1 ÷ 3 = 0.333… 왜 안 끝날까? 계산기도 컴퓨터도 못 끝내는 나눗셈" — 3이 끝없이 흐르는 애니.
- 인물/시대: 분수를 소수로 적기 시작한 사람들, '무한'을 처음 마주한 긴장.
- 핵심 인터랙션: 분모의 소인수를 슬라이더로(2·5만 → "딱 떨어짐" / 3·7 섞이면 "무한 반복"). 나눗셈이 애니로 돌며 **순환마디가 색으로 뜬다**.
- 언어 렌즈: 순환마디 위 점 표기(0.3̇) = "무한을 유한하게 적는 약속".
- 드릴 연결: 순환마디 찾기 · 유한/무한 판별.

**2. 식의 계산 (지수법칙)**
- 훅: "종이를 42번 접으면 달에 닿는다 — 2를 42번 곱하면?" 지수의 폭발.
- 인물: 곱셈 반복을 압축한 기호의 발명(비에트·데카르트, L4·L5).
- 핵심 인터랙션: aⁿ = 블록 n개. a²·a³ 를 **블록 합치기**로 → a⁵ (왜 지수를 더하는지 눈으로). (aᵐ)ⁿ = 블록의 블록.
- 언어 렌즈: L5(곱셈기호 생략, 2x=2×x), 지수 표기.
- 드릴 연결: 지수법칙·동류항·괄호 풀기.

**3. 일차부등식**
- 훅: "'같다'가 아니라 '더 크다/작다'로 세상을 본다면? 키 제한, 예산, 시간…" 부등식 = 조건.
- 인물: 부등호 <, > 를 만든 해리엇.
- 핵심 인터랙션: **저울(balance)**. 양변에 같은 수 더해도 균형 유지 → 근데 **음수를 곱하면 저울이 뒤집힌다**(부등호 방향 반전)를 애니로. (중2 최대 함정 정조준)
- 언어 렌즈: 부등호 방향, 수직선 위 범위 색칠.
- 드릴 연결: (부등식 스킬 추가 예정).

**4. 연립일차방정식**
- 훅: "우리에 닭과 토끼. 머리 35, 다리 94. 각각 몇 마리?"(구장산술 고전) — 두 조건 동시에.
- 인물: **디오판토스(중1-4 연장!)** + 동양 구장산술. "아는 인물의 다음 이야기."
- 핵심 인터랙션: 두 직선이 좌표에 그려지고 **교점 = 해**. 대입법 = 한 식을 다른 식에 **흘려넣는** 애니(드릴 대입법과 직결).
- 언어 렌즈: L2(일반형/구체형), 미지수 2개.
- 드릴 연결: 대입법.

**5. 일차함수와 그래프** ★ (세은 원약점 정조준)
- 훅: "데카르트가 침대에서 천장의 파리를 보고 발명한 것"(concept.md 실화) — 위치를 숫자 두 개로.
- 인물: **데카르트(중1-5·6 연장!)**.
- 핵심 인터랙션: **y = ax + b 슬라이더** — a(기울기)·b(절편)를 움직이면 직선이 실시간으로 움직이고 **식이 자동으로 다시 써진다**. → literacy **L2 flagship** = 세은의 바로 그 약점(y=a/x → y=-2/x "못 읽음")을 정면 처치. 여기가 가장 화려한 핵심.
- 언어 렌즈: L2 일반형/구체형, L7 식읽기 5단계.
- 드릴 연결: (함수 스킬 추가 예정).

**6. 일차함수와 일차방정식**
- 훅: "방정식의 답은 그래프의 어디에 숨어 있을까?" 식의 세계와 그림의 세계가 하나로.
- 인물: 데카르트 연장(좌표기하 통합).
- 핵심 인터랙션: ax+b=0 의 해가 그래프의 **x절편으로 빛난다**. 연립 = 두 그래프 교점.
- 드릴 연결: (통합 스킬).

## 3. "화려·몰입·호기심" 장치 (Nick 새 강조점)

- **스크롤리텔링**: 장면 단위 전체화면, 스크롤이 애니메이션을 트리거(IntersectionObserver). 이야기처럼 넘어감.
- **살아있는 그래프/애니**: 나눗셈 흐르기, 지수 블록 쌓기, 저울 뒤집기, 직선 실시간 이동. (정적 설명 최소)
- **직접 조작**: 슬라이더·드래그 — "네가 움직여봐". 조작이 곧 이해.
- **인물 가이드**: 각 단원 인물이 말 거는 방식(작은 초상 + 말풍선).
- **세계관 비주얼**: 남색·청록·골드 팔레트, 삽화, 단원 커버.
- **마이크로 보상**: 여정 완료 시 "발견 배지/도장", 6단원 진행 지도가 채워짐 → 다음 호기심.
- **호기심 훅**: 모든 단원을 질문/미스터리로 연다("왜 안 끝날까?", "닭과 토끼").
- **딸의 자리**: 글쓰기·빈칸(강점 활용, 자기 언어로 개념 체화).
- (선택) 부드러운 효과음 — 부담되면 off 토글.

## 4. 기술 — 화려함 vs 제약

- 바닐라 HTML/JS 유지. 화려함 위해 **스크롤 애니(GSAP+ScrollTrigger 또는 CSS+IntersectionObserver)**, 그래프 **JSXGraph/SVG**, 수식 **KaTeX**.
- 트레이드오프: 드릴은 CDN無 오프라인. 개념 페이지는 몰입 위해 **CDN 애니 라이브러리 허용?** = 결정사항(폰 로딩·오프라인 vs 화려함).
- 폰 우선, max-width는 몰입형이라 700보다 넓게(풀블리드 장면) 가능 — APP_PRINCIPLES 진화 필요.

# Round 1 — 방향 반영, 기본 개념 phase 다시 설계 (2026-07-09)

> Round 0은 기능 나열(배지·효과음·"몰입/화려" 반복)에 치우쳐 "너무 AI스럽다"는 지적을 받음. 아래가 실제 학습 설계 기준의 정리본이고, Round 0의 접근을 대체한다.

## Nick 피드백 (반영 4가지)

1. 중1↔중2 연결을 **본문에서** 자연스럽게. "작년에 배운 걸 이어서 이걸 한다"를 학습자가 느끼게. (사이드 링크 X)
2. **기본 개념 phase에서는 인물 서사를 뺀다.** (인물 이야기는 영상 트랙과 심화 과정 몫.) 단, **호기심 장치는 남긴다.**
3. 딸이 **이해한 걸 스스로 설명(teach-back)** 하고 **직접 문제를 만들어보는** 경험을 넣는다.
4. 이번엔 **기초**, 다음엔 **심화** 과정을 만든다 — 명시.

## 기본 개념 페이지 하나 = 하나의 학습 흐름

장면·기능의 나열이 아니라, 한 개념을 "들어는 봤다"에서 **"내 말로 설명하고 내가 문제도 낼 수 있다"** 까지 데려가는 순서다. 여섯 걸음:

1. **이어짐** — 먼저 작년에 할 수 있던 것을 되살린다(작은 확인 1개). 그 위에서 "올해 건 여기서 딱 한 걸음"임을 본문이 말한다. 새 개념을 낯선 것이 아니라 아는 것의 연장으로 만든다 — 세은에게 필요한 안전감.
2. **왜 궁금한가** — 인물 이야기 대신, 현상·상황·수수께끼로 당긴다. 답이 궁금해서 다음으로 넘어가게.
3. **직접 움직여 이해** — 슬라이더·드래그로 개념이 반응한다. "b를 바꿔봐, 그래프가 어떻게 되지?" 유도 질문과 함께. 여기에 수학 언어(일반형 ↔ 구체형)를 심는다 — 조작하는 동안 식이 저절로 다시 써진다.
4. **내 말로 설명** — 골격 있는 빈칸 + 자유 설명으로 스스로 정리한다. 시도한 뒤에야 예시 설명을 연다(점진적 공개). 세은의 글쓰기 강점을 이해의 통로로.
5. **내가 문제 만들기** — 상황과 숫자를 골라 자기 문제를 만든다. 문제를 내는 쪽에 서는 순간 이해가 굳는다. 언어 강점이 그대로 쓰인다.
6. **손에 익히기** — 해당 드릴로 넘긴다.

## 연속성을 본문에 심는 지점 (단원별 "작년의 무엇에서 출발")

- **1 순환소수** ← 작년의 분수·소수, 나눗셈. "분수를 소수로 바꾸던 그 나눗셈을 계속하면…"
- **2 식의 계산** ← 작년의 문자와 식, 동류항. "작년에 2x+3x를 5x로 모았지. 올해는 x²·x³ 같은 것도."
- **3 일차부등식** ← 작년의 방정식(등식). "'='를 풀던 방법이 '<, >'에서도 거의 그대로 — 딱 한 곳만 빼고(음수)."
- **4 연립방정식** ← 작년의 일차방정식(미지수 1개). "작년엔 x 하나였지. 올해는 x, y 둘 — 대신 식도 둘."
- **5 일차함수** ← 작년의 정비례 y=ax. "y=2x면 x가 1,2,3일 때 y는 2,4,6. 여기에 +b 하나만 더한 게 일차함수."
- **6 함수와 방정식** ← 5 + 작년 방정식. "방정식의 답이 그래프 위 어디에 있는지."

## teach-back & 문제 만들기 — 실제 형태

- **teach-back**: 뼈대 있는 빈칸("이 그래프에서 a는 ___를 정하고, b는 ___를 정한다. 왜냐하면 ___") + 자유 설명 칸. 쓰기 전엔 답을 안 보여주고, 쓴 뒤 "다른 설명 보기"로 예시를 연다.
- **문제 만들기**: 언어 강점을 쓴다. 상황 템플릿을 채우면(예: "매일 ___원씩 모으고 지금 ___원 있다 → n일 후 얼마?") 자기만의 식 y=ax+b가 나오고, 자기가 만든 문제를 자기가 푼다(역할 반전). 만든 문제는 저장/모아 보기.

## 호기심은 유지하되 장식 게임화는 뺀다

현상·상황·수수께끼로 당긴다: "1÷3은 왜 안 끝날까?"(순환), "종이를 42번 접으면 달에 닿는다?"(지수), "음수를 곱하면 왜 뒤집힐까?"(부등식), "닭과 토끼"(연립), "택시요금을 그림으로 그리면?"(함수). 배지·효과음·컨페티 같은 장식은 넣지 않는다 — 이해에 기여하지 않으면 소음이다. 몰입은 "조작하면 반응하는 그래프 + 궁금하게 만드는 질문"에서 나온다.

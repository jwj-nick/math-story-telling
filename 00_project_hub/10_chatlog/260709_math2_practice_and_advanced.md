### 단원별 내용 설계 (핵심 = 수학 정확성 + 청소년 흥미)
- **U1 순환소수**: 연습=피자 나눗셈/분모 소인수 판별/순환마디 자리찾기. 심화탐구=**순환소수→분수 변환기**(×10ⁿ 빼기 원리, 순환소수가 유리수임). 심화문제=0.999…=1 증명·1/7 n번째 자리·복합.
- **U2 식의 계산**: 연습=세포분열/동류항(젤리)/괄호(세트상자)/넓이. 심화탐구=**지수 폭발/복리 시뮬레이터**(ECharts log). 심화문제=2¹⁰≈10³·넓이나눗셈·종이접기 n번.
- **U3 부등식**: 연습=용돈예산/놀이기구 키/부호함정/요금비교. 심화탐구=**부등식 풀이+수직선 시뮬레이터**(음수÷ 시 뒤집기 애니). 심화문제=자유이용권 손익·평균점수.
- **U4 연립방정식**: 연습=**대입법 직격**(y=2x+1을 다른 식에 대입 단계 시각화, 세은 약점)/카페가격/닭토끼/티켓. 심화탐구=**두 직선 교점 시뮬레이터**(평행=해없음·일치=무수). 심화문제=거리속도·복합대입.
- **U5 일차함수**: 연습=양초/택시요금/요금비교/기울기읽기. 심화탐구=**일차함수 랩**(기울기삼각형·양절편·2직선 비교). 심화문제=두점→식→절편·요금비교·그래프해석.
- **U6 함수와 방정식**: 연습=x절편=해/교점=연립해/손익분기/온도. 심화탐구=**직선·방정식·연립 통합 시뮬레이터**. 심화문제=교점 2방법·손익분기·삼각형 넓이.

### 실행 순서
1. 인프라(css/js) + 개념페이지 링크 수정 (NCC).
2. **U1 trio(p1/d1/d1p) NCC 직접 = 골드 레퍼런스.** 검증.
3. U2~U6 서브에이전트 5개 병렬 — 레퍼런스 미러 + 단원 스펙.
4. **재검증 루프 1**: Node 파스체크 전 페이지 + 수학 스팟체크 + 구조 확인 → 수정.
5. **재설계/업그레이드 루프 2**: 아키타입별 품질(시각·정확·난이도·몰입) 상향 → 재검증.
6. 허브·REVIEW_NOTES·chatlog 갱신 → 배포(네트워크 마지막).

### 원칙 준수
- 우선순위 (a)흥미·이해 > (b)실전력. 너무 어렵지 않게.
- 딸 약점(대입·치환·양변 정리) 연습에 명시적으로 녹임.
- 게임식 보상은 은은하게(완료 도장·격려). 과하지 않게.
- 빈칸·상상력 자극(문제 만들기·예측·서술) 유지.

## 지면화에서 한 일

- ★ **화면 그래프에 기대던 문항을 지면에서 성립하게 고쳤어요.** 유형 7 은 원본이 "아래 그래프에서 3초 후 거리는?"
  처럼 앱 화면을 전제로 했어요. 지면에서는 **점의 좌표·상황을 발문에 글로** 줬어요
  (예: "그래프는 원점 (0, 0) 과 점 (4, 6) 을 잇는 직선입니다"). 원본 SVG 1개는 `figure` 로 함께 인쇄돼요.
  나머지 8문항도 기울기·기온·거리를 전부 수치와 상황으로 적어, 그림이 없어도 풀 수 있어요.
- **답의 형태를 못 박았어요** — 좌표는 `(a, b) 꼴로`, 사분면은 `사분면 이름으로 (예: 제1사분면)`,
  부호 문항은 `부등호를 쓴 식으로`, 개수는 `answer_unit: "개"`, 속도·거리는 `단위 m` · `단위 L/분` · `단위 km`.
- **선택형 → 단답형.** 원본의 ①②③ 보기 문항(사분면 고르기, 그래프 위의 점 고르기)은 번호를 떼고
  **해당하는 점의 좌표를 직접 쓰게** 바꿨어요.
- **유형 내부의 답 누출을 막았어요.** 유형 7 의 2번 발문이 6번의 답(그래프 모양)을 그대로 알려 주고 있어서,
  2번을 "선이 위아래로 전혀 움직이지 않는 구간" 으로 고쳐 썼어요.
- KaTeX → HTML. `$\dfrac{a}{b}$` → CSS 세로분수, `$-3$` → `−3`(U+2212), `$\mathrm{A}(-3,-2)$` → `A(−3, −2)`.
  표 문항 2개(유형 6)는 인라인 스타일 `<table>` 로 지면에 그렸어요.
- R8 — 유형 원리 상자는 **판별 방법만** 적었어요. "축 위의 점은 사분면에 속하지 않아요" 처럼 결론을 쓰면
  유형 2 의 세 문항이 그대로 새기 때문에, "x좌표나 y좌표가 0 인 점은 축 위에 놓이니 따로 살펴봐요" 로 바꿨어요.

## 남은 경고 1건

`V3 m1-u05-t02-08 원자 "② $a 0$" 가 지면 정답 "a &lt; 0, b &gt; 0" 에 없음`

- **원본 추출값이 깨진 경우예요.** 원본 앱의 정답 문자열이 `② $a < 0, b > 0$` 인데,
  추출기의 태그 제거(`<[^>]+>`)가 `< 0, b >` 를 태그로 보고 지워서 `② $a 0$` 만 남았어요.
- `answer_atoms` 는 규칙대로 **손대지 않았고**, 지면 정답은 원본 해설(제2사분면 = x 음수, y 양수)과 일치해요.
- 도구를 고치는 대신 보고만 해요. 고친다면 `extract_gen_ac.py` 의 태그 제거를 `<[a-zA-Z/!][^>]*>` 로 좁히면 돼요.
  (같은 증상이 부등식을 정답으로 갖는 다른 단원에도 있을 수 있어요.)

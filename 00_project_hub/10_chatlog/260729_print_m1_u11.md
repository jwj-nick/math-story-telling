## 지면화에서 한 일

- 원본 63문항이 **전부 4지선다**였어요. 종이에서는 찍기가 되므로 **모두 단답형으로 재작성**했어요.
- 답의 형태를 못 박았어요 — 다면체 이름은 `‘정○면체’ 꼴로`, 면·모서리·꼭짓점은 `수로 (개수)` + `answer_unit: "개"`,
  회전체 단면은 `‘원 / 직사각형 / 사다리꼴’ 처럼 도형 이름으로`.
- 화면에서 입체를 돌려 보고 답하던 문항은 **도형의 이름·면의 모양·개수를 글로 주는** 형태로 바꿨어요.
  (예: 원본 "아래 입체도형의 면의 수는?" → "아래 그림은 **삼각기둥**이에요. 이 삼각기둥의 면의 수를 구하시오.")
- KaTeX → HTML. `$V - E + F = 2$` → `v − e + f = 2` (빼기 U+2212), `$\dfrac{r}{l}$` → CSS 세로분수,
  `$2\sqrt{5}$` → `2√5` (overline span). 원본 SVG 4개는 `figure` 에 그대로 실었어요.

## ⚠️ 도구 문제 2건 (고치지 않고 보고만 — 병렬 배치 중)

**① `extract_gen_ac.py` 의 `idx` 가 난이도마다 1 로 되돌아가요 → 세대 A 에서 V1/V2 가 무력해져요.**

`parse_gen_a` 는 `idx` 를 앱의 `q-num` (L 1,2,3 / M 1,2,3 / H 1,2,3) 으로 넣어요.
`verify_bank.re_extract` 는 `m[(유형no, idx)] = atoms` 로 맵을 만드는데, 유형마다 키가 3개뿐이라
**63문항이 21개로 덮여 써져요** (뒤에 오는 H 가 L·M 을 덮음).
그 결과 은행이 아무리 정확해도 V1 1건 + V2 63건 = **오류 64건이 구조적으로 발생**해요.
중2(세대 D)는 유형당 3문항이라 이 충돌이 안 나서 지금까지 안 드러났어요.

- **한 줄 고침:** `extract_gen_ac.py` 86행 `'idx': int(num.group(1)) if num else len(problems) + 1,`
  → `'idx': len(problems) + 1,` (유형 안에서 1~9 로 연속 부여)
- **검증:** 스크래치에 도구 사본을 떠서 이 한 줄만 고쳐 돌린 결과
  → `V1 문항 수 일치: 63 · 오류 0 · 경고 56`. 즉 **은행 자체는 완전히 통과**해요.
- 세대 A 를 쓰는 중1 07~12 단원이 전부 같은 증상일 거예요. 배치가 끝난 뒤 한 번에 고치는 게 좋아요.

**② `build_sheet.select_problems` 의 mock 뽑기가 난이도를 섞지 못해요.**

`ps = sorted(문항, key=난이도순서)` 뒤 `ps[:per_type]` 라서 **가장 쉬운 쪽에서 앞에서부터 per_type 개**만 나와요.
"유형마다 L 1개 + M 1개" 같은 조합이 표현되지 않아요. 그래서 이번 mock 은 이렇게 잡았어요.

| 회차 | 실제 구성 | 원래 의도 |
|---|---|---|
| `mockA` | 7유형 × **L 2문항** = 14문항 | 7유형 × L·M |
| `mockB` | 7유형 × **M 2문항** = 14문항 | 7유형 × M·H |

- H 문항은 유형별 회차(`t1~t7`)에 다 들어 있어서 빠지지는 않아요.
- 고치려면 `pick` 에 `levels` 를 "각 난이도에서 몇 개씩" 으로 해석하는 분기를 넣으면 돼요.

## 남은 경고 56건 — 왜 0 이 될 수 없나

V3 는 `answer_atoms` 가 `answer_print` 안에 들어 있는지 봐요. 그런데 세대 A 의 원자는
**앱 화면의 정답 표시 그대로** 라서 `③ 원기둥` 처럼 선택지 번호가 붙거나 `$36$` 처럼 KaTeX 를 품고 있어요.

- 선택지 번호 — 단답형으로 재작성했으니 지면 정답에 `③` 을 넣을 수 없어요.
- KaTeX — **V4 가 `answer_print` 안의 `$` 를 오류로 잡아요.** 즉 V3 를 만족시키면 V4 가 터져요.

그래서 세대 A + 단답형 재작성에서는 V3 경고가 구조적으로 남아요.
V3 도 이 경우를 `(수식·서술형 — 사람이 확인)` 이라고 표시하고 넘겨요. **56건 전부 눈으로 대조했고 수학은 일치해요.**

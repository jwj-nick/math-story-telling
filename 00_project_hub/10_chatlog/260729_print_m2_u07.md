## 지면화에서 한 일

- 추출 `types=6 problems=18 atoms=18 choice2=5 unmatched=0`.
- **2지선다 5문항을 단답형으로 재작성**했어요. 종이에서 O/X 는 찍으면 절반이 맞으니 **이름을 쓰게** 바꿨어요.
  - `외심은 세 변의 수직이등분선이 만나는 점일까요? (맞아요/아니에요)`
    → `삼각형의 세 변의 수직이등분선은 한 점에서 만난다. 이 점을 무엇이라 하는지 이름을 쓰시오.`
  - `두 각이 55°, 55°인 삼각형은 이등변삼각형일까요?` → `… 어떤 삼각형인지 그 이름을 쓰시오.`
- **도형 의존 문항은 변·각 조건을 발문에 글로** 줬어요.
  `외심 O에서 OA = 5일 때 OB는?` → `삼각형 ABC의 외심을 O라 하자. 선분 OA의 길이가 5 cm일 때, 선분 OB의 길이를 구하시오.`
  겹선(overline) 은 인쇄에서 밀려 나오므로 **`선분 OA` 처럼 우리말**로 썼어요 (PRINT_PRINCIPLES §8-5).
- 단위를 못 박았어요 — 각도 `answer_unit: "°"`, 길이 `"cm"`. 낱말 답은 `answer_format` 에 `(단위 없음)` 명시.
- 기호는 전부 유니코드(`∠`, `⊥`, `−`). KaTeX 잔재 0.
- 난이도 배분은 유형마다 **L 1 · M 2** 로 잡아 mock 의 `quota {"L":1,"M":1}` 가 유형당 정확히 2문항을 뽑도록 했어요.

## 오개념 15개

세 각의 합 3개(합=360° 착각 / 한 각만 빼기 / 직각 빼먹기), 이등변 5개(꼭지각↔밑각 / 꼭지각을 그냥 반 나누기 /
밑각을 한 번만 빼기 / **변↔각 방향(역)** / **꼭지각 이등분선이 밑변을 수직이등분함을 놓침**),
외심·내심 7개(**변의 수직이등분선 vs 각의 이등분선 혼동** / 거리의 대상(꼭짓점 vs 변) /
**∠BOC = 2∠A 와 ∠BIC = 90° + ∠A의 반 혼동** / **직각삼각형 외심 = 빗변의 중점** / 접선⊥반지름 /
반지름↔지름 / 외심이 항상 안에 있다고 믿음).

## 경고 3건 — 왜 0 이 될 수 없나

V3 는 `answer_atoms`(원본 선택지 텍스트) 가 지면 정답 안에 있는지 봐요. 2지선다를 단답형으로 바꾸면
원자 `맞아요` · `이등변이에요` 는 지면 정답(`외심 (외접원의 중심)`, `이등변삼각형`) 에 문자로 남을 수 없어요.

| 문항 | 원자 | 지면 정답 | 눈 대조 |
|---|---|---|---|
| t03-02 | `이등변이에요` | `이등변삼각형` | 같은 뜻 ✓ |
| t04-02 | `맞아요` | `외심 (외접원의 중심)` | 원본이 "외심 = 세 변의 수직이등분선 교점" 을 맞다고 한 것 ✓ |

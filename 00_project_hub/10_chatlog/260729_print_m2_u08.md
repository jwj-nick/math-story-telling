- **2지선다 5문항을 단답형으로 재작성**했어요.
  - `평행사변형의 두 대각선은 서로 이등분할까요? (이등분해요/아니에요)`
    → `평행사변형의 두 대각선이 서로에 대해 하는 일을 '서로 ~해요' 형태의 한 문장으로 쓰시오.`
  - `직사각형의 두 대각선은 길이가 같을까요? (같아요/달라요)`
    → `직사각형의 두 대각선의 길이를 서로 비교하면 어떠한지 … 한 문장으로 쓰시오.`
  - `네 각이 모두 90°인 평행사변형은? (직사각형/마름모)`
    → `네 각의 크기가 모두 90° 인 평행사변형을 무엇이라 하는지 이름을 쓰시오.`
    `answer_format` 에 **`'평행사변형 / 직사각형 / 마름모 / 정사각형' 중 하나로`** 를 못 박아 답의 형태를 고정했어요.
- **도형 의존 문항은 꼭짓점·교점 이름을 발문에 글로** 줬어요. 종이엔 그림이 없으니까요.
  `대각선 AC = 8, 교점 M일 때 AM은?`
  → `평행사변형 ABCD 에서 두 대각선 AC 와 BD 의 교점을 M 이라 하자. AC = 8 cm 일 때, AM 의 길이를 구하시오.`
- 단위를 못 박았어요 — 각도 `answer_unit: "°"`, 길이 `"cm"`. 낱말·문장 답은 `answer_format` 에 `(단위 없음)` 명시.
- 기호는 전부 유니코드(`∠`, `△`, `≡`, `−`). KaTeX 잔재 0.
- 난이도 배분은 유형마다 **L 을 최소 1개, M 을 최소 1개** 두어 mock 의 `quota {"L":1,"M":1}` 가
  유형당 정확히 2문항(총 12문항, L 6 + M 6)을 뽑도록 했어요. 유형6만 `M / H / L` 로 H 를 하나 넣었어요.

## 경고 0 — 이번엔 왜 0 이 됐나

정답 원자가 낱말(`같아요`·`이등분해요`)인 5문항에서, **지면 정답을 원자를 품는 더 긴 문장으로** 썼어요.
`같아요` → `두 대각선의 길이는 같아요`, `이등분해요` → `서로 이등분해요`.
V3(원자 포함)를 자연히 통과하면서, V5(정답 누출)에서는 **누출 판정 문자열이 길어져 오탐이 사라지는** 부수 효과가 있어요.
단원7 기록의 "뜻을 덧붙여 쓰기" 요령을 문장형 답으로 확장한 셈이에요.

반대로 `직사각형`·`정사각형` 처럼 더 늘일 수 없는 낱말 정답은, 그 문항에 붙은 카드 본문에서
그 낱말을 **아예 쓰지 않고** 조건을 말로 풀어 썼어요 (`네 각이 모두 직각이면서 네 변도 모두 같은 도형`).
숫자 정답도 같은 함정이 있어요 — 정답 `80` 은 카드에 `180` 만 써도 누출로 잡혀요.
그래서 **각의 합 관련 카드는 아라비아 숫자를 아예 쓰지 않고** `삼백육십`·`삼각형 하나의 각의 합을 두 배` 로 썼어요.

## 지면화 중 잡은 콘텐츠 문제 1건

유형6 원리 상자가 처음엔 `각 조건→직사각형, 변 조건→마름모, 둘 다→정사각형` 이라는 **대응표 자체**여서,
같은 유형의 문항 2개(7번·8번)가 상자 베끼기로 전락했어요.
→ 원리 상자를 **판별 방법**(조건이 각에 대한 것인지 변에 대한 것인지 먼저 가르기)으로 바꿔 답을 회수했어요.
유형1~5 는 원리 상자를 그대로 뒀어요. 숫자 문항의 발판이 필요하고,
말로 쓰는 문항은 mock(원리 상자 없음)에서 어차피 맨몸으로 다시 나와요.

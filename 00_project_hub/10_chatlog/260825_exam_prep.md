### 2. "시험대비" 렌즈로 본 갭 — 5가지

- **G1. 범위형 시험이 없다.** 실제 시험은 여러 단원 묶음 범위(예: 2학기 중간 ≈ u7~9)인데, 현재 회차는 전부 단원 단위. 시험 직전 "범위 전체를 섞어서 리허설"할 도구가 없음. **가장 큰 갭.**
- **G2. 실전 난이도 분포의 모의고사가 없다.** 현재 mock = H only → 이건 "심화 훈련"이지 "실전 리허설"이 아님. 실제 시험은 기본~중 60~70% + 중상 20~30% + 상 ~10%. 우선순위 (b) "기본 문제는 시험에서 풀 수 있도록"과 정확히 맞는 건 이 분포 쪽.
- **G3. 실전 형식이 아니다.** 학교 시험 = 객관식(5지선다) 다수 + 단답 + 서술형, 배점 합 100점, 45분. 현재 bank는 전부 단답 입력형이라 객관식 기술(보기 소거·함정 보기 피하기)과 시간 감각이 훈련 안 됨.
- **G4. 서술형 대비가 없다.** 풀이 과정을 쓰고 부분점수를 받는 훈련. **딸은 국어·영어 강세 → 서술형은 오히려 잠재 득점원**(수학 중하위 학생이 서술형에서 과정 점수를 챙기는 전략은 실효가 큼).
- **G5. 오답 리사이클이 없다.** 프린트를 채점한 뒤 틀린 문제만 모아 다시 보는 장치가 없음. 오개념 카탈로그·오답진단표라는 자산이 이미 있는데 "다음 행동"으로 이어지지 않음.

### 3. 시기 감각

오늘 2026-08-25. 통상 2학기 중간고사는 **10월 초·중순(D-40~50)**, 기말은 12월 초·중순. 중1 1학기는 자유학기제로 시험이 없었을 가능성이 크고, 2학기 중간 범위는 대략 u7(기본도형)~u9(다각형) 부근일 것으로 추정 — **학교 공지·진도 확인 필요(Q1)**. 이 일정이면 9월 = 범위 단원 학습 + 유형세트, 시험 2주 전 = 범위형 모의고사 리허설이 자연스러운 배치.

### 4. 제안 — 시험대비 레이어 4개 (우선순위 순)

- **P1. 범위형 실전 모의고사 (프린트, 최우선).** 시험 범위(예: u7~9) × 2~3회차. 회차 구성 예: 20문항 = L8 + M9 + H3, 단원별 quota 배분, 배점·45분 표기, 문제지+해답묶음+오답진단표. 기존 bank 364문항 재조합이 뼈대(신규 저작 최소화 가능), `build_sheet.py`를 **다단원 bank 로드 + 단원별 quota**로 확장(현재 단원 단위 → cross-unit). 심화 모의고사 때 확립한 mock+quota 체계의 자연 연장.
- **P2. 서술형 전용 세트.** 시험 범위 단원당 2~3문항 신규 저작. 풀이 칸을 크게 + **채점기준표(부분점수 단계)**를 해설지에 명시 — "어디까지 쓰면 몇 점"을 보여주는 게 핵심. 딸의 언어 강점을 수학 득점으로 연결하는 축.
- **P3. 오답 재시험 회차.** 채점 후 틀린 문항 id 리스트만 주면 → 그 문항 + 같은 유형의 다른 레벨 문항을 묶은 맞춤 재시험 PDF 생성. 파이프라인 소확장(config에 id 명시 선택 추가). 시험 2주 전 루프: 모의고사 → 채점 → 오답 재시험 → 재채점.
- **P4. (보조) 앱 실전 모드.** 타이머 + 범위 선택 랜덤 세트. 단, **딸이 앱에서 문제 풀기를 싫어함(2026-07-28 프린트 전환의 이유)** → 프린트가 본선, 앱은 가볍게 오답 복습용 정도로만. 우선순위 낮음.

### 5. 객관식을 어디까지 만들 것인가 (P1의 핵심 결정)

실제 시험은 객관식 위주인데 현재 bank는 전부 단답형. 선택지:

| 안 | 내용 | 저작 비용 | 실전감 |
|---|---|---|---|
| (a) | 기존 단답형 그대로 재조합만 | 최소 | 중 — 수학 실력 리허설은 됨, 형식 리허설은 안 됨 |
| (b) | **회차당 객관식 5~8문항만 신규**(함정 보기는 오개념 카탈로그에서 도출) + 나머지 단답 재조합 | 중 | 상 — NCC 추천. 오개념 카드가 이미 있어 "그럴듯한 오답 보기" 저작이 싸다 |
| (c) | 실제 시험 판박이(객관식 15+ 서술형 3~5 전면 신규) | 최대 | 최상 |

### 1. 조사 결과 — 실제 중1 수학 시험이 어떻게 생겼나

- **① 자유학기제 → 시험이 2학기에 몰린다.** 2025-08 보도 기준 전국 중학교 10곳 중 8곳이 1학기 중간·기말을 아예 안 침. 일부 학교는 2학기 시험에 1년치 범위를 몰아넣음 — **Nick의 "기말고사만 + 중1 전체 범위" 설정이 실제 관행과 정확히 부합.** (출처: 다음뉴스 2025-08-01 기사)
- **② 2026년부터 지필평가 안에 논술형 30% 이상이 의무.** 경기교육청 2026 학업성적관리 시행지침 개정 — 중·고 지필평가(중간·기말)에 논술형 문항을 포함하고 교과별 학기당 논술형 평가 비율 30% 이상(중학교 기존 40%에서 조정). → **서술형 대비는 선택이 아니라 배점 구조상 필수. 시험지의 약 1/3이 "과정 점수".** Round 1의 P2(서술형=딸의 잠재 득점원) 판단이 정책적으로도 뒷받침됨. (출처: 서울신문 2026-02-23)
- **③ 문제지 통례** (기출문제집·학교 문제지 관행): 총 20~25문항 = 선택형(5지선다) 15~18 + 서술형 4~7, 100점 만점, 45분. 서술형은 문항당 5~8점에 단계별 부분점수.
- **④ 웹에서 언급되는 2학기 빈출 포인트** — 다각형 대각선(n−3), 평행선과 각, 부채꼴 호의 길이·넓이, 원뿔·원기둥 겉넓이, 도수분포표·히스토그램·상대도수 — **우리 `meta.json` 7유형×13단원 목록과 일치**(교과서 유래이므로 당연). 자체 유형 목록을 빈출 기준으로 그대로 써도 됨.
- **한계**: 실제 학교 문제지 원문은 원격 열람 불가(Scribd 미리보기 차단, kimsu.kr 접속 거부 등). 나중에 딸 학교 기출을 종이로 구하게 되면 figcrop으로 형식을 재보정하는 게 가장 정확 — 필수는 아님.

### 2. 확정 설계 — "중1 전범위 실전 기말 모의고사" (프린트)

| 항목 | 설계 | 근거 |
|---|---|---|
| 형식 | **22문항 · 100점 · 45분** = 선택형 15(52점) + 단답형 3(12점) + 서술형 4(36점) | 조사 ②③ — 서술형 배점 ~1/3 |
| 난이도 | L 40% · M 45% · H 15% | 우선순위 (b) 기본 실전력 + 실제 분포 |

### 4. 남은 결정 (Q5~Q6)

- **Q5.** 종합 3회(A/B/C)로 시작하는 규모가 적당할까요? 회차당 신규 저작이 선택형 8 + 서술형 4라서, 3회면 신규 36문항입니다(병렬 에이전트로 1~2세션 규모).
- **Q6.** 착수 방식은 어느 쪽이 좋을까요 — (i) 바로 3회 양산 vs **(ii) 1회차(A)만 프로토타입으로 만들어 Nick이 PDF 육안 검토 후 B/C 양산 (NCC 추천)**. 선택형 렌더와 서술형 채점기준표가 이 프로젝트 처음 만드는 형식이라, 1회 검수를 거치는 쪽이 안전합니다.

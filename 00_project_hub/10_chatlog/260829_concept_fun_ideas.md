### 2. 딸 프로필에서 나오는 설계 원칙 3개

LEARNER_PROFILE 기준 — 감성적·공감형·글쓰기 강점·서사 친화, 수학 중하위, "잘하고 싶다"는 내적 동기, **스트레스 없는 진행이 핵심 KPI**.

- **원칙 ①: 보상은 "맞혔다"보다 "끝까지 해냈다·이해했다"에.** 정답률이 높지 않은 아이에게 정답 중심 화려함은 오히려 오답의 대비를 키운다. 큰 효과는 완주·탐구 순간에, 정답에는 작은 손맛만.
- **원칙 ②: 화려함은 순간, 아기자기함은 상시.** 내성적 성향 + 반복 학습 도구 → 매번 터지는 효과는 3일이면 피로. 첫 진입·완주에만 화려하게, 평소엔 조용히 귀엽게.
- **원칙 ③: 언어·서사 강점을 재미 통로로.** 수학 앱이지만 "글 쓰는 재미", "인물이 말 거는 재미"가 이 아이에겐 숫자보다 강한 동기가 될 가능성이 크다.

### 3. 아이디어

#### A. 화려하게 — 큰 순간 (단원당 1~2번만 터지는 것)

- **A1. 완주 도장 + 꽃가루** — 이미 있는 `.stamp` 도장 애니와 `.pg-confetti`를 개념 페이지의 완주 노트에 연결. 꽃가루 색은 단원 시그니처 색 2종. **비용 최소(놀이터 코드 재사용), 효과 확실.**
- **A2. "와" 전환점 이벤트** — 직접 움직여 봐요에서 개념의 핵심 전환이 일어나는 값에 닿는 순간만 짧은 반짝임. 예: u6에서 a가 0을 지나 음수로 넘어가는 순간 그래프가 반대 사분면으로 넘어가며 0.4초 펄스 + "부호가 바뀌면 방향이 바뀌어요" 말풍선. u5는 점이 사분면 경계를 넘을 때, u1은 슬라이더가 소수에 멈출 때. **개념 포인트 = 시각 이벤트**로 묶는 게 핵심. 단원마다 1개씩 정의(13개).
- **A3. 단원 첫 진입 인트로(0.8초)** — 히어로 그라데이션이 커튼처럼 열리며 단원 인물 실루엣(영상 자산 재사용)이 스쳐감. **첫 방문 1회만**(localStorage) — 반복 피로 방지. 화려하지만 방해 안 됨.
- **A4. 13단원 별자리 지도** — 홈에서 완료 단원이 별로 켜지고 선으로 이어짐(수학 지도 자산과 연결). 전 단원 완주 시 큰 애니 1회. 장기 동기.

#### B. 소소하게 — 매 상호작용의 손맛

- **B1. 정답 마이크로 애니** — 입력칸 초록 테두리 펄스 + 작은 ✓가 톡 튀어오름 + 진행바 새 칸이 살짝 부풂. 오답은 **흔들림 없이**(스트레스 KPI) 노란 테두리 + "다시 한 번?" 톤. 텍스트 한 줄이 반응으로 바뀐다.
- **B2. 오답 → 정답 즉시 공개 대신 힌트 1단계** — 이미 있는 `hintSteps` 활용. 첫 오답엔 힌트, 두 번째 오답에 정답. "맞힐 기회 한 번 더" = 자기효능감 보호. (원칙 ①과 직결)
- **B3. 진행바 칸에 이름** — 5칸이 각각 뭘 뜻하는지 탭하면 툴팁("정비례 확인 ✓ / 직접 움직여봄 ✓ …"). 완료 칸에 작은 아이콘. "8개 중 몇 개 했다"가 손에 잡힘.
- **B4. 섹션 번호 → ✓ 전환** — 섹션 끝내면 eyebrow 동그라미 번호가 체크로 바뀌며 색 채움. 스크롤 올려보면 내가 지나온 길이 보임.
- **B5. 리빌 변주** — 직접 움직여 봐요는 왼쪽에서, 내 말로는 살짝 확대되며, 나머지는 지금처럼. 미세한 리듬만 줘도 "다음 섹션이 궁금"해짐.
- **B6. 이어하기** — 재방문 시 "지난번 3번까지 했어요 — 여기서 이어갈까요?" 배너 + 탭하면 스크롤. "나를 기억해 준다"는 느낌.
- **B7. 소리(선택)** — 정답 '띵', 완주 짧은 팡파레. 기본 OFF + 토글. 감성형에게 소리는 강한 보상이지만 학교·공공장소 고려.

#### C. 아기자기하게 — 캐릭터·수집·꾸미기

- **C1. 단원 인물 미니 아바타 말풍선** — 각 단원 인물(에라토스테네스·브라마굽타·알콰리즈미·디오판토스·데카르트·케플러…)이 섹션 옆 작은 아바타로 한 줄씩 말을 건다. 예: u6 섹션4 옆 케플러 "나도 행성 속도 계산할 때 이 규칙 덕을 봤어요". 영상 파이프라인의 캐릭터 이미지 자산 재사용 가능. **서사 친화형 아이에게 가장 효과적일 것으로 예상.**
- **C2. 스티커북** — 섹션·단원 완료마다 SVG 스티커 획득(체·저울·좌표 파리·쌍곡선·정다면체…), 홈에 스티커북. 13단원 × 2~3개. 수집은 소소한 지속 동기.
- **C3. "내 수학 노트"** — 내 말로에 쓴 글을 localStorage에 모아 홈에서 "내가 쓴 설명 모음"으로 열람·인쇄. **글쓰기 강점을 수학 자산으로 바꿔주는 장치** — 13단원 다 쓰면 자기 손으로 만든 중1 수학 해설집이 됨. (원칙 ③ 핵심)
- **C4. 바탕 테마 고르기** — 라이트/다크 2종 → 벚꽃·민트·밤하늘·종이 등 3~4 팔레트. CSS 변수가 이미 토큰화돼 있어 비용 낮음. **딸이 직접 고르는 첫 "내 앱" 경험** = 프로젝트 우선순위 (c) "AI로 직접 만드는 경험"의 자연스러운 입구.
- **C5. 마스코트 반응** — 슬라이더를 a=0 같은 금지값에 두면 아바타가 놀라며 "0은 비례상수가 될 수 없어요!" — 귀여움과 개념 포인트를 한 번에.
- **C6. 오늘의 한 줄** — 진입 시 인물 명언 각색 한 줄(해요체), 날짜 seed로 하루 1개 고정.

## Round 0 — 요청 정리 + 설계안 제안 (2026-09-02)

### Nick 요청 정리
- 속력·거리·시간 문제를 **완전히 이해 못함** — 완전 스페셜 특강, A to Z, "이해할 수밖에 없도록"
- 매우 친절히, 기본개념부터 완벽하게
- 비주얼라이즈 생각해서
- 다양한 예제·문제, "함께 생각하기" 등
- 구체 아이디어 + 배치 위치

### 왜 안 되는지 (현재 상태 확인)
`p4.html` 유형7을 보면 문제 3개 앞에 "거리=속력×시간... 단위를 통일해요" 팁 한 줄만 있고 바로 혼합 문제(왕복+반대방향 동시출발)로 들어간다. **공식을 왜 그런지 유도해준 적도, 표(table)로 정리하는 법을 가르친 적도, 상황을 그림으로 보여준 적도 없다.** 이 유형만 따로 떼어 처음부터 완전히 다시 가르쳐야 한다.

### 설계안 — 7단계 롱폼 특강 페이지

한 페이지 안에서 스크롤하며 순서대로 쌓아가는 구조(기존 개념 페이지의 reveal-on-scroll 패턴 재사용). 각 단계는 "왜?"부터 시작하고 공식은 마지막에 정리만 한다.

1. **도입 — 공감 먼저**: "이 문제만 보면 머리가 하얘지나요? 그럴 만해요 — 순서만 알면 하나도 안 어려워요." 목표 제시.
2. **속력 감 잡기(공식 없이)**: 친숙한 기준(걷기 시속 4km, 자전거 15km, KTX 300km)을 나란히 놓고 "1시간 뒤 어디까지 가나" 애니메이션(슬라이더로 시간을 움직이면 각자 이동한 거리가 실시간으로 늘어나는 타임라인 — `makeNumberLine`류 헬퍼 확장). "속력 = 1시간 동안 얼마나 갔는지"를 말로 먼저 박아넣는다.
3. **공식은 외우는 게 아니라 읽는 것**: "시속 60km"를 "1시간에 60km"로 풀어 읽는 연습 → 거리=속력×시간이 왜 곱셈인지 스스로 말해보기(함께 생각하기 ①). 나머지 두 공식(속력=거리÷시간, 시간=거리÷속력)도 "친구가 2시간에 8km 걸었으면 1시간엔?" 같은 구체 상황에서 유도. 삼각형 암기법은 맨 끝에 "치트시트"로만 보너스 제공.
4. **표(테이블) 세우기 — 핵심 도구**: 거리·속력·시간 3열 표를 빈칸으로 주고 채우는 인터랙티브 위젯. "아는 값은 파란색, 구하는 값은 빨간 물음표"로 색 구분. 이후 모든 유형에서 이 표를 계속 재사용.
5. **유형별 완전정복(우선순위 4개)** — 각 유형마다 그림(SVG로 두 사람/두 지점을 실제로 움직이는 다이어그램) → 표 채우기 → 식 세우기 → 풀이 → "함께 생각하기"(숫자만 바꾼 문제, 표 빈칸을 직접 채우게):
   - ① 기본형(공식 대입)
   - ② 왕복형(갈 때·올 때 속력 다름, 총 시간 주어짐) — 지금 p4.html에 있는 유형
   - ③ 따라잡기형(먼저 출발 → 나중에 출발해서 따라잡기) — "만난다 = 이동 거리가 같다"로 번역
   - ④ 마주보기형(양쪽에서 동시 출발해서 만나기) — "만난다 = 두 사람 거리의 합 = 전체 거리"로 번역
   (기차/터널형은 중1 범위에서 우선순위 낮음 — 뺌)
6. **실전 총정리**: 유형 섞어서 5문제 자가진단 — 틀리면 "이건 ③ 따라잡기형이에요, 다시 볼까요?" 하고 해당 섹션으로 스크롤.
7. **마무리 치트시트**: 표 도구 + 삼각형 암기법 + 4유형 한 줄 요약 카드(인쇄해서 책상에 붙여도 될 정도로 압축).

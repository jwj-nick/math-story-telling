# 특강 주제 탐색 — 중1·2·3 + 고등(2028 수능 체제)

> "속력·거리·시간 완전정복"처럼 단원 밖에서 A to Z로 다시 가르칠 가치가 있는 주제가 얼마나 되는가.
> 중등 = 딸(세은) 기준, 고등 = 2028 수능 체제 기준(직접 확인함).

---

## Round 0 — 탐색 결과 (2026-09-02)

### 0. 먼저 — "특강감"의 기준

속력 특강이 성립한 이유를 일반화하면, 특강으로 뗄 가치가 있는 주제는 아래 중 3개 이상을 만족한다:

1. **여러 단원·여러 학년을 관통** — 단원 페이지 하나에 담으면 반드시 어딘가에서 잘린다.
2. **"한 줄 팁 + 문제"로는 절대 안 되는 주제** — 공식 암기가 아니라 개념 빌드업이 필요.
3. **시각화·인터랙션이 결정적** — 그림이 있으면 이해가 확 바뀌는 종류.
4. **관찰된 약점과 직결** — 세은: 절차 유창성 부족, 말→식 번역 어려움, 표기 리터러시(y=a/x 사건).

반대로, 이 기준을 못 넘는 건 특강이 아니라 **스피드 드릴 챕터**(자동화가 목적) 또는 **단원 보강**(그 단원 안 이야기)으로 처리하는 게 맞다.

### 1. 중1·2·3 특강 후보 — 실질 특강감 9개 (+ 흡수 가능 3개)

#### 티어 1 — 세은 약점 직결, 지금 바로 효과 (4개)

| # | 특강 | 이유 |
|---|---|---|
| 1 | **소금물 농도 완전정복** | 속력 특강의 쌍둥이. 방정식 활용 2대 장벽(속력·농도) 중 남은 하나. "%는 전체 중 소금의 비율"을 비커 그림·물 붓기 애니메이션으로. 중1 일차방정식 → 중2 연립방정식에서 그대로 재등장하므로 지금 잡으면 2년 쓴다. |
| 2 | **비율·퍼센트 감각 리셋** | 농도·정비례·닮음·확률·정가할인 전부의 공통 뿌리. 초등 결손이 남아 있으면 위의 모든 특강이 모래 위에 선다. "30%란 100칸 중 30칸" 수준부터 시각적으로 재건축. |
| 3 | **분수·음수 계산 리셋** | 통분·약분·분수 나눗셈·부호 규칙 = 모든 계산 실수의 근원. 절차 유창성 부족이 관찰된 만큼 개연성 높음. 특강(왜 그런지 1회) + 스피드 드릴 신규 챕터(자동화) 하이브리드가 적격. |
| 4 | **함수란 무엇인가** | y=a/x에 a=−2를 못 넣은 사건의 근본 치료. 중1 정비례·반비례 → 중2 일차함수 → 중3 이차함수를 관통하는 최장수 개념. "함수 = 넣으면 나오는 상자" + 표↔그래프↔식 3표상 번역 훈련. |

#### 티어 2 — 중2·중3 진입 대비 (5개)

| # | 특강 | 이유 |
|---|---|---|
| 5 | **기울기 완전정복** | 중2 일차함수의 심장. "오른쪽 1칸 갈 때 몇 칸 오르나". 사실 속력과 같은 개념(변화율)임을 연결하면 특강끼리 서로 강화. 고교 미분의 예고편이기도 함. |
| 6 | **경우의 수 세는 법** | 중2 확률 진입 장벽. 감으로 세다 실패하는 전형 단원. 나열 → 수형도 → 곱셈원리 순서로, 수형도가 자라나는 애니메이션이 결정적. |
| 7 | **인수분해·전개 스피드 완성** | 중3의 관문이자 고교 전체의 기초 체력. 이게 느리면 이차방정식·이차함수·고1 다항식이 전부 느려진다. 곱셈공식의 넓이 그림(직사각형 분할) 특강 + 드릴 챕터 하이브리드. |
| 8 | **제곱근·무리수 감 잡기** | 중3 도입부. √2를 "넓이 2인 정사각형의 한 변"으로 — 수직선 위에 실제로 찍어보는 시각화. 기호 공포(축 C)와 개념이 동시에 걸리는 지점. |
| 9 | **도형 각도 추적** | 평행선 엇각·동위각, 삼각형 외각, 이등변 표시를 "그림에 마킹하며 추적하는 습관"으로. 단, 세은의 도형 데이터가 아직 없음 — 중1 2학기 반응 관찰 후 착수 여부 결정. |

#### 티어 3 — 독립 특강 불필요, 흡수·통합 (3개)

- **단위 환산** (km↔m, 시↔분, 넓이·부피 단위) → 속력 특강 부록 + 각 특강 안에서 소화.
- **수학 기호 읽는 법** → 특강이라기보다 축 C(literacy 트랙)의 산출물. 기존 트랙에서 처리.
- **방정식 활용 번역 전반** (나이·개수·일 문제) → 스피드 드릴 ②(식 세우기)의 확장 챕터로.

**결론: 중등은 9개가 실질 특강감.** 전부 만들 필요는 없고, 딸의 진도·반응을 보며 티어 1부터. 바로 다음 1순위는 **농도**(속력과 완벽한 세트, 시험에도 세트로 나옴).

### 2. 고등 특강 후보 — 2028 수능 체제 (직접 확인)

- **2028 수능 수학 = 선택과목 폐지, 공통 출제**: **대수(11문항) + 미적분Ⅰ(11문항) + 확률과 통계(8문항)**. 미적분Ⅱ·기하는 수능에서 제외. Nick의 추정("대수/미적분/확통")이 정확했음.

### 3. 관통 설계 자산 — 특강이 서로를 강화하는 지점

- **변화율 3부작**: 속력(중1, 완성) → 기울기(중2) → 미분(고2). 같은 그림이 3번 진화.
- **세기 3부작**: 경우의 수(중2) → 순열·조합(고1~) → 확률(고2).
- **번역 시리즈**: 말→식(스피드 드릴 ②) → 농도·속력(특강) → 표↔그래프↔식(함수 특강).
- 이 연결 자체가 "학원 인강과 다른 점"이 된다 — 특강끼리 앵커 링크로 상호 참조.

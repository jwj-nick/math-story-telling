### 3. 이 특강의 성격 — 기존 16개와 다르다

지금까지의 특강 16개는 대부분 **"절차를 다시 세우는 특강"**이었다(속력·농도·계산 리셋·인수분해…). 이번은 성격이 다르다.

- **축 C(수학 언어) 특강** — 기호가 아니라 **낱말**이 장벽인 첫 사례. `y=a/x` 사건이 표기 리터러시였다면, 이번은 어휘 리터러시다.
- **축 B(흥미) 특강** — "이걸 왜 배우나"에 정면으로 답하는 첫 특강.

특강감 기준(Round 0 §0) 대조: ①여러 학년 관통 ○(중1→중3→고2) ②한 줄 팁으로 안 됨 ○ ③시각화 결정적 ○(분포의 변신·정규분포로 가는 다리) ④관찰된 약점 직결 ○(국어 강점을 못 쓰는 상태). **네 기준을 모두 만족한다.**

### 4. 제안하는 구조 — `data-mastery.html` (중1 앱)

표준 7단계를 이 주제에 맞게 변형한다. 색은 자료·통계 느낌의 청록(`--dt:#3f8f7a` 후보).

**① 도입 — "몰라서 못 푸는 게 아니라, 말이 낯설어서예요"**
문제는 읽었는데 무슨 말인지 모르겠던 경험에 공감. 이 단원 용어 10개를 먼저 보여 주고 "이 중 뜻을 자신 있게 말할 수 있는 게 몇 개인가요?" 자가 점검.

**② 용어 해부실 — 이 특강의 심장 (카드 뒤집기 위젯)**
용어마다 카드 한 장, 뒤집으면 네 칸이 나온다: **한자·어원 / 일상에서 만나는 같은 말 / 수학에서의 뜻 / 한 문장 예시**.

| 용어 | 해부 요지 |
|---|---|
| **도수(度數)** | 度=정도·횟수를 재는 글자(온도·각도·안경 도수·알코올 도수와 같은 글자), 數=수 → **"몇 번 나왔는지 센 횟수"**. 영어 frequency 는 **주파수**와 같은 단어다 — 라디오 주파수 = 1초에 몇 번 흔들리나, 도수 = 그 구간에 몇 개가 들어오나. |
| **계급(階級)** | 階=계단, 級=등급 → **계단처럼 나눈 구간**. 사회 시간의 '계급'과 글자는 같지만 여기서는 "몇 층 칸"이라는 뜻. 영어로는 통(bin)에 나눠 담는다고 한다. |
| **계급값** | 그 칸을 **대표하는 한 값** = (시작 + 끝) ÷ 2. 왜 필요한가 = 칸에 들어간 순간 개별 값이 사라지므로 대표를 세워야 계산이 된다. |
| **변량(變量)** | 變=변하다, 量=양 → **값마다 달라지는 그 양 하나하나**. 키를 쟀으면 키 하나하나가 변량. |
| **상대도수(相對度數)** | 相對=서로 맞대어 봄 → **전체와 견준 도수**. "몇 명"이 아니라 "전체 중 얼마". |
| **분포(分布)** | 分=나뉘어, 布=펼쳐짐 → **흩어져 있는 모양**. 도수분포표 = 도수가 어떻게 흩어졌는지 적은 표. |
| **히스토그램** | 그리스말 histos(똑바로 선 것) + gramma(그림) → **세워 놓은 막대 그림**. 막대그래프와 달리 **막대가 붙어 있는 이유**(구간이 이어져 있으니까). |
| **도수분포다각형** | 多角形 = 각이 여럿인 도형. 양 끝을 도수 0 까지 늘려야 **닫힌 도형**이 되고, 그래야 넓이가 히스토그램과 같아진다. |
| **이상·미만** | 以上 = 그 수를 **포함해** 위 / 未滿 = 아직(未) 차지(滿) 않음 → **그 수는 빼고**. "80 미만"은 80 이 아직 안 된 것. |
| **자료(資料)** | 資=밑천, 料=재료 → **판단의 재료**. 정리하기 전 = 자료, 읽어낸 뒤 = 정보. |

**③ 같은 자료, 다섯 가지 옷 (변신 애니메이션)**
원자료 15개 → 줄기와 잎 → 도수분포표 → 히스토그램 → 도수분포다각형으로 **하나의 자료가 옷을 갈아입는** 애니메이션. 단계마다 **"무엇이 남고 무엇이 사라지는가"**를 표시한다(줄기잎까지는 원래 값이 살아 있고, 도수분포표부터는 사라진다). 이 단원 전체가 한 그림에 들어오는 지도 역할.

**④ 이상·미만 경계 훈련**
수직선 위의 점을 드래그하면 어느 계급으로 떨어지는지 실시간 표시. 정확히 경계값일 때 어디로 가는지가 핵심. 시험에서 가장 자주 틀리는 자리다.

**⑤ 상대도수 = 공평한 저울**

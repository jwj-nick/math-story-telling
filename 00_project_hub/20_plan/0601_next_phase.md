## 2. 방향 해석 (NCC 1차 구조화 — Round에서 교정)

Nick의 키워드를 작업 가능한 축으로 풀면:

1. **"구분법이 중요치 않음 / 연결성 가시화"** → 지금은 *단원 경계*가 1차 구조. 다음은 **인물·개념·시대·아이디어가 단원을 가로질러 잇는 연결망**이 1차 구조. (예: 케플러가 u06·u09·u11을 관통; "극한" 사고가 u10 아르키메데스↔류후이↔u12 카발리에리↔미적분으로 이어짐.)
2. **"인물이야기를 감싼 설명이 앱에 보이도록"** → 영상은 *압축된 서사*. 그 둘레에 **왜 이 인물인지 / 시대 배경 / 개념과의 연결 / 다음 인물로의 다리**를 텍스트·도식 레이어로 펼쳐 앱에 노출. (영상=핵, 설명=후광.)
3. **"navigation app"** → 단원 목록이 아니라 **탐색 앱**: 인물 축 / 개념 축 / 시대(연표) 축 / 한-단어 축으로 들어가 서로 점프. 연결망을 *걸어다니는* 경험.
4. **"영상 더 완벽하게"** → v2 품질: 웹 재인코딩(faststart, TODO_video_deploy_encoding) + 로워서드(인물명·시대·연대) + 나라/도시 지도·시대상(TODO_video_enhancements) + 전수 재검토.
5. **"인물 추가"** → 단원당 2~3인 본격화. 옛 anim 인물(데카르트·가우스·케플러·카발리에리)을 정식 2nd 영상/이야기로 승격 + meta 조연(thales·viete·fermat·boyle·liu-hui·playfair) 제작.

## 1. 기술 통합 — 정확한 코드 지점 (실측 완료)

mid2는 사이드바 + **자동 생성 단원 내 탭바**(`.utabs`, `concept.js`의 `initChrome()`) 구조다.
탭바는 `pageInfo()`가 파일명으로 페이지 종류를 판별하고, `tabs[]` 배열로 그려진다. **새 탭 하나 추가는 이 두 곳만 건드리면 된다.**

**파일명 규약** — 기존 `u`(개념)`p`(연습)`d`/`dp`(심화)`x`(탐험)에 이어 **`g`(놀이터, game) 신설**: `g1.html`~`g11.html`.

### 1-1. `concept.js` 수정 지점 (3곳, 총 ~4줄)

```js
// ① 24행 부근 — EXPLORE_READY 옆에 신설. 단원 완성될 때마다 1 추가
var PLAY_READY={1:1};   // 파일럿은 단원1만. 2~6 완성 시 갱신

// ② pageInfo() 안, x 판별 위/아래
if(m=f.match(/^g([1-9]|1[01])$/)) return {no:+m[1],kind:'play'};

// ③ tabs 배열 — '연습' 바로 뒤에 삽입 (개념→놀이터→연습→심화탐구→심화문제→탐험 순서)
//    "먼저 흥미로 붙잡고 그다음 연습" 우선순위와 일치
if(PLAY_READY[unit.no]) tabs.splice(1,0,{k:'play',href:'g'+unit.no+'.html',i:'🎨',t:'놀이터'});
```

탭 스타일(`.ut`/`.ut-i`)은 기존 것 재사용 — 탭바 자체는 새 CSS 불필요.

### 1-2. 페이지 내부 — 재사용 가능한 `MJ` 헬퍼 (이미 있음, 새로 안 만들어도 됨)

| 헬퍼 | 용도 | 이번에 쓸 아이디어 |
|---|---|---|
| `MJ.decimalOf(n,d)` | 분수의 순환소수 전개 계산(순환마디 자동 검출) | 예언자 게임, 반복무늬 탐정 |
| `MJ.check(id,test,outId,opt)` | 유연한 정답 확인 (숫자/함수) | 전 아이디어 공통 |
| `MJ.hintSteps(btnId,boxIds)` | 단계별 힌트 공개 | 오류 탐정류 |
| `MJ.animateCount(el,from,to,ms)` | 숫자 카운트업 애니메이션("와" 모먼트) | 디지털 용량 재기 |
| `MJ.makePlane(svg,opt)` | 좌표평면 + 동적 직선 | 기울기 미끄럼틀, 그래프 위의 정답 |
| `MJ.gcd(a,b)` | 최대공약수 | 예언자 게임(분모 소인수 판정) |
| `MJ.reveal(btnId,boxId)` | 정답 펼치기 | 공통 |

### 1-3. 디자인 — "한 단계 더" 를 구체화

`concept.css` 끝에 **`playground` 섹션 신설**(전 단원 g-page 공유):
- 카드에 은은한 그림자 대신 **더 굵은 보더 + 살짝 기울어진 배지**("게임" 느낌)
- 정답 맞으면 **작은 컨페티/스파클 CSS 애니메이션** (라이브러리 없이 순수 CSS `@keyframes`)
- 버튼 터치 타깃을 연습 문제보다 **더 크게**(놀이 맥락은 손가락으로 톡톡 누르는 느낌)
- 단원별 accent 색(`--u`/`--u2`)은 유지하되 **채도를 조금 올린 변형**(`--u-play`)을 놀이터 전용으로 추가해 "같은 단원인데 좀 더 신남"을 표현

### 1-4. 허브 연결

`index.html`(중2 허브)에 기존 "🧭 탐험" / "✏️ 계산 연습" 툴카드와 같은 자리에 **"🎨 흥미 놀이터"** 카드 추가(단원1 완성 후, 또는 처음부터 추가하고 "1개 단원 오픈" 명시).

## 2. 단원별 아이디어 카탈로그 — 트랙 A (중2-1)

**공통 메커닉 (재사용, 매 단원에 최소 1개씩 깔림):** ★ **오류 탐정** — 일부러 틀린 풀이를 보여주고 어디서 틀렸는지 짚기.
**기존 오개념 카드 357장(`30_content/problem_bank/misconceptions/`)을 그대로 재료로 쓴다** — 단원별 15개 카드의 `counter`(반례)를 "가짜 풀이" 형태로 재구성하면 새로 쓸 내용이 거의 없다. 아래 표의 "오류 탐정"은 매번 이 자산을 가리킨다.

### 단원1 · 유리수와 순환소수 — ★파일럿, 지금 만든다
1. **끝나는 소수 예언자** — 분모만 보고 유한/순환을 먼저 예측 → `MJ.decimalOf`로 실제 전개 확인. 예측→확인 루프(mid-sci 과학 앱에서 검증된 패턴).
2. **반복무늬 탐정** — 1/7, 2/7, 3/7…의 순환마디가 전부 같은 숫자의 순서 바꿈이라는 걸 나열해서 스스로 발견.
3. **후렴구 변환기** — 순환소수 ↔ 분수 즉석 상호 변환 + "10배 빼기" 트릭 애니메이션.
4. **오류 탐정** — 순환마디 표기 오류 찾기.

### 단원2 · 식의 계산
1. **디지털 용량 재기** — 지수 슬라이더 → KB/MB/GB/TB 실시간 변환(`animateCount`). "네 폰 사진앱이 몇 GB인지".
2. **지수 저글링** — 여러 지수법칙 식을 최소 단계로 정리하는 "적은 단계 = 고득점" 챌린지.
3. **동류항 정리함** — 같은 항끼리 드래그해 모으는 분류 인터랙션.
4. **오류 탐정** — 지수법칙 오개념 15개 기반.

### 단원3 · 일차부등식
1. **용돈 시뮬레이터** — 실제 용돈으로 "이 조건에서 살 수 있나" 판정(PC방 시간·데이터요금제·택배무게 등 미니 계산기 여러 개).
2. **부호 뒤집기 실험실** — 양변에 곱하는 수를 슬라이더로 바꾸며 부등호가 뒤집히는 순간을 직접 목격.
3. **수직선 색칠 게임** — 해를 수직선에 드래그로 표시 후 정답과 비교.
4. **오류 탐정** — 음수 곱셈 시 부호 안 뒤집은 풀이.

### 단원4 · 연립방정식
1. **탐정 사건 파일** — 단서 2개(방정식)로 범인(x,y) 찾기. 화면을 사건 파일 카드로 디자인.
2. **저울 맞추기** — 대입법/가감법을 양팔저울 애니메이션으로.
3. **교점 사냥꾼** — 그래프에서 직접 교점 클릭 → 대수 풀이와 일치 확인.
4. **오류 탐정** — 가감법 한쪽 식만 곱한 풀이.

### 단원5 · 일차함수와 그래프
1. **암호 편지 만들기** — $y=ax+b$ 로 자기만의 암호 생성 → **인쇄해서 친구에게 낼 수 있음**(D축 프린트 인프라 재사용 가능, 후속 확장).
2. **기울기 미끄럼틀** — a,b 슬라이더 → 그래프 실시간 반응(`MJ.makePlane`).
3. **실생활 그래프 맞히기** — 택시요금/물탱크/온도변화 상황과 그래프 짝짓기.
4. **오류 탐정** — 기울기 부호 오독.

### 단원6 · 일차함수와 일차방정식
1. **그래프 위의 정답** — 그래프 조작 ↔ 교점 ↔ 대수적 해가 연동되는 위젯.
2. **평행선 미스터리** — 기울기 같은 두 직선 겹쳐보며 "왜 해가 없는지" 시각 발견.
3. **오류 탐정** — x=k/y=k 그래프 방향 혼동.

**🎉 트랙A 완주 (2026-08-16, chatlog Round 2~7):** 단원1~6 전부 4개 위젯씩·총 24개 완성·배포. 실제 구현은 g1~g6.html(`40_grades/middle/math2/app2/`) 참조 — 위 카탈로그와 부분적으로 다르게 구체화된 아이디어도 있음(예: 단원4 "저울 맞추기"는 대입법 대신 가감법 더하기/빼기 선택 게임으로, 단원6은 계획에 없던 "수직·수평선 감별사"를 4번째 위젯으로 추가).

## 2b. 단원별 아이디어 카탈로그 — 트랙 B (도형, 10단원)

> 확정 2026-08-16 · 리서치 = `00_project_hub/10_chatlog/260810_content_interest_no_person.md` Round 8

### ⚠️ 착수 전 결정 필요 — 아키텍처 갭

트랙A(math2/app2)는 **`concept.js`의 공유 엔진**(PLAY_READY + pageInfo + tabs splice, §1 참조) 덕에 g*.html 하나 추가 + 3줄 수정으로 끝났다.
**트랙B의 math1 6단원(07~12)은 이 엔진이 없다** — 각 단원 폴더(`40_grades/middle/math1/NN_단원명/`)가 각자 독립된 정적 HTML(자체 `<script>`, KaTeX CDN, 공유 탭바 없음)이다.
다만 **`geo.js`(namespace `MG`)가 math2의 `MJ.makeGeo`와 API 100% 호환**(poly/seg/dot/label/angle/tick/right) — 도형 그리기 자체는 그대로 이식 가능하나, "탭에 자동으로 놀이터 링크가 뜨는" 경험은 별도 작업이 필요하다.
math2 4단원(07~10)은 기존 엔진 그대로 재사용 가능(§1 그대로 적용).

**선택지:**
- **(A) math1용 경량 엔진 포팅** — `geo.js` 파일에 PLAY_READY 유사 로직 추가, 각 단원 `index.html`에 탭/카드 수동 삽입. 트랙A와 동일한 통합감, 초기 스캐폴딩 비용 있음.
- **(B) 링크만 추가** — 각 단원 `index.html`에 "🎨 놀이터" 카드 하나만 손으로 추가(탭바 없이). 즉시 시작 가능, 통합감은 떨어짐.
- **(C) math2 4단원(07~10) 먼저** — 기존 엔진 그대로 재사용, math1은 스캐폴딩 결정 후 착수.

### 단원 범위 확인

### math1 단원07 · 기본도형
1. **위치관계 판별사** — 두 직선의 위치관계(평행/한 점에서 만남/꼬인 위치) 카드를 분류. "꼬인 위치=평행 아님"을 정면 타격.
2. **각 짝꿍 찾기** — 두 직선이 다른 직선과 만날 때 생기는 각들 중 동위각·엇각 짝을 클릭으로 찾기.
3. **맞꼭지각 vs 이웃각 감별사** — 지정된 각과 "맞꼭지각"인 것 vs "이웃한 각"인 것 구분.
4. **오류 탐정** — 반직선 방향(PQ≠QP), 맞꼭지각/이웃각 혼동 등.

### math1 단원08 · 작도와 합동
1. **합동 판정관** — SSS/SAS/ASA 세 조건 카드를 "합동이다/알 수 없다"로 분류. **SSA 함정 카드 필수 포함**(핵심 오개념).
2. **끼인각 찾기** — 삼각형 그림에서 "이 두 변의 끼인각"을 클릭으로 짚기.
3. **컴퍼스 작도 시뮬레이터** — 반지름 슬라이더로 두 원이 만나는 점(작도 원리)을 시각 확인.
4. **오류 탐정** — SSA 오조건, 세 각만 같음(닮음과 혼동), 작도 도구 오용 등.

### math1 단원09 · 다각형
1. **대각선 사냥꾼** — 다각형 꼭짓점에서 그을 수 있는 대각선을 클릭으로 모두 찾기 → n각형 대각선 공식 확인.
2. **내각의 합 실험실** — 변의 수(n) 슬라이더 → 삼각형 분할선 자동 표시 + 내각의 합=180×(n−2) 실시간 계산.
3. **외각 레이서** — 정다각형 둘레를 도는 애니메이션으로 "외각의 합은 항상 360°" 체감(CSS만으로 회전 애니메이션).
4. **오류 탐정** — 대각선 개수 공식, 내각합 −2 누락, 외각 정리 등.

### math1 단원10 · 원과 부채꼴
1. **부채꼴 저울** — 중심각 슬라이더 → 호의 길이·넓이는 정비례로 변하지만 **현의 길이는 비례하지 않음**을 나란히 대조(★핵심 오개념 정면 타격).
2. **호 vs 현 감별사** — 그림에서 지정된 선을 "호"인지 "현"인지 클릭으로 분류.
3. **색칠부분 넓이 계산기** — 부채꼴 두 개를 합/차로 조합해 색칠 영역 넓이 공식 적용 연습.
4. **오류 탐정** — 지름/반지름, 호/현/접선 혼동, π 근사 계산 등. ★현 비례 오개념 필수 포함.

### math1 단원11 · 다면체와 회전체
1. **정다면체 판정관** — 후보 카드(면의 모양+꼭짓점에 모이는 면의 수)를 보고 "두 조건"을 만족하는지 체크 → 왜 5종뿐인지 발견.
2. **오일러 공식 계산기** — V,E,F 입력 → V−E+F 실시간 계산, 여러 다면체로 =2 검증.
3. **단면 자르기 시뮬레이터** — "회전축에 수직으로 자르기" vs "축을 포함해 자르기" 버튼 → 단면 모양(원 vs 대칭도형)이 바뀌어 표시(★핵심 오개념 정면 타격).
4. **오류 탐정** — 면/모서리/꼭짓점 수 뒤바꿈, 오일러공식 부호, 회전축 단면 혼동 등.

### math1 단원12 · 입체도형의 겉넓이와 부피
1. **전개도 조립공** — 기둥/뿔 전개도 부품을 클릭해 겉넓이 공식에 포함(밑면 개수: 기둥=2, 뿔=1 — "밑면 1개만 더함" 오개념 타격).
2. **뿔 부피 1/3 실험실** — 같은 밑면·높이 기둥·뿔의 부피 비율을 애니메이션(뿔 3번 부으면 기둥 가득)으로 체감.
3. **원기둥·원뿔·구 부피 저울** — 반지름 r 슬라이더 하나로 세 도형 부피 관계를 실시간 계산.
4. **오류 탐정** — 밑면 개수, 1/3 누락, 모선/높이 혼동, cm²/cm³ 구분 등.

### math2 단원7 · 삼각형의 성질
1. **외심 vs 내심 감별사** — "변의 수직이등분선이 만나는 점" vs "각의 이등분선이 만나는 점" 설명을 보고 분류(핵심 혼동 타격).
2. **이등변삼각형 접기 실험** — 꼭지각 이등분선을 그리면 두 밑각이 겹치는 대칭 애니메이션(`MJ.makeGeo`) 후 퀴즈.
3. **외심 각도 계산기** — ∠A 슬라이더 → ∠BOC=2∠A 자동 계산, 둔각삼각형일 때 외심이 삼각형 밖으로 나가는 것 확인(항상 안에 있다는 오개념 타격).
4. **오류 탐정** — 세 각 합 360°로 착각, 외심·내심 공식 바꿔 씀 등.

### math2 단원8 · 사각형의 성질
1. **사각형 족보 만들기** — 평행사변형→직사각형/마름모→정사각형 포함관계를 배치로 완성(포함관계 거꾸로 보는 오개념 타격).
2. **대각선 성질 실험실** — 평행사변형/직사각형/마름모/정사각형 전환 시 대각선이 "이등분"/"길이같음"/"수직" 중 무엇을 만족하는지 체크리스트로 확인.
3. **이웃각 합 180 챌린지** — 평행사변형 한 각 슬라이더 → 이웃각이 자동으로 180−(그 각)으로 실시간 계산.
4. **오류 탐정** — 네 각 합 180°로 오인(삼각형과 혼동), 대각선 성질(길이 같음 vs 이등분) 오판 등.

### math2 단원9 · 도형의 닮음
1. **넓이비 함정** — 닮음비 k인 두 도형의 넓이비를 먼저 예측(k라고 답하기 쉬움) → 실제론 k²임을 체감. 부피비 k³로 확장.
2. **무게중심 눈금자** — 중선 위 2:1 지점을 직접 찾아보는 게임(중점(1:1) 오판 정면 타격).
3. **평행선 사이 비율 재기** — 삼각형 내부 평행선을 움직이며 대응 선분의 비가 항상 같음을 확인 후 대응 짝 퀴즈.
4. **오류 탐정** — 넓이비 제곱 누락, 대응변 짝 안 맞춤, 부분/전체 혼동 등.

### math2 단원10 · 피타고라스 정리
1. **제곱 계산기 오류 잡기** — "a²을 2×a로 계산"하는 흔한 실수를 직접 계산해보는 인풋 챌린지(가장 근본적인 계산 오개념 정면 타격).
2. **세 변 판별사** — 세 변의 길이 카드(3-4-5, 5-12-13 + 함정)를 보고 직각삼각형인지 판정.
3. **두 점 사이의 거리 사냥꾼** — 좌표평면에 두 점 표시 → 피타고라스로 거리 계산(`MJ.makePlane` 재사용).
4. **오류 탐정** — c자리 오배치, 제곱=2배 계산, 판별 시 가장 긴 변 안 찾음 등.

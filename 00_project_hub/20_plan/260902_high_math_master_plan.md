# 고등 수학 마스터 플랜 — 2028 수능 체제 (bootstrap 정본)

> **이 파일이 고등 수학 작업의 시작점이다.** 새 세션은 이 파일을 먼저 읽고 Phase 0부터 진행한다.
> 기획 배경·특강 목록의 원본 논의 = `00_project_hub/10_chatlog/260902_special_lecture_topics.md`.

---

## 1. 목표·대상

- **목표**: 2028 수능 체제(선택과목 폐지)에 맞춘 고등 수학 학습 시스템 — mid1~3에서 검증된 "개념 이해 우선 + 인터랙티브 시각화 + 특강 + 프린트" 패턴의 고교 확장.
- **대상**: 1차 = 아들(2026 현재 고1 — 2028 개편 수능 적용 세대). 2차 = 딸(중1)의 미래 자산.
- **우선순위는 중등과 동일**: (a) 이해·자신감 > (b) 실전력. 단, 고교는 (b)의 비중이 중등보다 높다(수능이 실존하는 시험이므로 유형 커버리지·프린트 모의고사의 무게 ↑).

## 2. 확정 사실 (2026-09-02 웹 확인 — 재확인 불필요)

- **2028 수능 수학 = 공통 출제**: 대수(11문항) + 미적분Ⅰ(11문항) + 확률과 통계(8문항). 선택과목 폐지, 미적분Ⅱ·기하 제외.
- **2022 개정 고교 과정**:
  - 고1: **공통수학1** = 다항식 · 방정식과 부등식 · 경우의 수 · **행렬(신설, 2×2까지·역행렬 제외)** / **공통수학2** = 도형의 방정식 · 집합과 명제 · 함수와 그래프
  - **대수**(구 수학Ⅰ) = 지수와 로그 · 지수함수와 로그함수 · 삼각함수 · 수열
  - **미적분Ⅰ**(구 수학Ⅱ) = 함수의 극한과 연속 · 미분 · 적분
  - **확률과 통계** = 경우의 수(순열·조합, 원순열 제외) · 확률 · 통계(모비율 재도입)
- 출처: 매일신문(2028 수능 개편 발표) · mathedu.me.kr(범위 총정리) · 나무위키(2022 개정 과목별 문서). 상세 링크 = chatlog Round 0.

## 3. 범위 (스코프)

| 구간 | 형태 | 규모 |
|---|---|---|
| 고1 공통수학1·2 | **특강 5개만** (전 단원 앱 X — 결정 Q3 참조) | G1 이차함수 완전정복 · G2 절댓값과 그래프 개형 · G3 집합·명제=수학의 문법 · G4 행렬 첫만남 · G5 도형의 방정식 |
| 대수 | **전 단원 앱** + 특강 3 | 단원 앱 ~8단원 분해(Phase 0에서 확정) + G6 지수→로그 · G7 삼각함수는 원이다 · G8 수열과 Σ 리터러시 |

| 확률과 통계 | **전 단원 앱** + 특강 3 | ~6단원 + G12 순열·조합 구분 · G13 조건부확률 직관 · G14 정규분포·표준화 |
| 프린트 | 유형별 학습지 + 실전 모의고사 | mid 파이프라인(EXAM_SPEC 패턴) 확장. 과목별 완주 후 |

## 5. Phase 로드맵

> 원칙: **특강이 과목의 관문** — 각 과목 Phase는 그 과목 특강부터 만들고 단원 앱으로 들어간다(특강이 단원 개념 페이지의 토대 서사가 됨).

| Phase | 내용 | 산출물 |
|---|---|---|
| **P0 정본** | 교과서 목차 기준 과목별 단원 분해 확정, `UNITS_HIGH.md` 작성, 엔진 스캐폴드(허브+1단원 시제품), 배포 경로 확정, KaTeX 파이프라인 검증 | UNITS_HIGH.md · 허브 · 시제품 1단원 |
| **P1 고1 특강** | G1~G5 (아들 현 학년 내신 직결 — 시급성 최상) | special/ 5페이지 |
| **P2 대수** | G6~G8 특강 → 전 단원 앱 (~8단원 × u/g/p/d) | algebra/ 완성 |

## 9. 결정 필요 (Nick — P0 프롬프트에 답을 채워 보낼 것)

- **Q1. 대상 확정**: 1차 사용자 = 아들이 맞는지? 현재 학교 진도(공통수학2 진행 중인지, 고2 때 대수·미적Ⅰ 어느 순서인지)를 알려주면 P1~P4 순서를 진도에 동기화.
- **Q2. 착수 순서**: 제안 = P1 고1 특강(내신 즉효) → P2 대수. 아들 진도가 다르면 조정.
- **Q3. 공통수학 전 단원 앱**: 특강 5개로 갈음하는 게 기본안. 아들 고1 내신에 전 단원 앱까지 필요하면 스코프 추가(규모 +40%).
- **Q4. 어투·톤**: 고등도 해요체 유지? 아들 취향(담백/게임성 낮춤 등)을 반영할지. mid 시리즈의 파티클·콤보 같은 게임 요소를 고등에도 쓸지.

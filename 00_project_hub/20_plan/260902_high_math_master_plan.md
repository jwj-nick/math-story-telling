## 2. 확정 사실 — 2028 수능 (재확인 불필요)

- **수능 수학 = 공통 출제**: 대수(11문항) + 미적분Ⅰ(11문항) + 확률과 통계(8문항). 선택과목 폐지, 미적분Ⅱ·기하 제외.
- 대수 = 지수와 로그 · 지수함수와 로그함수 · 삼각함수 · 수열 / 미적분Ⅰ = 극한과 연속 · 미분 · 적분 / 확통 = 순열·조합(원순열 제외) · 확률 · 통계(모비율 재도입).
- 아들(2026 고1) = 2028 개편 수능 적용 세대. 공통수학1·2는 수능 직접 출제 범위가 아니라 **토대**(이미 앱 완성).
- 출처 링크 = chatlog Round 0.

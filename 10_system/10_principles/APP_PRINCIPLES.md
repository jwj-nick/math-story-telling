# APP PRINCIPLES — 중1 수학 학습 앱 설계 원칙

> 모든 스킬·에이전트·수동 작업이 이 파일을 준수한다.
> 위반 사항은 `app-reviewer` 에이전트가 감지하고 보고한다.

---

## 핵심 철학

### 1. 점진적 공개 (Progressive Disclosure)
학생이 스스로 풀어나가는 흐름을 방해하지 않는다.
**풀이 과정에서 도출해야 할 정보를 문제 페이지에 미리 보여주면 안 된다.**

### 2. 따뜻한 말투
대상이 중1 여학생. 감성적·내성적. "~해요", "함께 생각해봐요" 톤.
수학 용어는 정확하되, 설명은 친근하게.

### 3. 빈칸을 남겨라
딸이 채울 자리가 있어야 한다. 모든 것을 다 보여주지 않는다.

## 공통 HTML 원칙

- **단일 파일**: 바닐라 JS, CDN만 사용 (KaTeX, JSXGraph)
- **반응형**: max-width 700px, 모바일 대응
- **색상**: primary `#4361EE`, 배경 `#eef2ff`, 카드 white
- **네비게이션**: 진행 도트 클릭으로 페이지 이동
- **수식**: KaTeX CDN 렌더링
- **비표준 기호**: 첫 등장 시 초록 `.deg-info` 박스 설명 + 이후 보라색 한글 병행

## 오답노트 앱 원칙

### page-0 (문제 페이지)

**반드시 표시**:
- 문제 텍스트 원문 (추가/삭제 금지)
- 선택지 (객관식)
- 원본 구도와 동일한 **정적 SVG** 또는 원본 이미지
- 배점

**절대 금지**:
| 금지 항목 | 이유 |
|---|---|
| 풀이 중 도출해야 할 수치/좌표 | 풀이 흐름 파괴 |
| JSXGraph 슬라이더 | 탐구는 풀이 단계에서 |
| 정답 힌트가 되는 공식/변환 | 스스로 발견해야 할 과정 |
| 축에 좌표 수치 표기 | 원본에 없는 정보 |

### page-1~N (풀이 페이지)
- 한 페이지 = 하나의 단계 (번호 + 제목 + "왜 이 단계인가" 필수)
- 해당 단계에서 새로 도출한 정보만 공개
- JSXGraph: 해당 단계에서 처음 도입하는 시점, lazy init 패턴
- warn-box (흔한 실수) 포함

### 요약 페이지
- 핵심 풀이 흐름 3~5줄
- 정답 (큰 글자, answer-box)
- 약점 태그

## 연습 앱 원칙

- 각 문제는 독립적으로 풀 수 있어야 함
- 정답·힌트는 **탭 전환으로만** 공개
- prob(문제판)에 인터랙티브 요소 금지
- 난이도: L(쉬운)×3 + M(중간)×3 + H(어려운)×3

---

## 개념 탐구 앱 원칙 (중1 특화)

오답노트와 별개로, **개념을 탐구하는 인터랙티브 도구**에 적용:

- 슬라이더로 파라미터를 직접 조작하며 변화 관찰
- 식이 자동으로 다시 써지는 실시간 연동
- "이번에는 a를 바꿔보세요" 같은 유도 메시지
- 끝에 "직접 써보세요" 칸 (빈칸 원칙)

---

## 스토리텔링 앱 원칙 (중1 특화)

인물 서사를 앱으로 만들 때:

- 이야기 → 개념 → 탐구 → 직접 써보기 흐름
- 인물의 시대적 맥락 (연도, 장소, 고민)
- 개념과 인물을 자연스럽게 연결
- 잡학(Trivia) 섹션: 현대 활용처, 다른 단원 연결

---

## 정적 그림 원칙

- 원본 구도와 레이블 일치
- 좌표값은 원문에 명시된 것만 표시
- 축 눈금 숫자 표시 금지
- 참조용 대표값으로 고정

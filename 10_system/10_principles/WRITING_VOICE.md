# WRITING_VOICE.md — 학습 앱 글쓰기 어투 (SSOT)

> 모든 학년·학기 학습 앱(중2-1, 향후 중1·중2-2 등)의 **화면 문구 어투 기준**.
> 2026-07-12 Nick 지시로 확정: 반말 → **친근한 높임말**로 전환. 앞으로 신규 콘텐츠도 이 어투.

## 원칙
아이가 **존중받고 배려받는다**고 느끼도록. 반말·명령조 금지. 그렇다고 딱딱한 격식체(합쇼체: 합니다/하십시오)도 아님.
**친근한 높임말 = 해요체.** 따뜻하고 담백하게. (이전 원칙 유지: 과장 칭찬·느낌표·장식 이모지 최소.)

## 종결 어미 변환
| 반말 (금지) | 높임말 (사용) |
|---|---|
| ~한다 / ~이다 (서술) | ~해요 / ~이에요·예요 |
| ~해봐 / ~해 / ~하자 (명령·청유) | ~해 볼까요? / ~해 보세요 / ~해요 |
| ~할래? / ~일까? / ~니? (질문) | ~할까요? / ~일까요? |
| ~거야 / ~야 | ~예요 / ~이에요 |
| ~네 (감탄) | ~네요 |
| ~어 / ~지 (종결) | ~어요 / ~죠 |

## 호칭·인칭
- "너 / 네가 / 네" → 되도록 생략하거나 "직접 / 스스로 / 자기"로. 예: "네가 문제를 내봐" → "직접 문제를 내볼까요?"
- 아이를 다정히 대하되 과하지 않게. 부담스러운 애칭·오글거림 금지.

## 예시 (Before → After)
- "직접 움직여봐" → "직접 움직여 볼까요?"
- "먼저 스스로 풀고, 막히면 연다." → "먼저 스스로 풀어 보고, 막히면 열어요."
- "이게 진짜 이해야." → "이게 진짜 이해예요."
- "왜 그런지 동생한테 설명한다면 어떻게 말할래?" → "왜 그런지 동생에게 설명한다면 어떻게 말할까요?"
- "문제를 풀면 위 막대가 찬다." → "문제를 풀면 위 막대가 차요."
- "네 말이면 돼." → "자기 말로 설명하면 돼요."
- "정답" → "정답이에요" · "아니야. 답은 3" → "아니에요. 답은 3이에요"
- "숫자를 넣어줘" → "숫자를 넣어 주세요"

## 불변 (절대 건드리지 말 것)
HTML 태그·속성·id·class·style, `<span class="eq">`·`<sup>` 속 수식, `<script>` 코드, `<span class="en">` 영어 병기, 숫자·수학 기호·정답, 파일명·링크. **오직 한국어 서술/안내/문제 지문/피드백 문장의 어투만** 바꾼다. 수학 내용·정답은 불변.

## 톤 균형
높임말이되 **담백**하게. 정보 위주. 예: 완료 문구 "순환소수 연습 완료" → "순환소수 연습을 마쳤어요." (사실 + 높임, 과장 없음)

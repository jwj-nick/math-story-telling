- **감성적, 공감 능력 높음** — 인물 서사에 몰입 가능

## 수학 현황

- **성적**: 중하위
- **자기 인식**: "수학도 잘하고 싶은데 너무 어려움"
- **관찰된 패턴**:
  - 개념을 명확히 알면 어렵지 않은 문제도 어려워함
  - 문제 풀 때 속도가 안 남
  - 오답률 높음
  - **(2026-08-31, Nick 관찰)** 등식의 양변에 같은 사칙연산을 적용해 단순화하는 것 — 할 수는 있지만 오래 걸리고 매번 새로 생각해내는 느낌(절차가 자동화되지 않음). 문장제를 여러 수식으로 나열해 풀어나가는 것(식 세우기)도 약함 → 아래 가설 #2 를 구체적으로 확인해주는 사례. 대응 기획 = `00_project_hub/10_chatlog/260831_math1_speed_drill.md`
- **추정 원인** (가설, 검증 필요):
  1. "안다"가 사실은 "들어봤다" 수준일 가능성
  2. 절차적 유창성(procedural fluency) 부족 — 충분히 안 풀어봐서 **(2026-08-31 위 관찰로 부분 확인)**
  3. 작업 기억(working memory)에서 개념과 절차를 동시 운용하는 부담

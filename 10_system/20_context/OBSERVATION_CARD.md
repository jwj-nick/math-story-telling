# 관찰 카드 — 특강을 딸이 실제로 어떻게 쓰는지 적는 자리

> 왜 필요한가: 특강 ⑨(도형 각도 추적)는 "관찰 후 결정"으로 남겨 두었다가, 결국 관찰 기록이 없어서
> 감으로 착수 여부를 판단했다. 다음 특강의 설계 입력은 **딸의 실제 반응**이어야 한다.
> 이 파일은 **템플릿 원본**이다. 실제 기록은 `.private/observation/`(gitignore)에 복사해 쓴다.

## 쓰는 법

1. 딸이 특강을 한 번 쓸 때마다 카드 한 장을 채운다. 완벽하게 채우지 않아도 된다 — **한 줄이라도** 남기는 편이 낫다.
2. 화면 옆에서 지켜보는 게 어려우면, 나중에 한 문장만 물어보고 그 대답을 적어도 충분하다.
3. 딸이 직접 쓴 글은 고치지 않는다(프로젝트 절대 원칙 3). 관찰자의 해석은 **해석** 칸에만 적는다.

## 카드 양식 (복사해서 쓰기)

```markdown
### <특강 이름> · <YYYY-MM-DD> · <몇 분>

**어디까지 갔나**
- 끝까지 / ⑤ 유형 도중 / ② 감 잡기에서 이탈 (해당하는 것)
- 멈춘 지점(섹션 번호와 무엇을 하다가):

**반응**
- 소리 내어 말한 것(그대로 옮기기):
- 손이 멈춘 곳:
- 다시 눌러 본 것(재생·다른 문제로·힌트):
- 웃거나 "오" 한 순간:

**총정리 결과**
- 첫 시도 정답 수 __ / 5 · 도장 받음(예/아니오)
- 틀린 문제의 유형:

**혼자 못 넘은 것**
- 설명이 필요했던 부분:
- 화면 문구 중 못 알아들은 표현:

**해석 (관찰자)**
- 다음에 고칠 것 한 가지:
- 새 특강이 필요해 보이는 주제:
```

## 모아서 보는 법

카드가 5장쯤 쌓이면 다음을 센다. 이것이 다음 Wave의 우선순위가 된다.

| 신호 | 뜻하는 것 |
|---|---|
| 같은 섹션에서 반복해 멈춤 | 그 설명이 아직 어렵다 → 그 단계를 쪼개거나 애니를 하나 더 |
| 총정리 첫 시도 정답이 3 이하 | 유형 훈련(⑤)이 부족하다 → 문제 풀 확대 |
| 도장을 받고도 다시 안 옴 | 반복 동기가 없다 → 드릴 챕터나 프린트로 연결 |
| "이건 왜 배워요?" | 도입(①)의 공감이 약하다 |
| 특강을 아예 안 연다 | 진입 동선 문제 → 연습 페이지 인라인 링크·추천 카드 위치를 조정 |

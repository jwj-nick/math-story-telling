# se_story_write — 인물 서사 초안 생성 스킬

## 인자 형태
```
/se_story_write unit01 에라토스테네스
/se_story_write unit03 알콰리즈미
```

## 절차

### 1. 리서치
- `20_research/02_R2-people-map.md`에서 해당 인물 정보 읽기
- `40_BaseDocs/NN_단원명/`에서 관련 개념 읽기
- 필요시 웹 리서치 (역사적 사실 확인)

### 2. 스토리 초안 작성

**구조** (10_docs/02_concept.md 5단계 기반):

```markdown
# [인물 이름] — [단원명]

## 이야기
[인물의 시대적 배경, 고민, 발견의 순간]
[~2000자, 10~15분 읽기 분량]
[역사적 사실 기반, 과도한 판타지 지양]

## 글쓰기 미션 (딸이 선택)
1. [인물에게 편지 쓰기]
2. [인물 인터뷰 시나리오]
3. [그 개념이 사라진 세상 단편소설]

## 개념 정리 (빈칸형)
[딸이 자기 언어로 채우는 빈칸 포함]

## 잡학 (Trivia & Connection)
- [현대적 활용처]
- [다른 단원/과목 연결]
- [재미있는 팩트]
```

### 3. 저장
**파일 경로**: `50_units/NN_단원명/story/unitNN.md`

### 4. Nick 리뷰 요청
chatlog 파일에 "스토리 초안 완성, 리뷰 부탁" 기록.
Nick의 피드백 반영 후 확정.

## 작성 원칙
- **역사적 사실 기반** — 가짜 판타지 지양
- **인물의 감정·고민 포함** — 딸의 공감 능력 활용
- **개념과 인물을 자연스럽게 연결**
- **빈칸을 남겨라** — 딸이 채울 자리
- **수학 용어는 40_BaseDocs의 정의 준수**

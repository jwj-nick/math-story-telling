# Q04 — 아이의 시스템 사용 자율도, 어느 단계까지 가도 좋은가?

> 상태: 🔴 미결. Nick의 교육 철학과 직결.

## 질문

아이(아들·딸)가 이 시스템을 직접 사용하는 단계, 어디까지 갈 것인가?

## 자율도 스펙트럼

| 단계 | 설명 | 현재 |
|---|---|---|
| L0. 소비자 | 부모·NCC가 만든 앱을 열어 학습만 | 🟢 현재 |
| L1. 요청자 | 아이가 "이런 거 필요해"라고 말 → 부모·NCC가 제작 | 🟡 자연스럽게 시작 |
| L2. 명령자 | 아이가 직접 Claude Code 콘솔에 명령 입력 (`/perf-eval-step ...`) | 🔴 시기·방법 미정 |
| L3. 제작자 | 아이가 새 패턴·컴포넌트 직접 제안·구현 | 🔴 먼 미래 |

## 우려·기대

### 우려
- 너무 일찍 L2 → AI 의존성. 본인 생각이 줄어들 수 있음
- AI가 답을 다 만들어주면 학습의 "체화 과정" 손실
- 디지털 디바이스 사용 시간 증가

### 기대
- L2 도달하면 → 부모 시간·정신 부담 ↓
- 아이가 "도구를 만든다"는 메타 경험 자체가 교육적
- 미래 직업 환경에 적응

## 단계별 안전장치 제안

| 단계 | 안전장치 |
|---|---|
| L0 → L1 | 무조건 OK. 학생이 요구하는 것은 작업 시작점 |
| L1 → L2 | 첫 도입 전에 30분 정도 함께 사용해보기. 명령 매뉴얼 1장 |
| L2 운영 중 | 매주 1회 학생 작업 회고 (어떤 명령 썼나, 결과 만족도) |
| L3 진입 | 학생이 명시적으로 관심 보일 때만 |

# P02 — 과학 개념카드 (화학결합·원자모형)

## 발견 맥락

- **출처**: `70_HighSchool/2604_고1_중간고사/수행평가-과학/` — 통합과학1 수행평가
- **트리거**: 화학결합 22종, 원자모형 10종을 시험 전에 비교·암기해야 하는 부담
- 단순 표 암기 → 카드형 인터랙티브로 전환

## 핵심 구조

### 산출
- 단일 HTML 앱 1개 (substances 배열 or elements 배열)
- 카드 클릭 시: 화학식·결합 유형·생활 속 이름·전자 배치 등 펼침

### 카드 항목 표준 (화학결합)
- id, name, commonName, formula (유니코드 아래첨자), bondType, electronegativity, polar/nonpolar
- 생활 예시 (소금·제설제·등)

### 카드 항목 표준 (원자모형)
- 원소 기호, 양성자/중성자/전자, 전자 배치, 주기·족, 화학결합 경향

## 재사용 단위

### 컴포넌트
- `concept-card` (선택 가능)
- 카드 그리드 + 검색·필터 (선택 시 펼침)

### 콘텐츠 구조
- 항목 표준화 (json 배열)
- skill `/science-chem-card` 로 항목 1개씩 추가·전체 재생성 자동화

## 일반화 가능 영역

### 적용 가능 단원
- 화학: 산-염기, 산화-환원, 유기 화합물 분류
- 생물: 세포 소기관, DNA·RNA·단백질, 영양소
- 물리: 단위·SI 접두사, 운동 종류, 파동 종류
- **국어**: 음운 변동·문법 개념 (조사·어미)
- **사회**: 정치 제도·경제 개념 카드

> 패턴 자체는 **"비교·암기가 핵심인 콘텐츠"** 모두에 적용 가능.

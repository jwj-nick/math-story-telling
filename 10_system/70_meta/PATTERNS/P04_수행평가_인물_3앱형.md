# P04 — 수행평가 인물 3앱형

## 발견 맥락

- **출처**: `70_HighSchool/2604_고1_중간고사/수행평가-한국사/` — 정도전 인물 분석 수행평가 (2026-05-09~10)
- **과제 구조**: Q1~Q5 단답·논술 혼합 (Q4 본인 개혁안 7점 ⭐, Q5 포스터)
- **트리거**: 단일 학습 자료로는 (a) 외우기 (b) 깊이 이해 (c) 자기 생각 모두 충족 불가 → 3개 앱으로 분리

## 핵심 구조

### 3축 분리

| 앱 | 용도 | 핵심 컴포넌트 | 톤 |
|---|---|---|---|
| **가이드** | 학습용. 타임라인·키워드·글자수카운터·브레인스토밍 | tab-nav, char-counter, hint-toggle, brainstorm | 학습 모드 (밝음) |
| **모범답안** | 암기·구조 학습용. Q1~Q5 완성본 + 포스터 템플릿 | tab-nav, copy-btn, image-embed | 명확 모드 (보라) |
| **심화** | 의미·동기 부여용. 인생 스토리북·풍경·매칭게임·시뮬레이터·평생 질문 | storybook, matching-game, simulator, persistent-textarea | 사색 모드 (네이비·금색) |

### 왜 3개로 분리?
- 한 앱에 다 넣으면 무겁고, 학생이 "오늘 어디까지 했나" 추적 불가
- 분리하면 학생이 시간 분배 자율적 (예: 시험 전날 → 모범답안만, 평소 → 심화)

## 재사용 단위

### 컴포넌트
- `tab-nav` (3 앱 모두)
- `char-counter` — Q2·Q3 같은 글자수 제약 (120~160자) 논술용
- `storybook` ⭐ — 5장면 prev/next 네비게이션 (한국사 정도전 인생)
- `matching-game` ⭐ — 5질문 ↔ 5답 짝짓기 (5개혁 학습)
- `simulator` ⭐ — 단계별 textarea → 즉시 합성 출력 (Q4 본인 개혁안)
- `persistent-textarea` ⭐ — localStorage 자동저장

### 콘텐츠 구조
- 인생 타임라인 (탄생→주요사건→최후)
- 인물·시대 풍경 4개 (시각화 가능한 장면)
- 핵심 사상 / 산출 / 개혁안 매핑
- 본인 사고법 시뮬레이터 (구조: 인식 → 원인 → 처방 → 효과)
- 평생 따라가는 질문 4개

## 일반화 가능 영역

### 적용 가능 인물 후보
- 한국사: 정도전(완료), 류성룡, 조광조, 이이, 정약용, 김구
- 세계사: 노자·공자, 마키아벨리, 토크빌
- 과학사: 갈릴레오, 다윈
- **MathTelling과 통합**: 단원별 수학자(에라토스테네스·브라마굽타·알콰리즈미·디오판토스·데카르트) — 이미 MathTelling에서 사용 중

### 과목별 변주
- 한국사·세계사 → 사료 인용 박스 (사상·서적·일화) 비중 ↑
- 과학사 → 실험·도구 시각화 (interactive) 비중 ↑
- 수학사(MathTelling) → 수학 언어 메타 학습 결합 (이미 진행 중)

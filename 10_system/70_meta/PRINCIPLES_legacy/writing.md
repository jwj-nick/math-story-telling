## W1. 글자수 카운터 (char-counter)

- 글자 수 제약이 있는 모든 양식 (예: 견해문 300~500자, 논술 120~160자)
- 공백 포함·비포함 동시 표시
- 범위 안에 들어가면 색 변경 (회색→초록)

```js
function countChars(text) {
  const total = text.length;
  const nonSpace = text.replace(/\s/g, '').length;
  return { total, nonSpace };
}
```

## W2. 논거 구조 카드

- 주장 → 근거 → 사례 3단 구조
- 학생이 자기 논거 채우는 빈칸 카드 (점진적 공개 + 빈칸 유지)

## W3. 교과 개념·핵심어 참조

- 단원 핵심어 자동 매핑 (예: 통합사회 V단원 개념어 8개)
- 글쓰기 도중 클릭하면 정의·예시 토글

## W4. 발표문일 때 추가

- 시간 배분 가이드 (도입·전개·결론 1:2:1)
- 발음·강조 노트 (대본형)
- 슬라이드와 1:1 매핑 표

## W5. 모범답안 + 평가 기준

- 채점 기준 (창의성·논리성·표현력·구성)
- 좋은 예 / 나쁜 예 대조
- "내 글" 자가 진단 체크리스트

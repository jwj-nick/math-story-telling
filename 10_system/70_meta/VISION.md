# 10_VISION — 비전·우선순위·3대 원칙

## 한 줄 비전

> **시간·노력은 거의 같지만, 흥미·생각의 깊이·지식 수준이 훨씬 높아지는 학습 환경**

## 최종 목표

1. **단기 (지금~3개월)**: 시험·수행평가별 도우미 앱을 빠르게 만들어 효율 ↑, 점수 ↑
2. **중기 (3~12개월)**: 패턴이 누적되어 새 과제도 비슷한 형태로 빠르게 생성 가능
3. **장기 (1년+)**: **아이가 직접** "이런 앱 필요해"라고 말하면 시스템이 80% 자동 생성 → 아이는 콘텐츠·생각에만 집중

## 3대 원칙

### 1️⃣ 점진적 공개 (Progressive Disclosure)

- 학생이 스스로 풀어나가는 흐름을 방해하지 않는다
- 답·힌트·결과를 미리 보여주지 않는다 (모범답안은 별도 페이지로)
- 출처: `40_PRINCIPLES.md` (수학 오답노트 앱에서 발견 → 비수학에도 적용 가능)

### 2️⃣ 빈칸을 의도적으로 남긴다

- "다 채워주면 학생은 채울 자리가 없어진다"
- 사회 Step 5/6 think-box, 한국사 정도전 심화 앱의 "평생 4질문" 같은 형태
- 학생의 글·답안·반응은 **수정 금지** (피드백은 별도 파일로)

### 3️⃣ 도구는 단순하게, 콘텐츠는 깊게

- 바닐라 HTML/CSS/JS — 빌드 X, 의존성 X (학생도 코드 열어볼 수 있음)
- KaTeX·JSXGraph만 외부 도입 (수학 한정)
- 한 앱 = 한 HTML 파일 원칙 유지 (배포·공유 쉬움)

## "성공"의 측정 (느슨하지만 정직하게)

| 지표 | 어떻게 본다 |
|---|---|
| 흥미 | 아이가 앱을 자발적으로 다시 열어보나? "이거 또 만들어줘"라고 하나? |
| 생각의 깊이 | 본인 답안에 "구조", "악순환", "역설", "왜" 같은 추상어가 등장하나? |
| 자율도 | 아이가 "이런 컴포넌트 가능?"이라고 묻기 시작하나? |
| 시간 효율 | 같은 분량 과제를 작년 대비 적은 시간에 더 깊게 처리하나? |

> 점수 그 자체는 부차적. 점수는 위 4가지가 충족되면 자연히 따라옴.

## "이 시스템이 없었다면"의 가상 시나리오

- 사회 수행평가 Step 1~6 → 각 시간 안에서 막연하게 6시간 보고서 작성, 점수 14~16/20
- 정도전 인물 분석 → 인터넷 요약만 보고 5점짜리 답안
- 수학 오답 → 풀이만 적고 똑같이 또 틀림

## "있을 때"의 시나리오 (현재)

- 사회 → Step별 앱으로 사고 구조 미리 설계, 본인 생각 포함된 답안, 기대 18~20/20
- 정도전 → 가이드/모범답안/심화 3축, 인물의 "왜"를 스토리로 이해, 평생 따라가는 질문 4개 확보
- 수학 → 오답노트 + 약점 태그 + 유형별 연습 9문 → 같은 실수 반복 안 함

> **핵심 차이는 "점수 1~2점"이 아니라 "생각의 결" 이다.**

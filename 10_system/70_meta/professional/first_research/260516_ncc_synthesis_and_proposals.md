## 4. 5개 문서가 *놓친* 영역 (NCC 진단)

### 4.1 콘텐츠 백본 — *세계관*이 없다
visual_identity는 *그림체*를 정의함. benchmark는 *형식*을 정의함. 그런데 **"이 시리즈가 한 권의 책이라면 그 책의 줄거리는?"** 이 미정.
- 단원 = 에피소드의 모음? (이러면 시즌 응집력 약함)
- 단원 = 한 큰 이야기의 챕터? (응집력 강하지만 설계 필요)
- → 제안 §5.1 참조.

### 4.2 *딸의 능동적 참여* 메커니즘 부족
vision은 딸을 *시청자·평가자*로만 둠. 더 능동적 역할은?
- "다음 주제 1개 제안" (있음, 약함)
- 영상 *작가/디자이너로 1편*? (없음)
- → 제안 §5.2.

### 4.3 *재무·시간 ROI* 추적
"24개월 후 4시간 자력 제작" 목표가 있는데 *측정 메커니즘*은 없다.
- 영상 1편당 실제 시간 기록 시트?
- API 비용 누적?
- → D11에 연결.

### 4.4 *부산물(by-product)* 전략 부재
visual_identity에서 만든 인물 일러스트·SVG·BGM이 영상 *외*로 쓰일 가능성 전혀 미언급.
- 같은 인물 시트 → 그림책, 슬라이드, 학습앱 캐릭터, 인쇄물.
- 이미 만든 자산을 영상으로만 소비하면 ROI 떨어짐.
- → 제안 §5.4, §5.7 참조.

### 4.5 *실패 카탈로그*
"이런 영상은 안 만든다" 안내는 있는데 "v1.5의 *실패 사례*"를 미리 정의하지 않음.
- 가령: "이 영상은 *우리 채널이 아니야*"를 판단하는 negative example.

## 5. 창의·상상력 제안 — 8개

> 5개 문서가 기존 카테고리(비전·정체성·스킬·기술) 안에서 움직임. 제안 8개는 그 카테고리 *바깥 또는 교차점*에 있음. 모두 채택 의무 없음. 마음에 드는 1~2개만 골라도 됨.

---

### 제안 §5.1. **"수학자의 편지함" — 시리즈 framing device**

모든 영상이 *공통 도입 3초*: "오늘 받은 편지는 ___로부터." 13인이 시간을 건너 우리에게 편지를 보냄. 시즌 1 = "고대편 다섯 통". 시즌 2 = "근대편" 등.

**왜 강력한가**:
- 시리즈 narrative arc 즉시 확보
- 인물 간 *연결* 가능 (디오판투스가 알콰리즈미를 언급, 등)
- "수학의 사람들" 채널명과 정합
- 양피지 톤(컬러 B)과 완벽 정합
- 0.3초 인식 가능한 *오프닝 의식* (Kurz의 비결과 같음)

**비용**: 무료. 첫 영상 1편 도입만 다시 만들면 됨.

---

### 제안 §5.2. **"회원 #001" — 딸을 *명시적 시청자*로 영상에 새기다**

영상 시그니처 한 구석에 "for Member #001" 같은 작은 마크. 익명·암호화 (가족만 의미 앎). Phase 2 공개 시 *시청자 누구든 #N으로 가입* 가능.

**왜 강력한가**:
- 딸이 *진짜 청중이라는 사실*이 영상의 진정성 자산이 됨
- Phase 2 공개 시 "이 채널은 *한 명의 딸*을 위해 시작됐다"가 마케팅 0순위
- 비밀 회원제 → 가족·친구 unlisted Phase 1에 자연 연결

**비용**: 무료. visual_identity §8 audit에 1줄 추가만.

---

### 제안 §5.3. **"Lab Notes" — 매 4편마다 메타 영상 1편 (시드 축적)**

시즌 1 4편 단위로 60초 "이 4편은 이렇게 만들었어요" 메타 영상. Phase 0/1 동안엔 unlisted. Phase 2 공개 시 *이미 5~7편의 메타 영상이 자산*.

**왜 강력한가**:
- Nick 비전 §7 "AI 워크플로우 자체가 콘텐츠" 콘셉트의 *현재 시드*
- 24개월 후 "갑자기 만든다"가 아니라 "쌓아온 것을 푼다"가 됨
- vision §4.2 월간 메트릭과 자연 연결 (회고 → 메타 영상 변환)

**비용**: 메타 영상 1편 = 1~2시간. 4주에 1번이면 시간 부담 적음.

---

### 제안 §5.4. **"수학 그림책" 트랙 — 영상의 *자매 출력***

같은 단원으로 영상(60s) + PDF 그림책(5~10page, 양피지 톤). 인물 시트·BGM 자산 100% 재활용. 딸은 *영상으로 한 번, 종이로 한 번* 만남.

**왜 강력한가**:
- 부산물 전략 (§4.4 누락 해소)
- 영상 60s = *너무 짧음*의 보완재. 그림책에 더 깊이.
- 인쇄 가능 → 교실, 도서관, 미래 출판 가능성
- visual_identity의 같은 그림체가 두 매체로 흐름 → 정체성 강화

**비용**: PDF 1편 = 4~6시간 추가. Phase 0-B 후반에 1편 파일럿 권장.

---

### 제안 §5.5. **"수학적 사물" — 인물마다 시그니처 *물건* 1개**

색뿐 아니라 *물건*도 시그니처화:
- 에라토스테네스 = 우물 / 그림자 / 막대
- 유클리드 = 컴퍼스
- 브라마굽타 = 모래·0의 점
- 알콰리즈미 = 균형 저울
- 디오판투스 = 묘비

영상 도입 0.5초에 *물건이 먼저 등장* → 0.3초 인식 강화.

**왜 강력한가**:
- visual_identity 원칙4(색)에 *형태* 추가 → 인식 가능성 ↑
- Phase 0-A에 13개 SVG 자산 추가 (이미 만든 14개에 추가 13개)
- 시그니처 색 + 시그니처 물건 = Kurz의 캐릭터 인식과 동급 효과
- 인물 일러스트 자체 학습(LoRA)이 어려운 시기에 *물건만으로 식별 가능*

**비용**: SVG 13개 = 2~3일.

---

### 제안 §5.6. **"Phase 0 캡슐" — 6개월 후 자신에게 보내는 영상**

Phase 0 시작할 때 Nick이 *비공개로* 60초 영상 1편 녹음: "지금 시작하는 이유, 우려, 기대". 6개월 후 재시청 + 답장 영상. Phase 2 공개 시 시청자에게 풀면 *진정성 자산*.

**왜 강력한가**:
- 도구·기술 학습이 아니라 *왜 만드는가*를 강제 명문화
- Exit/Pivot 결정(D12) 시 6개월 전 자기 의도와 비교 가능
- Phase 2 공개 콘텐츠로 *원천적 진정성* 확보
- 본업 RTL 엔지니어의 사명감이 자연스럽게 드러남

**비용**: 60s 영상 1편 = 2시간. 시즌 1 시작 전 *반드시* 권장.

---

### 제안 §5.7. **"Audio Story" 트랙 — 그림 없이 음성만 (Phase 2 검토)**

같은 단원을 5분 podcast 풀버전으로 따로 제작. ElevenLabs 보이스 그대로 사용. 듣는 학습자 (걷는 동안, 자기 전).

**왜 강력한가**:
- 영상 60~90s = 너무 짧음의 보완 (벤치마크 Mathologer "깊이 안 압축"의 한국 단편 버전)
- 영상 1편 만들 때 *나레이션 텍스트는 이미 풀버전*. podcast화 매우 저비용.
- 미래 다국어 더빙(tech §5.4 Rask AI)으로 글로벌 확장 가능
- 시각 정체성에 묶이지 않는 *제2의 트랙*

**비용**: 단원당 podcast 1편 = 30분 (나레이션 작성·녹음·편집). Phase 2 후반 검토.

---

### 제안 §5.8. **"문해력 노트" — 1페이지 인포그래픽 자동 출력**

영상의 핵심 4~5 visual + 1문장 quote → 1페이지 PDF/PNG로 *자동 추출*. 영상 못 본 사람도 5초에 흡수. 카톡·SNS·교실 인쇄 가능.

**왜 강력한가**:
- 영상 자산 100% 재활용 (인물 그림 + 핵심 한 줄)
- Phase 1 unlisted 공유 시 *링크 보내기 전에 미리보기* 역할
- 인스타그램·X 공유 가능 → Phase 2 공개 *전*에 자연스러운 *낚시*
- Motion Canvas로 영상 만들면 *마지막 프레임 PNG export*만 추가하면 됨

**비용**: 템플릿 1회 설계 = 2시간. 이후 영상당 자동 출력 5분.

## 0. 핵심 원칙 — 먼저 결론

**"도구를 줄여서 내재화한다"**

영상·앱 분야는 도구가 폭발적으로 많음. 매주 새 SOTA 도구가 나옴. 거기 휘둘리면 영원히 초보. 반대로:

- **한 스택을 1년 깊이 익히면** → 손에 붙음. 도구가 사라져도 원리가 남음.
- **TypeScript/React를 영상·앱 *공통* 코어로** → Motion Canvas + Remotion + 일반 웹앱이 모두 같은 언어.
- **AI 도구는 *교체 가능한 부품***으로 취급. 핵심 스킬은 *워크플로우 설계*.

이건 Nick의 RTL 배경과 정합함. RTL도 SystemVerilog 한 언어 깊이 익히는 게 새 HDL 따라가는 것보다 가치 큼.

---

## 1. 스택 청사진 (목표 상태)

```
[코어 언어]      TypeScript / React
                      ↓
[영상 트랙]     Motion Canvas (스토리·인물)
                Manim (수학 시각화, 선택)
                      ↓
[앱 트랙]       React + Vite (인터랙티브 학습 앱)
                      ↓
[공통 자산]     SVG 라이브러리, 컬러 팔레트, 폰트
                      ↓
[AI 도구]       Claude Code (워크플로우 자동화)
                ElevenLabs (TTS)
                Stable Diffusion + ControlNet (이미지)
                      ↓
[배포]          ffmpeg (영상), Vercel/local (앱)
```

**의도된 비대칭**: 영상·앱 양쪽이 같은 TS/React 기반. 한 번 익힌 게 양쪽에 다 쓰임.

## 2. 단계별 로드맵

### 2.1 Phase 0-A : 0~3개월 (v1.5 안정화)

**목표**: 현 v1 스택을 *벗어나지 않고* 품질만 1.5배.

| 영역 | 도입 | 학습 시간 | 산출 |
|---|---|---|---|
| TTS | ElevenLabs ($5/월 plan) | 4h | 인물별 보이스 13인 매핑 |
| AI 이미지 | DALL-E 3 또는 Firefly (API) | 8h | 인물 일러스트 13장 |
| 음악·SFX | Freesound + YT Audio Library | 4h | BGM 라이브러리 5곡 |
| 페르소나 audit | `/se_audit_*` 4개 스킬 작성 | 6h | 자동 1차 리뷰 |
| 영상 길이 | 60~90초로 확장 | (각 영상에 분산) | 시즌 1 4편 |

**도구 추가 = 4개. 그 외 *전혀* 새 도구 안 건드림.** v1 코드는 그대로.

**Anti-pattern**: 이 시기에 Motion Canvas나 Manim 손대지 말 것. 유혹 강함. 참아야 함.

### 2.2 Phase 0-B : 3~6개월 (시즌 1 완주)

**목표**: 시즌 1 (5단원 × 4편 = 20편) 완성.

이 시기 핵심은 *새 도구 학습이 아니라 반복*. 같은 스택으로 16편 더 만들기. 16번 만들면 손에 붙음.

| 활동 | 의도 |
|---|---|
| 시즌 1 16편 추가 제작 | 워크플로우 내재화 |
| 매 4편마다 자체 회고 (retro) | 무엇이 느려졌나? 자동화할 부분? |
| Claude Code 스킬 다듬기 | hw-agent-core 패턴 적용 |
| 페르소나 audit 신뢰도 평가 | NCC가 놓치는 것 잡는지 |

**Phase 0-B 끝 시점 자가 평가**:
- 1편 제작 시간이 처음 대비 절반 이하인가?
- 페르소나 audit 결과를 실제로 반영하는가?
- 본인 영상 스타일을 *말로 설명할 수 있는가?* (이게 안되면 visual_identity_guide 다시 봐야 함)

### 2.3 Phase 1 : 6~12개월 (Motion Canvas 파일럿 + 앱 통합)

**목표**: 새 트랙 1개 추가. 기존을 *대체하지 않고* 병행.

| 활동 | 시간 예산 | 목표 |
|---|---|---|
| Motion Canvas 학습 | 주 5h × 4주 = 20h | 튜토리얼 완주 + 1단원 재제작 |
| 시즌 2 초반 6편: 기존 스택 | 주 7h | 페이스 유지 |
| 시즌 2 후반 6편: Motion Canvas | 주 9h | 새 스택 실전 |
| React 인터랙티브 앱 통합 | 주 3h × 8주 | 영상 → 앱 → 영상 1세트 |

**Phase 1 끝**: Motion Canvas가 GSAP보다 빠르고 좋아진 시점이면 v1 폐기. 아니면 병행 유지.

### 2.4 Phase 2 : 12~24개월 (선택적 심화)

이 시점엔 본인이 알 거임. 가능한 방향 (택 1~2):

- **A. Manim 도입**: 수학 시각화 깊이. (단, 학습 곡선 큼. 정말 필요한지 검토)
- **B. SD + LoRA**: 캐릭터 일관성. 인물 시리즈 확장.
- **C. 실사 + AI 합성**: Veo-style 워크플로우.
- **D. 인터랙티브 앱 깊이**: Three.js, Pixi.js로 더 풍부한 학습 앱.
- **E. 자동화 심화**: 본인 hw-agent-core 패턴을 영상 파이프라인 전체로.

**권고**: B + D 조합. A(Manim)는 매력적이지만 ROI가 의외로 낮을 수 있음. 본인 채널은 인물 서사 중심이므로.

## 4. 매일 1~2시간 — 시간 분배 가이드

주 평균 10시간 가정:

| 활동 | 주간 시간 | 비고 |
|---|---|---|
| 영상 제작 (실작업) | 5~6h | 1주 1편 페이스 |
| 학습 (새 도구/원리) | 2~3h | Phase별 위 표 따름 |
| 회고·기록 (마크다운 문서화) | 1h | Nick 강점이자 자산화 |
| 딸과 함께 보기·대화 | 0.5h | 영상 시청 시간 포함 |

**중요**: 매주 회고 1h를 *반드시* 확보. 이게 본업 RTL의 *코드 리뷰*에 해당. 안 하면 내재화 안됨.

## 5. 학습 안티패턴 — 피할 것

1. **"새 도구가 더 좋대" 충동** → Phase 0 완주 전에는 봉인.
2. **튜토리얼만 보고 만족** → 항상 *실제 단원에 적용*까지 가야 학습 완료.
3. **완벽주의** → v1.5 영상이 v1보다 못해도 *공개*(가족에게)하고 다음 가기.
4. **양산만 하고 회고 안함** → 16편 만들고도 늘지 않는 함정.
5. **AI에 100% 의존** → 한 번은 *전 과정 손으로* 해봐야 자동화의 가치도 보임.

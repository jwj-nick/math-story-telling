## 0. 왜 이게 도구보다 먼저인가

Kurzgesagt가 알아보이는 건 After Effects 때문이 아님. **5가지 정해진 시각 규칙**을 5년간 어긴 적이 없기 때문임.

3Blue1Brown도 Manim 때문이 아님. 검은 배경, 차분한 컬러, 일정한 폰트, 절제된 모션 — 이 일관성.

우리도 같은 일관성을 *처음부터* 정해야 시즌 1 20편이 *같은 채널의 영상*으로 보임. 안 그러면 20편이 20개 스타일로 흩어짐.

---

## 1. 채널의 5가지 시각 원칙 (잠정)

> **이 5개는 모든 영상에서 어기지 않음.** 어기면 그 영상은 폐기.

### 원칙 1. 어두운 배경, 따뜻한 강조
- 베이스: 짙은 남색 또는 짙은 회색 (`#0F1419` 같은 톤)
- 강조: 황금색 / 부드러운 오렌지 (`#F4B95C` 같은 톤)
- 이유: 학습 영상은 *오래 봐도 눈이 안 아파야* 함. 흰 배경은 30분 보면 피로.

### 원칙 2. 한글 폰트 1종, 영문 폰트 1종 — 끝
- 한글: **Pretendard** (변형 풍부, 한글 가독성 최강)
- 영문/수식: **JetBrains Mono** 또는 **Inter**
- 다른 폰트 절대 안 씀. 강조는 굵기·색·크기로만.

### 원칙 3. 절제된 모션
- 모든 animation = ease-in-out (선형 안 씀)
- 평균 모션 길이: 0.4~0.8초 (너무 빠르면 못 따라옴, 너무 느리면 지루)
- 동시 모션 객체 ≤ 3개
- 회전·번쩍임 효과 금지 (학습 방해)

### 원칙 4. 인물은 실루엣 + 시그니처 색
- 사실적 일러스트 X (캐릭터 일관성 어려움)
- 실루엣 또는 단순화된 캐릭터 + 인물별 시그니처 색 1개
- 예: 에라토스테네스 = 황토색, 가우스 = 청록, 아르키메데스 = 금색
- 인물이 13명이어도 *같은 일러스트 룰*로 그려져야 함

### 원칙 5. 수학식은 정렬되고 정확하게
- LaTeX 렌더 (Motion Canvas / KaTeX)
- 손글씨 폰트 X
- 식이 등장할 땐 *왜 이 식인지* 화면에 함께 (식만 띄우지 않음)

## 2. 컬러 팔레트 (잠정 3개 후보)

선택해야 함. 한 개 고르면 24개월 어김 없이 사용.

### 후보 A: "별이 빛나는 밤" (어두운 남)
```
배경     #0F1A2E
서브배경 #1B2A4A
텍스트   #E8E6E3
강조1    #F4B95C  (황금)
강조2    #6B9BD8  (하늘)
강조3    #C77B5A  (테라코타)
```
**톤**: 차분한 학자. 3Blue1Brown 계열.

### 후보 B: "양피지" (따뜻한 어두움)
```
배경     #1F1814
서브배경 #2E2620
텍스트   #F0E6D2
강조1    #C9A66B  (양피지 금)
강조2    #8FAE7B  (이끼 초록)
강조3    #B85450  (붉은 인주)
```
**톤**: 역사·고전. 인물 서사에 어울림.

### 후보 C: "디지털 새벽" (짙은 회청)
```
배경     #14181F
서브배경 #1F2530
텍스트   #E5E9F0
강조1    #88C0D0  (사이안)
강조2    #EBCB8B  (앰버)
강조3    #BF616A  (코랄)
```
**톤**: 모던 테크. 본인 HW 배경과 정합.

**NCC 권고**: **후보 B**.

이유: "수학의 사람들" 비전 = 인물·역사 중심. B의 양피지 톤이 콘셉트와 가장 정합. 또 한국 학생에게 다른 수학 채널과 *겹치지 않는* 톤 (대부분 흰 배경 또는 모던 다크 사용).

## 3. 타이포 시스템

```
H1 (단원 제목)    Pretendard ExtraBold  56pt
H2 (장면 헤더)    Pretendard Bold       40pt
본문 자막         Pretendard Medium     28pt
강조 자막         Pretendard Bold       32pt
수식 (LaTeX)      Computer Modern       자동
영문·숫자         JetBrains Mono        28pt
```

**자막 규칙**:
- 한 화면에 ≤ 2줄
- 줄당 ≤ 20자 (한글)
- 등장 0.3s fade-in, 퇴장 0.2s fade-out
- 자막 vs 나레이션 *불일치* 금지 (같은 문장)

## 4. 모션 원칙 (디테일)

### 4.1 timing
- ease-in-out 기본
- 강조 진입 = `cubic-bezier(0.4, 0, 0.2, 1)` (Material Design 곡선)
- 빠른 변환 0.3s / 중간 0.6s / 느린 1.0s — 3단계만

### 4.2 화면 분할
- 1/3 황금비율 그리드 기본
- 좌측 = 시각, 우측 = 텍스트 (또는 반대)
- 가운데 단독 강조 = 클라이맥스 장면에만

### 4.3 카메라 (의사 카메라 이동)
- 줌인·줌아웃 = 한 영상에 ≤ 2회
- 팬 = ≤ 3회
- 회전 = 0회 (특별한 경우 외)

## 5. 시그니처 사운드 (음악·SFX)

영상 정체성의 30%는 *소리*. 시각만큼 중요.

### 5.1 시그니처 인트로 (3초)
- 채널 로고 + 짧은 멜로디 3초
- *모든 영상*에 동일 사용
- 후보: 직접 작곡 (간단한 4-note 모티프) / Mubert AI 생성 / 의뢰

### 5.2 배경 음악 라이브러리
- 5~7곡, 분위기별 분류:
  - 차분 (intro·conclusion)
  - 호기심 (질문 던질 때)
  - 발견 (a-ha 순간)
  - 긴장 (도전·난관)
  - 평온 (정리·마무리)
- 각 곡 30s~2min, 자연스러운 loop
- 출처: YT Audio Library + Freesound CC

### 5.3 SFX 라이브러리
- 글자 등장 = 부드러운 "탁"
- 강조 = 짧은 chime
- 전환 = whoosh (절제해서)
- 절대 안 씀: 만화풍 효과음, 박수, 폭발음

## 6. 인물 디자인 시스템

13인을 *한 스타일*로 그릴 규칙:

| 요소 | 규칙 |
|---|---|
| 형태 | 실루엣 또는 단순화된 측면 |
| 비율 | 머리:몸 = 1:5 (성인) / 1:4 (소년) |
| 디테일 | 옷 1특징, 액세서리 1개까지 (안경/모자/펜) |
| 색 | 시그니처 색 1 + 배경 색 1 |
| 크기 | 화면 세로의 1/2 ~ 2/3 |
| 표정 | 미세 (눈썹·입꼬리만) — 강한 표정 금지 |

**도구**: Phase 0 = DALL-E/Firefly로 시드 13장 → Inkscape로 단순화 / Phase 2 = SD + LoRA로 일관성 확보.

## 7. "이 채널의 영상은 X하다" 한 문장

이게 굳어지면 시각 정체성 완성:

> *"양피지 톤의 어두운 화면에, 절제된 모션과 깊은 음성으로, 한 명의 수학자를 친구처럼 만나는 60~90초."*

채널 소개 페이지에 그대로 쓸 수 있는 문장. 흔들릴 때 돌아갈 기준점.

## 8. 검증 — 시각 정체성 audit 체크리스트

영상 완성 후 매번 자문:
- [ ] 배경·텍스트 색이 팔레트 안에 있는가?
- [ ] 폰트가 2종 (한+영) 안에서만 사용되었는가?
- [ ] 모션 길이가 0.3~1.0s 안인가?
- [ ] 동시 움직임 객체 ≤ 3개인가?
- [ ] 시그니처 인트로 3초가 들어갔는가?
- [ ] 자막 줄당 ≤ 20자, 한 화면 ≤ 2줄인가?
- [ ] 인물이 실루엣·시그니처 색 규칙을 지키는가?

이 7개 통과해야 *우리 채널의 영상*.

## 발췌의 운영 규칙

- 원본은 SSOT. 발췌는 작업 메모리.
- 원본 변경 시 본 폴더 갱신 의무 X — 참조용 snapshot.
- 발췌 자료는 **옛 표기** (이전 대화에서 사용된 약어·기호) 를 그대로 포함. 자연어 풀이는 `INTEGRATED_PLAN.md` 에만 존재.
- 일반 사용 시 발췌 직접 읽지 않아도 된다. INTEGRATED_PLAN 만으로 충분.
- 발췌가 필요한 경우: 사실 자료 직접 확인 (예: 1편의 정확한 SSML 패턴), 출발점 대화 맥락 추적, 외부 자료 원본 위치 찾기.

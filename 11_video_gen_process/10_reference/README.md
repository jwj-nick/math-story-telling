# 10_reference — 외부 자료 발췌

원본은 `../../` 안. 본 폴더는 sub-project 작업 시 **자주 참조하는 핵심만 발췌**.
원본 path 는 `_origin.md` 에 명시. 원본 변경 시 본 폴더 갱신 의무 X — **참조용 snapshot**.

## 현 발췌

| 파일 | 내용 |
|---|---|
| `_origin.md` | 모든 원본 path index + 발췌 일자 |

## 발췌 방식 표준

각 발췌 파일은 다음 3섹션:
1. **원본 path** + 발췌 일자
2. **핵심 정리** (NCC 정제, 그대로 복사 X)
3. **NCC 추가 분석·의견** (명시적으로 라벨)

원본 = SSOT. 발췌는 sub-project 의 working memory.

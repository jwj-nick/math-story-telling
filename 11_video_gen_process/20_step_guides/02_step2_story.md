## 0. STEP 2 의 한 문장

> **서사라는 "광산 (~1900자)" 에서 영상이라는 "보석 (~550자 × 6장면)" 을 깎아내는 단계.**
> 깎는 기준은 두 가지뿐 — *시간 (110~140초)* 과 *약속 3겹*. 둘 중 하나라도 무너지면 다음 단계 전부가 흔들린다.

# 1. Step 개요

## 1.1 무엇을 하는가

STEP 1 [서사] (`se-people-narrate`) 가 만든 **인물 서사 원료** 는 길다. exp-002 에라토스테네스 서사는 §1~§7 + 부록 4 = 약 1900자였다. 이걸 그대로 영상으로 만들면 6분짜리 다큐가 된다. 학습자 (중1 딸) 는 끝까지 보지 못한다.

STEP 2 [스토리] 는 이 원료를 **영상 1편 분량의 "스토리 시드"** 로 압축한다. 결과물은:

- **6장면** (S1~S6) 으로 구조화
- 각 장면 = 시간 + 시각 단서 + 나레이션 시드 + 운반 약속 + 전환
- 총 **110~140초** (exp-002 = 110초)
- 총 나레이션 **~550자** (5자/초 기준)

이 스토리 시드가 STEP 3 [스토리보드] 의 **직접 입력** 이 된다.

## 1.2 4축 중 어디에 기여하는가

| 축 | 기여 | 정도 |
|---|---|---|
| **B. 흥미 유발** | 직접 기여 — 영상 흥미의 *극적 구조* 가 여기서 정해진다 | ★★★★★ |
| **A. 개념 이해** | 간접 — S3 같은 "수학 연결 장면" 의 그릇을 만들지만 개념 자체는 앱·문제 트랙이 백본 | ★★★☆☆ |
| C. 수학 언어 | 거의 무관 (영상은 흥미 강화의 보조, INTEGRATED_PLAN §1.3) | ★☆☆☆☆ |
| D. 문제 연습 | 무관 | — |

영상 트랙 전체가 **축 B (흥미)** 를 위해 존재한다. STEP 2 는 그 흥미를 *극적 곡선* 으로 설계하는 핵심 지점이다.

## 1.3 8단계 파이프라인에서의 위치

```
STEP 1 서사 ──▶ ★STEP 2 스토리★ ──▶ STEP 3 스토리보드 ──▶ STEP 4 나레이션 ─┐
 (~1900자)      (6장면 / ~550자)      (정밀 카드 + 카메라)    (음성 mp3)      │
                                                                            ▼
                                  STEP 8 합성 ◀── STEP 7 렌더 ◀── STEP 6 모션 ◀── STEP 5 이미지
```

- **선행 (입력)**: STEP 1 `1-narrative.md` (특히 부록 B = "다음 단계 [스토리] 입력 명세" 가 § → S 매핑 안을 미리 제공)
- **후행 (출력 수요자)**: STEP 3 스토리보드가 이 시드의 6장면을 받아 카메라·음향·자막을 입힌다. exp-002 `3-storyboard.md` §0.1·§0.2 가 그 증거 — 스토리 시드의 "S2·S4 에 에라토스테네스" 정보를 받아 캐릭터 reference 1장 전략을 세웠다.

## 1.4 이 step 의 본질적 난제 (2개)

| # | 난제 | 본질 |
|---|---|---|
| **난제 1** | **압축의 정보 손실** | 1900자 → 550자 = **71% 를 버린다.** 무엇을 버리고 무엇을 남기는가가 STEP 2 의 전부. 잘못 버리면 약속 3겹 중 하나가 죽는다. exp-002 는 §5 (노년 시력 상실) 를 통째로 버렸고, 그 대가로 약속 2 (정서) 가 S2 한 장면만 운반하게 됐다 — 이건 *의도된 trade-off* 였다 (어두움 회피 우선). |
| **난제 2** | **두 제약의 동시 만족** | 시간 (110~140초) 과 약속 3겹은 서로 당긴다. 약속을 충실히 운반하려면 장면이 길어지고, 시간을 지키려면 약속을 압축해야 한다. exp-002 는 S3 (필연성 핵심) 에 25초를 몰아주고 S1·S2·S6 을 15초로 깎아 균형을 맞췄다. |

# 2. Workflow (절차)

## 2.1 입력 align → 처리 → 출력 흐름

```
[입력 5+1] ──▶ S1 align ──▶ S2 Q&A 보강 ──▶ S3 §→장면 매핑
                                                    │
                                                    ▼
[출력 시드] ◀── S7 평가+출력 ◀── S6 글자수·시간 검증 ◀── S5 약속 배치 검증 ◀── S4 장면 카드 초안
```

## 2.2 실제 동작 순서 (S1~S7)

`se-video-story` SKILL.md 가 정의한 7개 동작. exp-002 에서 실제로 거친 순서 그대로다.

| 동작 | 무엇 | exp-002 실제 |
|---|---|---|
| **S1 입력 align** | 입력 5+1 확인, 누락 식별. 특히 서사 *부록 B* (§→S 매핑 안) 확인 | `1-narrative.md` 부록 B 에 이미 6장면 매핑 안이 있었음 → S3 의 부담 대폭 감소 |
| **S2 Q&A 보강** | A5 톤 미정 시 결정 / baseline 참조 여부 / 한 단어 압축 confirm | 톤 = *이야기 톤* 잠정 / baseline *미참조* (외부 의존 0) / 한 단어 = **정리** confirm |
| **S3 §→장면 매핑** | A4 장면 수(6) 와 서사 § 수(7) align. 불일치 시 통합·분할 | §7개 → 6장면. **§6+§7 → S6 통합**, §5 (노년) *드롭*. §1~§4 = S1~S4 1:1 |
| **S4 장면 카드 초안** | 각 장면 5~6 요소 작성 (시간/시각/나레이션/약속/전환/[자막]) | 6장면 카드 작성. S3=25s, S4=20s 가중. 나머지 15~20s |
| **S5 약속 배치 검증** | 부록 A 표 (행=약속, 열=장면 + 강도 합). 합격 기준 대조 | 약속1 ★5 / 약속2 ★4 (1장면 — *약점 플래그*) / 약속3 ★★★★★★ (4장면 — *최강*) |
| **S6 글자수·시간 검증** | 부록 B 표 (장면별 자수/시간/속도). 5자/초 ±10% | 정확히 550자 / 110초 / 평균 5.0자/초 ✅ |
| **S7 평가+출력** | 부록 A~D 작성 후 `2-story-seed.md` 출력 | 부록 A (약속) / B (글자수) / C (다음 단계 명세) / D (한계+retrospective) |

## 2.3 의사결정 포인트 (분기)

STEP 2 에는 **3개의 분기점** 이 있다. 각각이 결과물을 크게 바꾼다.

| 분기점 | 위치 | 옵션 | exp-002 선택 | 영향 |
|---|---|---|---|---|
| **분기 ①: 톤** | S2 | 이야기 / 다큐 / 혼합 | 이야기 톤 (잠정) | 나레이션 시드 어조 결정 |
| **분기 ②: §→S 통합·분할** | S3 | § > A4 → 통합 / § < A4 → 확장 / § 드롭 | §6+§7 통합 + §5 드롭 | *무엇을 버리는가* — 정보 손실의 핵심 |
| **분기 ③: 약속 미달 보강** | S5 | 약속 강도 미달 시 추가 장면 vs 통과 | 약속2 1장면 *통과* (영상 본질 = 시대+발견 중심 판단) | 약속 운반 균형 |

> **분기 ② 가 STEP 2 의 진짜 무게중심이다.** "무엇을 남길까" 가 아니라 **"무엇을 버려도 약속 3겹이 산다고 판단하는가"** — 이 판단이 영상의 질을 가른다.

## 3.2 외부 도구 — 거의 없음 (STEP 2 의 특징)

STEP 2 는 **순수 텍스트·구조 작업** 이다. TTS·이미지·FFmpeg 같은 외부 도구가 *전혀 필요 없다*. 이 점이 STEP 4~8 과 결정적으로 다르다.

| 도구 | STEP 2 사용 | 비고 |
|---|---|---|
| TTS (ElevenLabs / Google) | ❌ | STEP 4 의 영역 |
| 이미지 (Midjourney 등) | ❌ | STEP 5 의 영역 |
| FFmpeg | ❌ | STEP 7~8 의 영역 |
| WebSearch / WebFetch | △ (희귀) | 시대 풍경 reference, 인물 외형 부족 시만 |

→ **STEP 2 는 도구 의존이 0 에 가까워 자동화·재현이 가장 쉬운 단계.** 동시에 "도구가 못 도와주는, 순수 판단의 단계" 이기도 하다. 압축·약속 배치는 사람·LLM 의 *서사 감각* 에 전적으로 달려 있다.

## 3.4 agent 활용

STEP 2 는 **agent 위임 없이 NCC 직접 동작**. STEP 1 [선정] 의 동작 4·5 (리서치+평가) 가 백그라운드 agent 에 위임된 것과 대조적. 이유: STEP 2 는 외부 리서치가 거의 없고, 약속 배치는 정체성 결정 (§8) 과의 *대화* 라 위임보다 직접 판단이 빠르다.

# 4. User Input (Nick 입력)

## 4.1 무엇을 / 언제 / 어떤 형식으로

| 시점 | Nick 입력 | 형식 | 필수/선택 |
|---|---|---|---|

| S2 보강 | 톤 (A5) 미정 시 결정 | 이야기 / 다큐 / 혼합 | 필수 (잠정 가능) |
| S2 보강 | baseline 참조 여부 | 미참조 / 참조 / 비교 | 선택 |
| S2 보강 | 한 단어 압축 confirm | 단어 그대로 / 변경 / NCC 제안 채택 | 필수 |
| S7 후 | 스토리 시드 통검토 | "all ok" / 수정 지시 | 필수 |

## 4.2 HITL (사람 개입) 지점

exp-002 에서 Nick 의 실제 개입은 **2지점** 이었다:

1. **S2 보강** — 톤·baseline·한 단어 confirm (1회 Q&A)
2. **S7 후 통검토** — "all ok" (retro-2-story §1 의 "1 라운드 통검토" 패턴)

STEP 1 [선정] 의 5라운드 frontmatter Q&A → STEP 2 는 **1라운드 통검토로 단축** 됐다 (retro-2-story §1). 이건 STEP 1 frame 이 정상 작동한다는 증거이자, STEP 2 가 STEP 1 보다 *판단 표면적이 작다* 는 뜻이다 (압축 기준이 시간·약속 2개로 명확).

## 4.3 필수 vs 선택 입력의 본질

- **필수** = 약속·시간·톤 — 영상의 *정체* 와 직결. 비면 압축의 기준이 사라진다.
- **선택** = baseline 참조 — 외부 의존 0 frame (PURPOSE) 때문에 exp-002 는 *미참조*. 다음 단원에서 참조 효과 측정 예정 (retro-2-story §2 항목 3).

# 6. 현재 구현 (exp-002 실제 사례)

## 6.1 unit01 (에라토스테네스) 실제 6장면 배치

exp-002 `2-story-seed.md` §0 의 실제 장면 구조 — **이것이 STEP 2 의 가장 구체적인 표본** 이다:

|---|---|---|---|---|
| S1 | 15s | 도서관 풍경 | 1 시대 감각 ★★★★★ | §1 |
| S2 | 15s | 베타 + 도서관 관장 | 2 인물 정서 ★★★★☆ | §2 |
| **S3** | **25s** | **분류 본능 → 소수의 체** ★ | **3 필연성 핵심 ★★★★★** | §3 |
| **S4** | **20s** | **아르키메데스 편지** ★ | 3 필연성 보강 + 1 시대 | §4 |
| S5 | 20s | 유클리드 + 류후이 (대비 카메오) | 3 필연성 확장 + 1 시대 | §6 |
| S6 | 15s | 인류 두 번 도달 + "정리" | 3 클로징 + 한 단어 압축 | §6+§7 |

**총 110s / ~550자 / 약속 3 = 4장면 (S3·S4·S5·S6) 운반.**

핵심 관찰:
- **시간 가중**: S3 (25s) + S4 (20s) = 45초 = 전체의 41%. 약속 3 (필연성) 의 두 핵심 장면에 시간을 몰아줬다. 이것이 결정 2 가 진단한 "옛 1편의 약속 3 약점" 을 보강한 방식 (INTEGRATED_PLAN §8 결정 2).
- **§5 드롭**: 노년 시력 상실 (§5) 은 통째로 버려졌다. 약속 2 (정서) 의 두 번째 장면이 될 수 있었으나, "너무 어두움 + 후세 전승" 이라 *어두움 회피* 가 우선됐다 (부록 D).

## 6.2 실제 겪은 시행착오·결정

| 결정 | 내용 | 근거 |
|---|---|---|
| **§6+§7 → S6 통합** | 서사 §7개를 6장면에 맞추려 §6 후반 + §7 (한 단어 "정리") 을 S6 하나로 묶음 | A4=6 제약. retro-2-story §2 항목 4 = "§-S 매핑 규칙 명문화 필요" |

## 6.3 현재 구현의 강점과 한계

**강점**
- 약속 3 (필연성) 운반이 4장면 = ★★★★★★ — **옛 1편 약점을 명확히 보강** (결정 2 의 목표 달성)
- 글자수·시간 정확히 적중 (550자 / 110초 / 5.0자/초)
- 부록 C 가 다음 단계 인터페이스로 깔끔히 작동 (3-storyboard 가 바로 받음)

**한계** (부록 D + retro-2-story §4)
- **약속 2 (정서) S2 1장면만** — 영상이 인물의 *사람됨* 보다 *발견* 에 기운다. 다음 인물 (브라마굽타 등) 에서 정서 비중이 다를 수 있음 → 정체성 §5.1.2 보강 검토
- **§3 인과 미검증** — NCC 해석이 학설인지 미확인. 약속 3 핵심 장면의 토대가 *해석* 위에 서 있음
- **NCC 직접 동작** — 외부 호출 패턴 (다른 사람·세션이 SKILL.md 만으로 같은 결과를 내는가) 미검증. exp-003 에서 실증 필요
- **출력 양식 = NCC 임의 결정** — 장면 카드 sub-section 4 vs 5 미확정 (retro-2-story §2 항목 1)

# 8. 고급 Workflow (상상력·창의력)

> **STEP 2 는 "압축" 으로 보이지만 본질은 "극작 (dramaturgy)" 이다.** 6개의 장면은 단순한 정보 6조각이 아니라 *긴장 곡선을 그리는 6박자* 다. 여기서는 영화·게임·교육공학의 검증된 구조를 차용해 STEP 2 를 한 단계 끌어올린다.

## 8.1 장면 구조의 드라마투르기 — 기승전결 + 긴장 곡선

exp-002 의 6장면을 *극적 구조* 로 다시 읽으면:

| S | 극적 역할 | 긴장도 | 기승전결 |
|---|---|---|---|
| S1 도서관 풍경 | **세계 제시** (establishing) | 낮음 (몰입 시작) | **기** |
| S2 베타 + 관장 | **인물 소개 + 긴장 씨앗** ("2등" = 미묘한 결핍) | 살짝 상승 | **기→승** |
| S3 분류 → 소수의 체 | **전환점** (인물의 본능이 수학으로) | **상승** | **승** |
| S4 아르키메데스 편지 | **고조** (동시대 거장의 도전 = 외부 압력) | **정점 직전** | **전** |
| S5 유클리드·류후이 | **확장·울림** (인류가 같은 답에 두 번) | 정점 유지 | **전→결** |
| S6 "정리" 클로징 | **해소·여운** (한 단어로 압축) | 하강 (여운) | **결** |

**긴장 곡선 (이상형)**:

```
긴장
 ▲                      S4 ●━━● S5   ← 정점 (필연성의 클라이맥스)
 │                 S3 ●
 │            ●
 │      S2 ●               ● S6  ← 여운 (한 단어 해소)
 │  S1 ●
 └──────────────────────────────────▶ 시간
```

→ **고급 워크플로우 1**: STEP 2 출력에 **"긴장 곡선 (tension curve)" 그래프 (ASCII 또는 수치 배열)** 를 부록 E 로 추가. 장면별 긴장도 (0~10) 를 매기고, *단조 평탄* 하거나 *정점이 너무 일찍/늦게* 오면 경고. 게임 페이싱의 "intensity ramp" 차용.

## 8.2 결정적 순간 (S4) 설계 — "Sealing Moment"

exp-002 의 진짜 결정적 순간은 어디인가? 표면적 S4 (아르키메데스 편지) 이지만, 약속 강도로 보면 **S3 (필연성 핵심 ★5) + S4 (보강 ★4)** 가 *쌍* 으로 클라이맥스를 만든다.

영화 작법의 **"sealing moment" (관객이 인물을 영원히 기억하게 되는 한 장면)** 를 STEP 2 에 도입:

| 설계 원칙 | exp-002 적용 | 고급화 |
|---|---|---|
| **시각·청각 동시 정점** | S3 격자 애니메이션 + "소수의 체" 자막 | + 음향 ding (3-storyboard 가 추가) → STEP 2 가 *음향 단서까지 시드* 로 명시 |
| **시간을 *멈춤*** | S3 25초 = 최장 | "결정적 순간 직후 500~700ms pause" (TONE_STRUCTURE §8) 를 STEP 2 시드에 명시 |
| **나레이션 *떨림*** | (v0.1 미반영) | 톤 혼합 (A5) — S4 만 시적 톤. "결정적 순간의 떨림" 을 나레이션 시드에 마커로 |
| **한 컷 = 한 단어** | S6 "정리" | sealing moment 와 한 단어 압축을 *시각적으로 연결* (S3 격자에서 "정리" 글자가 자라나는 모션 시드) |

→ **고급 워크플로우 2**: 각 스토리 시드에 **"이 영상의 sealing moment 는 S__ 이고, 이유는 ___" 를 1줄 선언** 하게 강제. 결정적 순간이 *설계* 되었는지 *우연* 인지 구분된다.

## 8.3 약속 3겹을 장면에 녹이는 정교한 기법

현재 (exp-002) 는 약속을 장면에 *할당* (S1=약속1, S2=약속2...) 한다. 고급화는 약속을 *직조 (weave)* 한다 — 한 장면에 여러 겹을 겹친다.

| 기법 | 무엇 | exp-002 vs 고급 |
|---|---|---|
| **할당 (현재)** | 1 장면 = 주로 1 약속 | S2 = 약속 2 만 |
| **직조 (고급)** | 1 장면 = 2~3 약속 동시 | S4 = 약속 3 (필연성) + 약속 1 (시대) 이미 겹침 ✅. S2 도 약속 2 (정서) 위에 약속 1 (도서관 배경) 을 깔면 정서 약점 완화 |
| **복선·회수 (payoff)** | 앞 장면이 뒤 장면의 의미를 *완성* | S1 도서관 풍경 → S6 도서관 echo (이미 exp-002 가 사용! S6 "도서관 풍경 다시, S1 echo") — 이건 영화의 *bookend* 기법 |
| **삼겹 동시 정점** | sealing moment 에 약속 3겹 모두 터뜨림 | 이상형 — S3/S4 에서 시대(시각)+정서(인물 표정)+필연성(나레이션) 동시 |

→ **고급 워크플로우 3**: 약속 배치 검증 (S5) 을 *행렬* 로. 행=약속 3겹, 열=6장면, 칸=강도. "한 칸만 채워진 장면 (단일 약속)" 을 *최소화* 하도록 직조. exp-002 약속 2 약점 = 행렬에서 S2 한 칸만 채워진 결과.

## 8.4 다른 도메인 차용

### 영화 3막 구조 → 6장면 매핑

| 3막 | 비율 | 6장면 매핑 | exp-002 |
|---|---|---|---|
| **1막 설정** | 25% | S1~S2 (30s) | 도서관 + 인물 ✅ |
| **2막 대립·전개** | 50% | S3~S5 (65s) | 소수의 체 + 편지 + 동서 평행 ✅ (가장 긴 구간) |
| **3막 해소** | 25% | S6 (15s) | "정리" 클로징 ✅ |

→ exp-002 는 *무의식적으로* 3막 구조를 따랐다 (30/65/15 ≈ 27/59/14%). **고급화**: 이걸 *명시적 설계 원칙* 으로 SKILL.md 에 박아, 2막 (전개) 이 너무 짧거나 1막 (설정) 이 늘어지면 경고.

### 게임 페이싱 → 긴장 ramp + breather

게임 레벨 디자인의 "intensity ramp (긴장 상승) + breather (숨 고르기)" 를 적용:
- S1·S2 = breather (몰입·소개, 낮은 긴장)
- S3·S4 = ramp (긴장 급상승)
- S5 = peak hold (확장, 정점 유지)
- S6 = cooldown (여운)

→ 중1 학습자의 *주의 곡선* 과 일치. 110초 동안 긴장을 *유지만* 하면 피로하고, *평탄* 하면 이탈한다. ramp-hold-cooldown 이 흥미 (축 B) 의 페이싱 엔진.

### 교육 스토리텔링 → "호기심 갭 (curiosity gap)"

교육공학의 "호기심 갭 (질문을 먼저 던지고 답을 미룬다)" 을 장면 전환에 심는다:
- S2 끝 = "왜 2등인 사람이 역사에 남았을까?" (갭 열기)
- S3 = 답의 시작 (분류 본능)
- S6 = 갭 닫기 ("정리")

→ TONE_STRUCTURE v3 의 Q/A dialog 구조가 *바로 이 호기심 갭의 구현체*. Q (청소년) 가 갭을 열고 A (대학원생) 가 닫는다. STEP 2 가 dialog 를 시드부터 설계하면 호기심 갭이 구조적으로 보장된다.

## 8.5 "이상적이라면" 비전

> **이상적 STEP 2** = 서사 원료를 입력하면, LLM 이 (1) 약속 3겹을 *직조 행렬* 로 배치하고 (2) 긴장 곡선을 *3막 + ramp-hold-cooldown* 으로 설계하고 (3) sealing moment 를 *선언* 하고 (4) Q/A dialog turn 으로 나레이션 시드를 짠 뒤 (5) *3개의 대안 컷 (강조점이 다른)* 을 제시한다. Nick 은 셋 중 하나를 고르거나 섞는다. 압축은 자동, *극적 선택* 만 사람.

## 9.1 콘텐츠 질을 한 단계 올리는 구체 기법

| 기법 | 무엇 | exp-002 → 고급 |
|---|---|---|
| **구체 디테일 1개의 힘** | 추상 100마디보다 구체 1개 | "세계 지식의 중심" (추상) < "두루마리 50만 권" (구체). exp-002 §1 이 이미 사용 — STEP 2 가 압축 시 *추상을 버리고 구체를 남기는* 규칙화 |
| **숫자의 정서화** | 숫자를 *감각* 으로 | "BCE 250~212" (날짜) → "두 천재가 같은 하늘 아래 살아 서로에게 편지를 썼다" (S4 의 정서). 숫자 자막 + 정서 나레이션 병치 |
| **한 단어 닻 (anchor)** | 인물 = 1단어 (INTEGRATED_PLAN §9 원칙 5) | "정리" — S6 자막 + 나레이션 + (고급) S3 격자에서 자라나는 모션. *시각·청각·의미 삼중 각인* |
| **bookend (수미상관)** | 첫 장면 = 끝 장면의 변주 | S1 도서관 → S6 도서관 echo (exp-002 이미 사용). *같은 그림, 다른 의미* — 시작은 "장소", 끝은 "한 사람이 남긴 것" |

## 9.2 학습 효과·몰입·정서 연결 강화

중1 딸은 "수학에 흥미를 잃은" 학습자다. STEP 2 가 흥미를 *되살리는* 방법:

| 강화 축 | 기법 | 적용 |
|---|---|---|
| **몰입** | 호기심 갭 + Q/A dialog | Q (또래 청소년 목소리) 가 딸의 *대리인*. 딸이 궁금할 것을 Q 가 먼저 묻는다 — "왜요?" |
| **정서 연결** | 인물의 *결핍* 을 보여줌 | "베타 = 2등" 의 양면성 (S2). 1등이 아니어도 역사에 남은 사람 = *내성적이고 수학 중하위인 딸* 에게 닿는 메시지 |
| **자신감** | 발견의 *필연성* | "그 사람도 갑자기 천재라서 안 게 아니라, 책을 분류하던 본능이 수로 옮겨간 것" (S3) — 수학이 *특별한 사람만의 것이 아님* |
| **미완성 (think-box)** | 질문으로 끝내기 | INTEGRATED_PLAN §9 원칙 7 + A6 시청 후 행동 = "빈칸 think-box". S6 을 *완결된 답* 이 아니라 *여운/질문* 으로 닫기 |

→ **핵심**: STEP 2 의 약속 2 (정서) 약점은 *기술적 약점이 아니라 학습자 연결의 약점* 이다. 딸이 영상에 자기를 비추는 지점은 "베타 = 2등" 같은 *결핍의 정서* 다. exp-002 가 약속 2 를 1장면으로 줄인 건 다음 단원에서 *재고* 해야 할 우선 항목.

## 9.4 이 step 에서만 가능한 차별화 포인트

STEP 2 는 파이프라인에서 **유일하게 "전체 영상의 극적 형태" 를 결정하는 단계** 다. STEP 3~8 은 이 형태에 *살을 붙일 뿐* — 형태 자체를 바꾸지 못한다.

- **STEP 2 만의 권한**: 무엇을 버릴지 (drop), 어디를 정점으로 (peak), 무엇을 한 단어로 (anchor). 이 셋은 STEP 2 이후 *되돌릴 수 없다*.
- **차별화의 본질**: 다른 영상 채널은 "정보를 영상으로 옮긴다". 이 시스템은 STEP 2 에서 **"발견의 필연성" 을 극적 구조로 설계** 한다 (약속 3). 같은 에라토스테네스라도 "위인전" 이 아니라 "왜 그 사람이 그걸 발견할 수밖에 없었나" 의 *드라마* 가 된다 — 이것이 결정 2 의 약속 3 이 시스템에 박힌 이유.
- **수학 영상의 함정 회피**: 수학 영상이 흔히 빠지는 "개념 설명 = 강의 톤" 을 STEP 2 가 차단한다. S3 (수학 연결) 조차 *극적 전환점* 으로 설계되지 *수업* 으로 설계되지 않는다. "강의 톤 X / 함께 발견하는 톤 ✓" (TONE_STRUCTURE §3) 가 STEP 2 의 장면 설계 단계부터 강제되는 것.

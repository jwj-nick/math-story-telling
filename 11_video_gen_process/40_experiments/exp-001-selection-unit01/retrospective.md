## 2. 스킬 자체의 정련 필요 항목 (SKILL.md v0.1 → v0.2 시드)

### 2.1 동작 6 (Nick 검토 QnA) 의 위치 명확화 — ⚠️ 핵심

**현재 문제**: SKILL.md 동작 6 = "후보 제시 → Nick 선택·이견 확인". 그러나 본 시범 실행에서는 동작 6 이 *자동 생략* 되고 output 직접 작성으로 갔음. 백그라운드 에이전트가 Nick 과 직접 대화 불가능한 점이 원인.

**정련 안**:
- SKILL.md 에 **실행 모드 2종** 명시:
  - **인터랙티브 모드** (foreground, NCC 직접): 동작 1~7 모두 본 대화 안. 동작 2·6 의 QnA 본 대화로 진행.
  - **배치 모드** (background, 에이전트 위임): 동작 2·6 의 QnA 자동 생략. 출력 + 검토 라운드 분리. 동작 6 = "본 호출자 (NCC) 가 결과를 받아 본 대화에서 Nick 에게 제시" 단계로 격하.
- 본 시범은 배치 모드 — 동작 6 은 본 대화로 이동. retrospective + 동작 6 결과 정리 후 SKILL.md 갱신.

### 2.2 입력 #8 (학습자 반응) 의 default 동작 정의

**현재 문제**: 입력 #8 `.private/feedback/01_소인수분해/` 빈 디렉토리. 본 시범은 skip 처리. SKILL.md 에 default 동작 미명시.

**정련 안**:
- SKILL.md 동작 1 입력 align 항목에 명시: "디렉토리 빈 경우 = skip. 평가 (동작 5) 에 학습자 반응 항목 적용 X. 출력 (§4 다음 단계 입력 검증) 에 *학습자 반응 미반영* 명시."
- 첫 시범 후 학습자가 영상 볼 때 반응 수집 패턴도 SKILL.md 또는 별도 운영 양식에 정의.

### 2.3 자료원 도구 — WebFetch vs WebSearch

**현재 문제**: 백그라운드 에이전트 환경에서 WebFetch 차단됨 (permission denied). WebSearch 로 대체.

**정련 안**:
- SKILL.md `allowed-tools` 에 WebFetch 명시되어 있으나 환경별 동작 다름.
- 정련: SKILL.md 리서치 패턴 시드에 "도구 fallback 순서 = WebFetch → WebSearch → 내장 지식 + 자료원 명시" 추가.
- 학술 DB 자료 fetch 어려움 — Google Scholar 직접 fetch 불가. MacTutor / Wikipedia / Britannica 위주 진행. 약속 3 (필연성 서사) 자료는 1차 출처 (편지·서문·일화) 가 핵심이라 이들 사이트로 충분히 확보 가능 — 본 시범에서 확인.

### 2.4 신규 발굴 후보의 시즌 frame 처리 패턴

**현재 문제**: 메르센·페르마·가우스 등 시즌 frame 밖 인물 검토했으나 탈락. 본 시범에서 ad-hoc 처리.

**정련 안**:
- SKILL.md 평가 기준에 명시: "후보 평가 시 시즌 frame 밖 인물은 *후보 비교 표 (§3 of output)* 에 '시즌 frame 밖 / 후속 시즌 대기' 로 분류. 본 시즌의 top N 에는 들지 않음. 단 다른 시즌·단원에 살릴 패턴 (예: 페르마 → 단원 4 카메오) 기록."
- 시즌 N 으로의 인물 추천 누적 양식 — `40_experiments/season-N-candidates.md` 같은 운영 파일 시드.

### 2.5 "주연 + 대비 카메오" 패턴 (top 3 의 의미)

**현재 문제**: SKILL.md 입력 #6 후보 수 = "1순위 1인 / top 3 / top 5". 그러나 본 시범 결과는 *주연 1 + 대비 카메오 2* 의 패턴 — top 3 의 의미가 단순 "상위 3인" 이 아니라 *역할 차별화* 임을 보여줌.

**정련 안**:
- SKILL.md 출력 양식에 *역할 명시* 추가: 각 인물의 역할 = "주연 / 조연 / 카메오 / 후속 시즌 / 사이드". 본 시범의 패턴 = "1 주연 + 2 대비 카메오 (한 명은 같은 문명 한 세대 전 + 한 명은 다른 문명 같은 발견)" 가 본 시리즈의 유효 패턴.
- 입력 #6 = "주연 N + 대비 카메오 M" 형식으로 명세 가능.

### 2.6 "한 단어" 압축 (R6 quality essence 원칙 5) 의 평가 frame 편입

**현재 빠짐**: INTEGRATED_PLAN §9 진화 원칙 5 = "한 단어" 압축 (인물 1인 = 1단어). 본 시범에서 명시적 평가 없음.

**정련 안**:
- SKILL.md 평가 기준에 추가: "각 후보의 '한 단어' 가 시청자 마음에 남길 단어인가". 본 시범 후보의 잠정 한 단어:
  - 에라토스테네스 = **정리** (또는 *분류*)
  - 유클리드 = **체계**
  - 류후이 = **왜** (또는 *주석*)
- 이 한 단어가 영상 6장면 마지막 (S6 마무리) 에 압축되는지 다음 단계 [스토리] 에서 검증.

## 3. 본 시범의 한계 (정직)

본 시범 실행의 정직한 한계 — output.md §6 과 일관:

1. **WebFetch 차단 환경** — 일부 자료는 검색 요약만으로 인용. 1차 출처 (Plutarch, Heath's Elements, 류후이 서문 한문 원문) 직접 fetch 못함. 다음 라운드에 보강 가능.
2. **학습자 반응 (입력 #8)** 빈 디렉토리 → 평가 skip. 학습자가 옛 1편 본 후 반응 수집되면 재평가 가능.
3. **백그라운드 에이전트 stall** — 600s timeout. retrospective.md 작성 단계에서 발생 추정 (output.md / log.md 는 완성). 원인 미상. 다음 백그라운드 작업 시 출력 분할 (3개 파일을 1개씩 작성 후 보고) 패턴 권장.
4. **신규 발굴 후보** (메르센·니코마우스 등) 의 자료원 정밀도 — 검색 요약 수준. 본 시즌에서 탈락이라 본 시범에서는 충분.
5. **시즌 1 전체 분포 검증** — 다른 단원 시범 (exp-002~) 후 가능.

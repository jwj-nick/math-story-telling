# 90_archive — 폐기 실험·옛 버전

## 보관 대상
- 실패·중단된 실험 (`40_experiments/exp-NNN/` 에서 이동)
- 옛 표준 버전 (`20_principles/`의 superseded 파일)
- 옛 도구 (`70_tools/`의 deprecated 스크립트)

## 명명
원본 path 유지 + `_archived_YYMMDD/` prefix.

예: `_archived_260601/exp-001-elevenlabs-voice-compare/`

## 운영 규칙
- 삭제 X (안전망)
- 가끔 zoom out 시 "왜 폐기했는가" 회고 자료

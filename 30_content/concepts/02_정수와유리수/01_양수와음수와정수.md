# 양수, 음수, 정수

## 정의

- **양수(positive number)**: 0보다 큰 수. 부호 `+` (생략 가능)
- **음수(negative number)**: 0보다 작은 수. 부호 `-`
- **정수(integer)**: 양의 정수, 0, 음의 정수를 통틀어 부르는 말

$$\cdots, -3, -2, -1, 0, +1, +2, +3, \cdots$$

## 수직선

```
←──┬──┬──┬──┬──┬──┬──→
  -3 -2 -1  0 +1 +2 +3
```

- 0을 기준으로 오른쪽: 양수, 왼쪽: 음수
- 0은 양수도 음수도 아니다

## 정수의 분류

| 분류 | 예 |
|---|---|
| 양의 정수 (자연수) | +1, +2, +3, … |
| 0 | 0 |
| 음의 정수 | -1, -2, -3, … |

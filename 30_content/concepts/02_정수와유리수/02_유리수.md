# 유리수

## 정의

분수 $\dfrac{a}{b}$ (단, $a$는 정수, $b$는 0이 아닌 정수) 꼴로 나타낼 수 있는 수

## 유리수의 분류

```
유리수
├── 정수
│   ├── 양의 정수 (자연수): 1, 2, 3, …
│   ├── 0
│   └── 음의 정수: -1, -2, -3, …
└── 정수가 아닌 유리수
    ├── 양의 유리수: 1/2, 0.3, …
    └── 음의 유리수: -1/2, -0.3, …
```

## 핵심

- 모든 정수는 유리수이다 (예: $3 = \dfrac{3}{1}$)
- 유한소수, 순환소수는 모두 유리수이다
- 수직선 위의 모든 유리수는 점으로 대응된다

# 절댓값과 대소 관계

## 절댓값 (absolute value)

수직선에서 0으로부터 어떤 수까지의 **거리**

$$|a| = \begin{cases} a & (a > 0) \\ 0 & (a = 0) \\ -a & (a < 0) \end{cases}$$

- $|+3| = 3$, $|-3| = 3$, $|0| = 0$
- 절댓값은 항상 0 이상이다

## 대소 관계

수직선에서 **오른쪽**에 있는 수가 더 크다.

| 규칙 | 설명 |
|---|---|
| 양수 > 0 > 음수 | 양수는 항상 음수보다 크다 |
| 양수끼리 | 절댓값이 클수록 크다 |
| 음수끼리 | 절댓값이 클수록 작다 |

## 예시

$$-5 < -2 < 0 < 1 < 4$$

# 정수와 유리수의 덧셈·뺄셈

## 덧셈 규칙

| 경우 | 방법 | 예 |
|---|---|---|
| 양수 + 양수 (같은 부호) | 절댓값의 합, 부호 `+` | $(+3)+(+5) = +8$ |
| 음수 + 음수 (같은 부호) | 절댓값의 합, 부호 `-` | $(-3)+(-5) = -8$ |
| 양수 + 음수 (다른 부호) | 절댓값의 차, 절댓값이 큰 쪽 부호 | $(+5)+(-3) = +2$ |
| 음수 + 양수 (다른 부호) | 절댓값의 차, 절댓값이 큰 쪽 부호 | $(-5)+(+3) = -2$ |

## 뺄셈 → 덧셈으로 변환

$$A - B = A + (-B)$$

빼는 수의 부호를 바꾸어 더한다.

- $(+5) - (+3) = (+5) + (-3) = +2$
- $(-2) - (-5) = (-2) + (+5) = +3$

## 덧셈의 성질

- **교환법칙**: $a + b = b + a$
- **결합법칙**: $(a+b)+c = a+(b+c)$

## 덧셈·뺄셈 혼합 계산

모든 뺄셈을 덧셈으로 바꾼 뒤 한꺼번에 계산.

$$(-3) - (+5) + (-2) = (-3) + (-5) + (-2) = -10$$

**순서**:
1. 뺄셈 → 덧셈으로 변환 (빼는 수의 부호 반대로)
2. 양수끼리 합산, 음수끼리 합산
3. 마지막으로 양수합과 음수합을 합산

# 식의 값

## 정의

식에 포함된 문자에 **특정 수를 대입**하여 계산한 결과

## 대입 (substitution)

문자 대신 수를 넣는 것

## 주의사항

- 음수를 대입할 때는 반드시 **괄호**를 사용한다
- $x = -2$ 일 때 $3x = 3 \times (-2) = -6$

## 예시

$x = 3, y = -2$ 일 때:

| 식 | 계산 | 결과 |
|---|---|---|
| $2x + y$ | $2(3) + (-2)$ | $4$ |
| $x^2 - y$ | $3^2 - (-2)$ | $11$ |
| $\dfrac{x}{y}$ | $\dfrac{3}{-2}$ | $-\dfrac{3}{2}$ |

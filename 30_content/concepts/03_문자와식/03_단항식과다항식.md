# 단항식과 다항식

## 용어

| 용어 | 정의 | 예 |
|---|---|---|
| 항(term) | 수 또는 문자의 곱으로 이루어진 식 | $3x$, $-5$, $2xy$ |
| 계수(coefficient) | 항에서 문자에 곱해진 수 | $3x$의 계수 = $3$ |
| 상수항(constant) | 수만으로 이루어진 항 | $-5$ |
| 단항식(monomial) | 항이 1개인 식 | $3x$, $-2ab$ |
| 다항식(polynomial) | 항이 2개 이상인 식 | $x+3$, $2x^2-x+1$ |
| 차수(degree) | 문자가 곱해진 횟수 | $x^3$의 차수 = 3 |
| 일차식 | 가장 높은 차수가 1인 다항식 | $2x-5$ |

## 동류항 (like terms)

문자와 차수가 **같은** 항 → 계수끼리 더하거나 빼서 합칠 수 있음

- $3x + 5x = 8x$
- $2x^2 + 3x - x^2 + x = x^2 + 4x$

# 일차식의 계산

## 일차식 × 수

분배법칙을 이용한다.

$$a(bx + c) = abx + ac$$

- $3(2x - 1) = 6x - 3$
- $-2(x + 4) = -2x - 8$

> **주의**: 앞에 마이너스가 붙으면 괄호 안 모든 항의 부호가 바뀜

## 일차식 ÷ 수

나누는 수의 역수를 곱한다.

$$(6x - 4) \div 2 = (6x - 4) \times \frac{1}{2} = 3x - 2$$

## 일차식의 덧셈·뺄셈

1. 괄호가 있으면 괄호를 푼다
2. 동류항끼리 모은다
3. 동류항끼리 계산한다

## 예시

$(3x - 2) + (x + 5) = 3x - 2 + x + 5 = 4x + 3$

$(2x + 1) - (x - 3) = 2x + 1 - x + 3 = x + 4$

> **핵심 주의**: 빼기가 앞에 오면 괄호 안 부호가 전부 바뀐다!
> $(2x+1) - (x-3)$에서 $-(x-3) = -x+3$ (마이너스가 안으로 들어가면 부호 반전)

## 분수 계수가 있을 때

$$\frac{1}{2}(4x - 6) = 2x - 3$$

$$\frac{a}{2} + \frac{a}{3} = \frac{3a}{6} + \frac{2a}{6} = \frac{5a}{6}$$

분모가 다를 때는 통분 후 계산.

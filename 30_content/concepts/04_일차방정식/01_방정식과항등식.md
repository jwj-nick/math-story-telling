# 방정식과 항등식

## 등식 (equation)

등호 `=`를 사용하여 두 식이 같음을 나타낸 식

## 방정식 (equation with unknown)

특정 값에서만 참이 되는 등식

- $x + 3 = 5$ → $x = 2$ 일 때만 참
- 미지수(unknown): 값을 모르는 문자 (보통 $x$)
- **해(solution)**: 방정식을 참이 되게 하는 미지수의 값
- **풀다(solve)**: 해를 구하는 것

## 항등식 (identity)

미지수에 어떤 값을 대입해도 항상 참인 등식

- $2(x+1) = 2x + 2$ → 모든 $x$에 대해 참

## 구분

| | 방정식 | 항등식 |
|---|---|---|
| 참이 되는 경우 | 특정 값만 | 모든 값 |
| 예 | $x + 1 = 3$ | $x + x = 2x$ |

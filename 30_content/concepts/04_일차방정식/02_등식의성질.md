# 등식의 성질

## 4가지 성질

등식의 양변에 같은 수를 더하거나, 빼거나, 곱하거나, 나누어도 등식은 성립한다.

| 성질 | 표현 |
|---|---|
| 덧셈 | $a = b$ 이면 $a + c = b + c$ |
| 뺄셈 | $a = b$ 이면 $a - c = b - c$ |
| 곱셈 | $a = b$ 이면 $a \times c = b \times c$ |
| 나눗셈 | $a = b$ 이면 $a \div c = b \div c$ (단, $c \neq 0$) |

## 이항 (transposition)

등식의 한 항을 부호를 바꾸어 다른 변으로 옮기는 것

$$x + 3 = 7 \quad \Rightarrow \quad x = 7 - 3$$

> 덧셈 → 뺄셈, 뺄셈 → 덧셈으로 바꾸어 이항

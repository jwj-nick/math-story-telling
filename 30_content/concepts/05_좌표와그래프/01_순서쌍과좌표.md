# 순서쌍과 좌표

## 순서쌍 (ordered pair)

두 수를 순서를 정하여 괄호 안에 짝지어 나타낸 것

$$(a, b)$$

- $(2, 3) \neq (3, 2)$ → **순서**가 중요하다

## 좌표평면 (coordinate plane)

두 수직선이 원점(0, 0)에서 직교하는 평면

- **$x$축**: 가로 수직선
- **$y$축**: 세로 수직선
- **원점(O)**: 두 축의 교점 $(0, 0)$

## 좌표 (coordinate)

점 P에 대응하는 순서쌍 $(a, b)$

- $a$: **$x$좌표** (가로 방향 위치)
- $b$: **$y$좌표** (세로 방향 위치)
- 표기: $\mathrm{P}(a, b)$

## 사분면 (quadrant)

| 사분면 | $x$좌표 | $y$좌표 |
|---|---|---|
| 1사분면 | + | + |
| 2사분면 | - | + |
| 3사분면 | - | - |
| 4사분면 | + | - |

> 축 위의 점은 어느 사분면에도 속하지 않는다.

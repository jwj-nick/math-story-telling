# 각

## 정의

한 점(꼭짓점)에서 나온 두 반직선이 이루는 도형

## 표기

- $\angle AOB$ 또는 $\angle O$ (꼭짓점이 가운데)

## 각의 종류

| 이름 | 크기 |
|---|---|
| 예각(acute angle) | $0° < \angle < 90°$ |
| 직각(right angle) | $= 90°$ |
| 둔각(obtuse angle) | $90° < \angle < 180°$ |
| 평각(straight angle) | $= 180°$ |
| 우각(reflex angle) | $180° < \angle < 360°$ |

## 맞꼭지각 (vertical angles)

두 직선이 교차할 때 마주보는 각

$$\text{맞꼭지각은 서로 같다}$$

## 직교 (perpendicular)

두 직선이 이루는 각이 90°일 때 → 기호 $\perp$

$AB \perp CD$

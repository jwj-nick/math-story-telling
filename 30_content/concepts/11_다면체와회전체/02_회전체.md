# 회전체

## 정의

**회전체(solid of revolution)**: **평면도형**을 한 직선(**회전축**)을 중심으로 1회전 시킬 때 생기는 입체도형.

> "도형이 한 바퀴 도는 동안 지나간 자리"를 모두 모은 입체.
> 회전축은 평면도형의 변에 있을 수도 있고, 떨어져 있을 수도 있다.

## 회전체와 다면체의 차이

| | 다면체 | 회전체 |
|---|---|---|
| 면의 종류 | 모두 평면 다각형 | 곡면을 포함 |
| 만드는 방법 | 다각형들을 붙임 | 평면도형을 회전 |
| 예 | 각기둥, 각뿔, 정다면체 | 원기둥, 원뿔, 구, 원뿔대 |
| 각기둥은? | ✅ 다면체 | ❌ 회전체 아님 |

> ⚠️ **각기둥은 회전체가 아니다** — 직사각형을 한 직선 둘레로 회전하면 원기둥이 되지만, 각기둥(직육면체 등)은 회전 결과가 아니다.

---

## 회전체의 종류 (4가지 — 중1 핵심)

| 회전 전 (평면도형) | 회전축 | 회전체 |
|---|---|---|
| 직사각형 | 한 변 | **원기둥** (cylinder) |
| 직각삼각형 | 직각을 낀 한 변 | **원뿔** (cone) |
| 사다리꼴 (직각이 두 개) | 평행하지 않은 한 변 (평행한 변이 모두 보존되도록) | **원뿔대** (truncated cone / frustum) |
| 반원 | 지름 | **구** (sphere) |

### 시각화

```
원기둥                 원뿔
┌──┐  회전축          /│  회전축
│  │                 / │
│  │               /  │
│  │              ────┘
└──┘

원뿔대                구
┌──┐ 회전축          ╭─╮  회전축
 \ │                 │ │
  \│                 ╰─╯
 ──┘
```

## 회전체의 구성요소

| 용어 | 정의 |
|---|---|
| **회전축** | 회전의 중심이 되는 직선 |
| **모선(slant side)** | 원뿔·원뿔대에서 옆면을 만드는 선분 (원뿔 꼭짓점과 밑면 둘레 잇는 선분) |
| **밑면** | 회전체의 바닥(과 천장) — 원이거나 원기둥/원뿔대에선 두 개 |
| **옆면** | 곡면 부분 |

### 모선과 높이의 차이 (★)

원뿔에서:
- **높이**: 회전축 방향, 꼭짓점에서 밑면까지의 **수직 거리**.
- **모선**: 꼭짓점에서 밑면 **둘레의 점**까지의 거리 (**옆면 위 선분**).
- 항상 **모선 ≥ 높이** (피타고라스 정리: $($모선$)^2 = ($높이$)^2 + ($밑면 반지름$)^2$).

> ⚠️ 시험에서 자주 묻는다 — "원뿔의 모선이 5, 밑면 반지름이 3일 때 높이는?" → $\sqrt{5^2-3^2}=4$.

## 회전체의 단면 (★ 단원의 핵심 성질)

### 1. 회전축에 **수직인** 단면 — 항상 **원**

회전축에 수직으로 자르면 자른 자리는 항상 **원**이다 (회전체 정의상 자명).

| 회전체 | 수직 단면 |
|---|---|
| 원기둥 | 원 (모두 합동) |
| 원뿔 | 원 (위로 갈수록 작아짐) |
| 원뿔대 | 원 (위로 갈수록 작아짐) |
| 구 | 원 (적도가 가장 큼, 극으로 갈수록 작음) |

### 2. 회전축을 **포함하는** 단면 (= **축단면**) — 좌우대칭

회전축이 그 단면 안에 들어 있도록 자르면 자른 자리는 **회전축에 대해 좌우대칭**인 도형이다.

| 회전체 | 축단면 모양 | 설명 |
|---|---|---|
| 원기둥 | 직사각형 | 원래 회전 전 도형 + 거울상 |
| 원뿔 | 이등변삼각형 | 직각삼각형 + 거울상 = 이등변삼각형 |
| 원뿔대 | 사다리꼴 (등변사다리꼴) | 사다리꼴 + 거울상 |
| 구 | 원 (지름이 단면의 지름) | 반원 + 거울상 |

> ★ **모든 축단면은 합동**이다 — 어느 방향에서 회전축을 포함해 잘라도 같은 모양.

### 자주 하는 실수 (수직 단면 vs 축단면)
- ❌ "원뿔의 수직 단면은 이등변삼각형" — 이등변삼각형은 **축단면**, 수직 단면은 **원**.
- ❌ "원기둥의 축단면은 원" — 축단면은 **직사각형**, 수직 단면이 원.
- ✅ "수직 = 원, 축단면 = 좌우대칭 도형" 으로 외우기.

## 회전체의 전개도

전개도(net): 입체 표면을 평면에 펼친 그림.

### 원기둥의 전개도

원기둥(반지름 $r$, 높이 $h$)을 펼치면:
- **밑면 2개**: 반지름 $r$인 원
- **옆면 1개**: 직사각형 (가로 = 밑면 둘레 = $2\pi r$, 세로 = 높이 $h$)

> ★ 옆면 직사각형의 **가로** = 밑면 원의 **둘레** $2\pi r$. (시험 단골)

### 원뿔의 전개도

원뿔(밑면 반지름 $r$, 모선 $l$)을 펼치면:
- **밑면 1개**: 반지름 $r$인 원
- **옆면 1개**: **부채꼴** (반지름 = 모선 $l$, 호의 길이 = 밑면 둘레 = $2\pi r$)

> ★ 옆면 부채꼴의 **반지름** = 원뿔의 **모선**, 부채꼴의 **호** = 원뿔 밑면의 **둘레**.

#### 부채꼴 중심각 구하기 (참고, Unit 12에서 본격 다룸)
원뿔 옆면 부채꼴의 중심각을 $\theta$라 하면 호의 길이 = $\dfrac{\theta}{360} \cdot 2\pi l = 2\pi r$ → $\theta = \dfrac{r}{l} \cdot 360°$.

### 구의 전개도?
구는 **전개도가 없다** (평면에 완전히 펼칠 수 없음). 그래서 지구본을 평평한 지도로 만들 때 왜곡이 생긴다 (메르카토르 도법 등).

## 회전축의 위치에 따른 차이

같은 도형이라도 회전축이 어디인지에 따라 다른 회전체가 생긴다.

### 직사각형의 회전 (회전축에 따라)
- **한 변을 축으로** → 원기둥
- **대각선을 축으로** → 두 원뿔이 붙은 모양 (밑면이 같은)
- **외부의 평행선을 축으로** → 도넛 비슷한 모양 (가운데 비어있음)

### 직각삼각형의 회전
- **직각변 한 쪽을 축으로** → 원뿔
- **빗변을 축으로** → 두 원뿔이 밑면을 공유한 모양 (북도장 모양)

### 반원의 회전
- **지름을 축으로** → 구
- **지름과 평행한 외부 직선을 축으로** → 도넛(토러스) 비슷

> ★ 시험에서 "이 평면도형을 회전축 중심으로 회전했을 때 단면 모양은?" 같은 문제 출제됨.

## 자주 하는 실수

1. ❌ "각기둥도 회전체" — 각기둥은 **다면체**. 회전체 아님.
2. ❌ "원뿔의 수직 단면은 삼각형" — 수직 단면은 **원**, 축단면이 삼각형.
3. ❌ "원기둥 옆면 직사각형 가로 = 반지름" — 가로는 **밑면 둘레** $2\pi r$.
4. ❌ "원뿔 옆면 펼치면 삼각형" — 펼치면 **부채꼴**.
5. ❌ "원뿔의 모선과 높이가 같다" — 다르다 (모선 = 빗면, 높이 = 수직).
6. ❌ "구는 전개도가 있다" — 구는 평면에 펼칠 수 없음.
7. ❌ "사다리꼴 회전 → 항상 원뿔대" — 회전축 위치에 따라 다른 모양도 가능.

## 케플러와 회전체 (역사 메모)

- 1612년, 케플러가 결혼식 와인을 사다가 술통의 부피를 잰 방식이 부정확함을 발견.
- 1615년 「Stereometria Doliorum Vinariorum (와인 술통의 입체기하학)」 발간.
- 술통은 복잡한 회전체(중간이 부푼 통) → 미세 단면들을 적분해서 부피 계산 (현대 적분의 선구).
- 이 책은 카발리에리(1635) → 뉴턴/라이프니츠(1670s) 미적분으로 이어짐.

> 회전체는 단지 모양 분류가 아니라 **부피 계산**을 위한 핵심 도구.

# 히스토그램과 도수분포다각형

## 히스토그램 (histogram)

도수분포표를 막대그래프로 나타낸 것

- 가로축: 계급
- 세로축: 도수
- 막대 사이의 간격 없음 (연속 자료)

## 도수분포다각형 (frequency polygon)

히스토그램에서 각 막대의 **윗변의 중점**을 선으로 이은 그래프

- 양 끝은 도수가 0인 계급까지 연장하여 닫힌 도형을 만든다
- 도수분포다각형과 가로축으로 둘러싸인 넓이 = 히스토그램의 넓이

## 특징 비교

| | 히스토그램 | 도수분포다각형 |
|---|---|---|
| 형태 | 막대 | 꺾은선 |
| 두 집단 비교 | 어려움 | 겹쳐 그리면 쉬움 |

## 넓이 공식

**히스토그램의 넓이 = (계급의 크기) × (도수의 합)**

각 막대 = (계급의 크기) × (그 계급의 도수)
모두 더하면 → 계급의 크기 × (도수의 합)

**도수분포다각형과 가로축으로 둘러싸인 넓이 = 히스토그램 전체 넓이** (꺾은선 위로 솟은 삼각형 = 꺾은선 아래로 패인 삼각형, 면적 이동 동일)

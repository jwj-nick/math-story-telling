## 유형 1: 방정식 / 항등식 판별

**핵심 개념**: 특정 값에서만 참 → 방정식 / 모든 값에서 참 → 항등식

**출제 포인트**:
- 등식이 주어졌을 때 방정식인지 항등식인지 구분
- 항등식의 조건 ($a, b$ 값 결정)
- 방정식에서 해의 의미

**난이도 분포**: L×3, M×3, H×3

**H 문제 예시**: 항등식 조건에서 미정계수 $a, b$ 구하기 ($ax + 3 = 2x + b$가 항등식 → $a=2, b=3$)

---

## 유형 2: 등식의 성질 활용

**핵심 개념**: 양변에 같은 수를 더하거나 빼거나 곱하거나 나누어도 등식 성립

**출제 포인트**:
- 등식의 성질로 간단한 방정식 풀기
- 주어진 등식에서 성질 적용 결과 예측
- $a = b$일 때 변환식 참/거짓 판단

**난이도 분포**: L×3, M×3, H×3

**H 문제 예시**: 성질 적용 결과가 여러 단계로 연결되는 판단 문제

---

## 유형 3: 기본 일차방정식 풀기

**핵심 개념**: 이항 + 동류항 정리 + 계수로 나누기 (정수 계수)

**출제 포인트**:
- $ax + b = cx + d$ 꼴 풀기
- 이항 후 동류항 정리
- 해 구한 뒤 검산

**난이도 분포**: L×3, M×3, H×3

**H 문제 예시**: 해가 특정 조건(자연수, 음수 등)을 만족하는 $a$ 값 찾기

---

## 유형 4: 분수·소수 계수 방정식

**핵심 개념**: 분수 → 분모의 LCM 곱하기 / 소수 → 10의 거듭제곱 곱하기

**출제 포인트**:
- 분수 계수 방정식 (동분모 처리)
- 소수 계수 방정식 (정수로 변환)
- 분수+소수 혼합

**난이도 분포**: L×3, M×3, H×3

**H 문제 예시**: 분모가 다른 분수 + 소수가 혼합된 방정식

---

## 유형 5: 괄호 있는 방정식

**핵심 개념**: 분배법칙으로 괄호 먼저 풀기 → 이항

**출제 포인트**:
- $a(bx + c) = d$ 꼴
- 양변에 괄호 있는 경우
- 이중 괄호

**난이도 분포**: L×3, M×3, H×3

**H 문제 예시**: 이중 괄호 + 분수 계수 복합

---

## 유형 6: 복잡한 방정식 (괄호 + 분수 복합)

**핵심 개념**: 괄호 → 분수 → 이항 → 동류항의 순서로 처리

**출제 포인트**:
- 괄호와 분수가 함께 있는 방정식
- 방정식 변형 후 조건 판단
- 해가 정수가 되는 조건 ($a$ 값 찾기)

**난이도 분포**: L×3, M×3, H×3

**H 문제 예시**: $\frac{2(x-1)}{3} = \frac{x+4}{2} - 1$ 꼴

---

## 유형 7: 방정식 활용

**핵심 개념**: 미지수 설정 → 방정식 세우기 → 풀기 → 검토

**하위 유형**:
- 수 관계 (연속수, 배수, 차이)
- 나이 문제 (현재/미래/과거 나이)
- 거리·속력·시간
- 개수·금액
- 농도 문제

**난이도 분포**: L×3, M×3, H×3

**H 문제 예시**: 거리·속력·시간 + 만나는 시점 (서로 반대 방향 이동)

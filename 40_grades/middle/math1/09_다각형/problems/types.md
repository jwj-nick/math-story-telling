# Unit 09 다각형 — 유형 목록

> 중1 다각형 단원 시험에 자주 나오는 7유형. 각 유형마다 L×3 + M×3 + H×3 = 9문제 구성 (5-c).

---

## 유형 1 · 다각형 정의·이름·구성요소

**핵심**: 다각형 정의(3개 이상 선분·평면·닫힘) / 변·꼭짓점·이웃 / $n$각형 이름

**대표 문제 패턴**:
- 다각형 vs 다각형 아닌 것 식별 (원, 부채꼴, 입체, 열린 도형)
- 변·꼭짓점 수 계산 ($n$각형 → $n$, $n$)
- 한 꼭짓점에서 그릴 수 있는 대각선 수 ($n - 3$)
- $n$각형 이름 ↔ $n$ 변환

**난이도 분포**: L 3 (정의 식별·변 꼭짓점 수) / M 0 / H 0
→ **L만 있는 기본형 → Phase 5-d skip**

---

## 유형 2 · 대각선의 수

**핵심**: $\dfrac{n(n-3)}{2}$ 직접 계산 + 역산 ($n$ 구하기)

**대표 문제 패턴**:
- 직접: $n$각형의 대각선 수 (예: 십각형은?)
- 역산: 대각선 수가 $k$일 때 $n$ 구하기 (예: 대각선 35개 → $n$=10)
- 한 꼭짓점 vs 전체 구분
- 두 다각형 비교 (예: 칠각형과 구각형의 대각선 수 차)

**난이도 분포**: L 3 (직접) / M 3 (역산·비교) / H 3 (조건 포함)
→ **5-d 통합 대상** (유형 1과 함께 "다각형 기초" deep)

---

## 유형 3 · 삼각형 내각·외각

**핵심**: 삼각형 내각합 180° / 외각의 정리 (한 외각 = 이웃 안 하는 두 내각의 합)

**대표 문제 패턴**:
- 두 내각 주어진 상황에서 셋째 각 계산
- 한 외각 주어진 상황에서 안쪽 두 각의 합
- 이등변삼각형 + 한 각 → 다른 각
- 외각의 정리 활용 (보조각 미지수)

**난이도 분포**: L 3 / M 3 / H 3
→ **5-d 통합 대상** ("내각·외각" deep)

---

## 유형 4 · $n$각형 내각의 합

**핵심**: $180°(n-2)$ + 분할 삼각형 사고

**대표 문제 패턴**:
- 직접: 칠각형/팔각형 내각의 합
- 역산: 내각의 합 → $n$
- 미지수 한 각 찾기 (다각형 그림에서 5각 중 4각이 주어짐)
- $n$각형의 한 꼭짓점에서의 분할 삼각형 수

**난이도 분포**: L 3 / M 3 / H 3
→ **5-d 통합 대상**

---

## 유형 5 · 외각의 합·미지 외각

**핵심**: 외각의 합 = 360° (불변) + 한 외각 미지수 찾기

**대표 문제 패턴**:
- 외각의 합 직접 (변의 수 무관 = 360°)
- 5각형 외각 4개 주어지고 1개 찾기
- 내각·외각 합 관계 ($\angle$내+$\angle$외=180°)
- 외각합 vs 내각합 구분 함정

**난이도 분포**: L 3 / M 3 / H 3
→ **5-d 통합 대상**

---

## 유형 6 · 정다각형 한 내각·한 외각

**핵심**: 정$n$각형 한 외각 = $\dfrac{360°}{n}$, 한 내각 = $180° - \dfrac{360°}{n}$

**대표 문제 패턴**:
- 직접: 정육각형/정팔각형의 한 내각·한 외각
- 역산: 한 외각 $30°$ → 정$n$각형은? ($n=12$)
- 역산: 한 내각 $144°$ → 정$n$각형은? ($n=10$)
- 정다각형 변의 길이가 같은 두 정다각형 비교

**난이도 분포**: L 3 / M 3 / H 3
→ **5-d 통합 대상** ("정다각형·종합" deep)

---

## 유형 7 · 다각형 종합·복합

**핵심**: 별 모양·보조선·복합 도형에서 각 구하기

**대표 문제 패턴**:
- 별 모양(오각성·육각성)의 다섯 끝 각의 합
- 보조선 그어 다각형으로 변환 후 내각합 활용
- 평행선 + 다각형 결합
- 다각형 안의 점에서 각 분할

**난이도 분포**: L 1 / M 4 / H 4
→ **5-d 통합 대상** ("정다각형·종합" deep)

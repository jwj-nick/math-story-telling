# Unit 11 다면체와 회전체 — 시험 유형 목록

> 중1 교육과정 + 학교 시험 기출 패턴 기반 7유형
> 각 유형은 L(쉬운)×3 + M(중간)×3 + H(어려운)×3 = **9문제**

---

## 유형 1 · 다면체 분류와 구성요소
**핵심**: 다면체 vs 회전체 구분, 면·모서리·꼭짓점 정의 + 세기

### L (3문제)
- 다면체와 회전체 구분 (간단한 분류)
- 정육면체 V·E·F 직접 세기
- 어떤 입체의 면 수 세기 (그림 보기)

### M (3문제)
- 여러 입체 중 다면체만 모두 고르기
- 면 수가 주어진 다면체 분류 (예: 면 5 = 오면체)
- 한 꼭짓점에 모인 면 수 식별

### H (3문제)
- 면·모서리·꼭짓점 동시 세기 + 오일러 검증
- 정다면체와 헷갈리는 다면체 (정사각뿔 등) 구분 추론
- 도형 합치기/자르기 후 새 입체의 V·E·F

### 자주 하는 실수
- 곡면 포함 입체를 다면체로 착각
- 꼭짓점·모서리 셀 때 빼먹음 (특히 뒷면)

---

## 유형 2 · 각기둥·각뿔·각뿔대 ($V, E, F$)
**핵심**: $n$각 일반화 — 각기둥·각뿔·각뿔대의 $V, E, F$ 공식

### L (3문제)
- 삼각기둥/사각기둥/오각기둥의 $V, E, F$
- $n$각뿔의 면 수 ($n+1$)
- $n$각뿔대 모서리 수 ($3n$)

### M (3문제)
- 면 수가 주어졌을 때 → $n$ 역산 → 다른 양 구하기 (★ Q6 패턴)
- 각기둥과 각뿔대의 차이 (옆면 모양)
- 모서리 수가 같은 두 입체 (각기둥과 각뿔대의 동일성)

### H (3문제)
- $V+E+F$ 또는 $V \cdot E$ 등 조합 식 계산
- 두 다면체의 $V, E, F$ 비교 (예: 오각기둥과 칠각뿔)
- 각뿔대의 옆면 사다리꼴 — 합동 vs 닮음 구분

### 자주 하는 실수
- $n$각기둥 모서리 = $2n$ (옆 $n$개 빠뜨림) → 정답은 $3n$
- 각기둥과 각뿔대의 $V, E, F$ 같다는 점 모름

---

## 유형 3 · 정다면체 5종 (★)
**핵심**: 정다면체 정의 두 조건 + 5종 표 + 왜 5종뿐인가

### L (3문제)
- 정다면체 5종 이름과 면 모양 매칭
- 정사면체 / 정팔면체 / 정이십면체 (정삼각형 면) 묶기
- 각 정다면체의 $V, E, F$ 표 활용

### M (3문제)
- 정사각뿔이 정다면체인가? — 두 조건 대입 분석
- 정삼각기둥이 정다면체인가? — 옆면(정사각형)·밑면(정삼각형) 합동 X
- 한 꼭짓점에 모인 면 수가 5인 정다면체 (정이십면체)

### H (3문제)
- "왜 정다면체는 5종뿐인가" 각 합 < 360° 분석 (정육각형 → 360°)
- 한 꼭짓점에 정삼각형 6개 모이면? (평면)
- 정십이면체와 정이십면체의 $V, E$ 비교 (서로 쌍대)

### 자주 하는 실수
- "면이 정다각형이면 정다면체" — 꼭짓점 조건 빠뜨림
- 정다면체가 6종 이상이라고 착각
- 정육각형 정다면체가 있다고 착각 (없음)

---

## 유형 4 · 회전체 식별과 종류
**핵심**: 평면도형 + 회전축 → 회전체 종류

### L (3문제)
- 직사각형 한 변 회전 → 원기둥
- 직각삼각형 직각낀 변 회전 → 원뿔
- 반원 지름 회전 → 구

### M (3문제)
- 사다리꼴 회전 → 원뿔대 (회전축 위치 명시)
- 직각삼각형 빗변을 축으로 회전 → 두 원뿔 합쳐진 모양 (북도장)
- 직사각형 대각선 회전 → 두 원뿔 (밑면 공유)

### H (3문제)
- 회전축이 도형 외부에 있을 때 (도넛 비슷한 모양 추론)
- 평면도형의 어느 변을 회전축으로 잡았을 때 원기둥/원뿔이 되나
- 두 회전체 합쳐진 입체 분해 (예: 원기둥 + 원뿔)

### 자주 하는 실수
- 각기둥을 회전체로 분류 (각기둥은 다면체 — 곡면 없음)
- 회전축 위치 무시하고 회전체 종류 단정

---

## 유형 5 · 회전체의 단면 (★ 단원 핵심 함정)
**핵심**: 수직 단면 = 항상 원 / 축단면 = 좌우대칭 도형

### L (3문제)
- 원기둥의 수직 단면 = 원
- 원뿔의 축단면 = 이등변삼각형
- 구의 어떤 단면이라도 = 원

### M (3문제)
- 원뿔의 수직 단면 = 원 (★ 이등변삼각형 함정)
- 원기둥의 축단면 = 직사각형 (★ 원 함정)
- 원뿔대의 축단면 = 사다리꼴 + 모든 축단면 합동

### H (3문제)
- 회전체 단면 모양 보고 어떤 회전체인지 역으로 추론
- 축단면의 둘레/넓이 계산 (예: 원기둥 축단면 직사각형 둘레)
- 구를 비스듬히 자른 단면도 원 (원의 크기 추론)

### 자주 하는 실수
- 수직 단면을 축단면과 혼동 (★ 가장 큰 함정)
- "원뿔의 수직 단면 = 이등변삼각형" 오답
- 모든 축단면이 합동임을 모름

---

## 유형 6 · 회전체의 전개도
**핵심**: 원기둥 = 직사각형 + 원2 / 원뿔 = 부채꼴 + 원

### L (3문제)
- 원기둥 옆면 = 직사각형
- 원뿔 옆면 = 부채꼴
- 구는 전개도가 없음

### M (3문제)
- 원기둥 옆면 직사각형 가로 = 밑면 둘레 = $2\pi r$
- 원뿔 옆면 부채꼴 호 = 밑면 둘레 = $2\pi r$ (★ Q7 패턴)
- 원뿔 옆면 부채꼴 반지름 = 모선 $l$

### H (3문제)
- 원뿔 옆면 부채꼴의 중심각 = $\dfrac{r}{l} \times 360°$
- 직사각형 가로·세로 주어지면 원기둥의 $r, h$ 역산
- 부채꼴 호·반지름 주어지면 원뿔의 $r, l$ 역산

### 자주 하는 실수
- 원뿔 옆면을 삼각형으로 착각 (부채꼴이 정답)
- 원기둥 옆면 직사각형의 가로 = 반지름으로 착각 (둘레 = $2\pi r$)

---

## 유형 7 · 종합 (입체 추론)
**핵심**: 전개도→입체, 입체→단면, 회전축 추론, 결합 입체

### L (3문제)
- 전개도 보고 입체 이름 맞추기 (정육면체, 삼각기둥)
- 평면도형+회전축 보고 회전체 이름
- 단면 모양으로 회전체 추론 (3종 보기 중)

### M (3문제)
- 회전체 단면(축단면) 보고 회전 전 평면도형 추론
- 두 입체 합쳐서 새 입체 만들기 (예: 원기둥+원뿔)
- 정다면체 전개도 식별 (정사면체 = 정삼각형 4개)

### H (3문제)
- 복합 입체의 V·E·F 계산 (예: 사각뿔 + 사각기둥)
- 회전체와 다면체를 결합한 입체의 단면 모양
- 종합 추론 — 어떤 정보로 회전축 결정 가능한가

### 자주 하는 실수
- 전개도 식별 오류 (정사면체 vs 다른 정삼각형 4개 배치)
- 결합 입체에서 공유면 처리 누락 (V, E, F 잘못 계산)

## 단원 횡단 함정 정리

1. **다면체 vs 회전체** — 곡면 유무로 구분
2. **수직 단면 vs 축단면** — 수직 = 원, 축단면 = 좌우대칭
3. **정다면체 두 조건** — 면 합동 + 꼭짓점 모임 같음 (둘 다)
4. **$n$각기둥 모서리 = $3n$** — $2n$ 함정
5. **원뿔 옆면 = 부채꼴** — 삼각형 함정
6. **부채꼴 호 = $2\pi r$** — 모선 $l$ 함정 (Q7 패턴)
7. **각기둥은 다면체** — 회전체 아님

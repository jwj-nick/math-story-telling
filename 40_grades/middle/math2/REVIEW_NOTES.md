## Nick이 특별히 주의해서 볼 것 (리뷰 체크리스트)

1. **수학 정확성** — 생성기 로직(드릴)은 Node로 대량 검증했고, 개념 페이지의 핵심 수치도 내가 검증했지만, **개념 설명 문장의 정확성/오해 소지는 사람 눈으로** 봐주면 좋겠음. 단원별 핵심 주장:
   - u1: 기약분수 분모가 2·5로만 → 유한소수 (10진법이라서).
   - u2: aᵐ·aⁿ=a^(m+n) (지수 더함). *나눗셈·괄호지수·지수 0/음수는 v1에서 뺌.*
   - u3: 음수를 곱/나누면 부등호 방향 뒤집힘. *실제 부등식 완전 풀이 전개는 얕게.*
   - u4: 두 직선의 교점 = 연립의 해. 대입법은 "교점을 계산으로". *가감법은 안 다룸.*
   - u5: y=ax+b, a=기울기·b=y절편. 정비례(b=0)에서 한 걸음.
   - u6: 방정식 ax+b=0의 답 = 그래프의 x절편.
2. **톤·난이도** — 세은에게 문장이 편안한지, 너무 쉽거나 어려운지. 반말 톤("~야/봐") 유지 여부.
3. **인터랙션이 이해를 돕는지** — 각 단원 "직접 움직여봐"의 조작이 개념을 실제로 클릭되게 하는지(특히 u3 부호 뒤집힘, u5 슬라이더).
4. **라이트 기본 + 다크 토글**(오른쪽 위 🌙/☀), 폰 세로에서 깨지는 곳, 그래프 잘림.
5. **6걸음 흐름**(이어짐→왜→직접→내 말로→내가 문제 내기→손에 익히기)이 자연스러운지, "내 말로/문제 만들기"가 부담인지 즐거운지.
6. **보상 강도** — 진행 도트 + 단원 완주 시 "🌸 잘했어" + 홈의 완료 체크. 과한지/약한지.

## v1 스코프 · 알려진 한계 (심화 phase에서 보강 예정)

- **기초 phase = 단원마다 핵심 개념 1개**를 6걸음으로. 아래는 의도적으로 뺌(심화):
  - u1 순환소수 → 분수 변환, u2 지수 나눗셈·괄호지수, u3 부등식 여러 유형 완전 풀이, u4 가감법·활용문제, u5 기울기=변화율의 의미·두 점으로 식 구하기, u6 연립을 그래프로.
- **드릴 스킬**은 아직 순환소수·식의 계산·방정식/대입법만. 부등식·함수 스킬은 미추가(개념↔드릴 완전 연결하려면 추가 필요).
- **problem-poser**는 가벼운 버전(역할 반전 맛보기). 딸이 만든 문제를 저장·축적하는 기능은 없음.
- **교과서 목차 미확정**: 단원 5 vs 6 분할, 부등식/연립 묶음은 표준 2022 개정 가정. 목차 사진 오면 조정.

## NCC 설계 커멘트 (왜 이렇게 했나)

- **인물 서사 제거(기초)**: 개념 이해에 집중. 인물·역사는 영상 트랙과 심화 몫. 호기심은 현상·수수께끼로.
- **연속성 본문화**: 각 단원 1번 섹션이 "작년의 무엇"에서 시작 + 미니 확인 1개. 새 개념을 아는 것의 연장으로 → 안전감.
- **teach-back + 문제 만들기**: 이해를 "설명"과 "출제"로 꺼내게. 세은 언어 강점 활용. 정답 채점이 아니라 표현 유도(점진 공개).
- **공용 엔진**(`concept.css`/`concept.js`): 6단원 일관성 + 유지보수. 인터랙티브 부품(좌표평면·수직선·지수블록·소수기계) 재사용.
- **라이트 기본 + 절제된 보상 + 부드러운 팔레트**(로즈·허니골드·세이지): 피드백 반영.
- **단원 번호 1~6 리셋**, 드릴 라벨도 14/15→1/2로 재정합(URL은 그대로).

## 열린 질문 (Nick 결정 원함)

1. **교과서 목차** — 5단원인지 6단원인지, 부등식·연립 묶음. (번호/분할 최종 확정)
2. **개념↔드릴 완전 연결** — 드릴에 부등식·일차함수 스킬을 추가할까? (그럼 모든 단원이 "이해→연습" 짝을 가짐)

### 무엇이 생겼나 — 단원별 3페이지 신규 (총 18페이지)
| 파일 | 역할 | 성격 |
|---|---|---|
| `pN.html` | **연습** | 미션 카드 5개. 실생활 응용(피자·용돈·카페·양초·손익분기…) + 시각효과 + 즉시 피드백 + "왜?" 설명 + 완료 도장 |
| `dN.html` | **심화 탐구** | 시뮬레이터 실험실 1개 중심. 답 맞히는 문제 없음, 직접 굴려 원리 발견 |
| `dNp.html` | **심화 문제** | 서술형/2단계 복합 3문제. 서술 textarea + 단계별 힌트 + 풀이 전체 보기 |

- **동선**: 개념(uN) → 연습(pN) → 심화 탐구(dN) → 심화 문제(dNp). 단원 안에서 **상단 탭바**로 자유 이동(엔진이 자동 주입). 개념 페이지 끝 링크도 연습으로 연결.
- **핵심 시뮬레이터**: 1)순환소수→분수 변환기 2)지수 폭발/복리(ECharts) 3)부등식 풀이+수직선(음수÷ 뒤집기 실시간) 4)두 직선 교점(평행=해없음·일치=무수) 5)일차함수 랩(기울기 삼각형·양 절편·평행) 6)직선·방정식·연립 통합.
- **세은 약점 직격**: p4 M1이 대입법(y=2x+1을 다른 식에 대입)을 시각·단계로. d3/d3p·d4p가 양변 정리 반복.
- ① 히어로 `.en` 흰색 처리 완료(`.hero .en{color:#fff}`). ② drill = 사이드바/허브에 "preview" 라벨 + 유지.

# Story 영상 제작 가이드 (v1.0)

> MathTelling 13단원 각 인물의 **Story 영상** 표준 명세.
> 이 문서가 단일 진실 원본(SSOT). 모든 후속 작업(템플릿, 팔레트, 스킬)은 여기 명세를 따른다.

---

## 0. 빠른 요약

- **목적**: 단원 진입 전 학습자(중1)의 흥미를 유발하는 50초 인물 서사 영상
- **형식**: 1280×720, MP4 (H.264 + AAC), 24fps
- **제작 도구**: HTML+GSAP → HyperFrames → FFmpeg
- **나레이션**: edge-tts 한국어 (ko-KR-SunHiNeural 기본)
- **시각 진화**: v1 (텍스트+심볼) → v4 (시네마틱)
- **배포**: `90_video/unitNN/final.mp4` + `story.html` 상단 임베드

---

## 1. 영상의 목적·청중·사용 시점

### 1.1 목적
**감성적 인트로**. 단원을 시작하기 전에 "이 인물 흥미롭네, 어떤 이야기인지 보고 싶다"는 마음 상태를 만든다. 수학 개념 설명은 목적 아님 (그건 Concept 영상의 역할).

### 1.2 청중
- 중1 학생 (특히 감성적·내성적 학습자, 국어 강세)
- 부모/교사가 함께 보기 가능
- 짧은 attention span에 맞춰 50초

### 1.3 사용 시점
1. **단원 진입 전**: 학습 첫날 영상 시청 → 흥미 점화
2. **story.html 상단 임베드**: 단원 페이지 진입 시 자동 노출 또는 클릭 재생
3. **(미래) YouTube 플레이리스트**: 13개 묶음, 자가 학습 동기 부여

## 2. 표준 길이 정책

| 항목 | 값 |
|---|---|
| 목표 길이 | **50초** |
| 허용 범위 | 45~55초 |
| 나레이션 분량 | 한국어 240~270자 (TTS 5자/초 기준) |
| 도입/마무리 여백 | 시작 1초 + 끝 1초 (음악 페이드용 미래 대비) |

**길이 정한 이유**:
- 30초 미만: 인물 서사 담기 어려움
- 60초 초과: 학습자 attention 흐트러짐
- 50초 = 5장면 × 평균 10초 = 적절한 호흡

## 3. 5장면 구조 (Five-Act)

| 장면 | 시간 | 길이 | 목적 | 나레이션 분량 |
|---|---|---|---|---|
| S1 | 0:00–0:05 | 5s | 타이틀 — 인물·시대·단원 노출 | 20~25자 |
| S2 | 0:05–0:15 | 10s | 인물 등장 — 시대·장소·역할 | 45~55자 |
| S3 | 0:15–0:32 | 17s | 결정적 순간 — 문제·발견의 메타포 | 80~90자 |
| S4 | 0:32–0:45 | 13s | 수학과의 연결 — "오늘 우리가 배우는…" | 60~70자 |
| S5 | 0:45–0:50 | 5s | 마무리 — "이 단원에서 만날 이야기" | 20~25자 |

### 3.1 장면별 시각 가이드

**S1 — 타이틀** (정적 + 페이드 인)
- 중앙 정렬: 인물명 (큰 명조체)
- 부제: 시대·장소 (작은 산세리프)
- 우하단: 단원 번호·이름 (subtle)
- 배경: 단원 팔레트의 메인 컬러

**S2 — 인물 등장** (좌측 시각 + 우측 텍스트)
- v1: 좌측에 시대 상징 SVG (예: 도서관 두루마리)
- v2~: 인물 실루엣 + 시대 배경
- 우측: 인물 소개 텍스트 (좌측 정렬, 2~3줄)

**S3 — 결정적 순간** (전체 화면 메타포)
- 핵심 발견·문제를 시각적 메타포로
- 예 (에라토스테네스): 별빛이 우물에 비치는 장면 → 도형으로 추상화
- 텍스트 최소, 시각이 주인공
- 1~2초마다 살짝 변화 (zoom, fade, position shift)

**S4 — 수학과의 연결** (다이어그램 + 캡션)
- 인물의 발견이 오늘 어떻게 이어지는지
- 단원 핵심 개념 그래픽 1개 (수직선, 좌표축, 그리드 등)
- 캡션: "오늘 우리는 ___ 를 배웁니다"

**S5 — 마무리** (텍스트 only, 페이드 아웃)
- 짧은 한 문장: "이 단원에서, 그를 만나봅시다"
- 단원 번호·이름 마지막 강조

### 3.2 장면 전환 규칙
- 모든 전환: **1초 fade** (opacity 0→1, GSAP)
- 음성과 시각 동기: 나레이션 새 문장 시작 = 새 장면 시작
- `tl.call()` 사용 금지 (HyperFrames seek 미호환)

## 4. 톤 & 시각 원칙

### 4.1 톤 가이드

| 권장 | 지양 |
|---|---|
| "기원전 240년, 어느 도서관…" (이야기체) | "에라토스테네스는 수학자였다" (백과사전체) |
| "그는 신기한 생각을 했습니다" (호기심 유발) | "다음과 같은 방법을 제시합니다" (강의체) |
| 짧은 문장, 한 호흡씩 끊기 | 복문, 만연체 |
| 현재 진행형 ("…하고 있었습니다") | 단순 과거 ("…했다") |

### 4.2 시각 원칙
1. **단원별 시대 분위기** — 인물·지역·시대를 컬러로 차별화
2. **한 화면 한 메시지** — 텍스트와 시각을 동시에 폭격하지 않음
3. **여백 존중** — 1280×720 캔버스의 30% 이상은 항상 빈 공간
4. **타이포그래피가 주연**: 제목은 명조 (Nanum Myeongjo), 본문은 산세리프 (Noto Sans KR)

### 4.3 단원별 팔레트 매핑 (요약)

상세는 `_assets/palettes.css` 참조. 키워드 톤만 제시:

| 단원 | 인물 | 시대·지역 | 톤 |
|---|---|---|---|
| 01 | 에라토스테네스 | BCE 240, 알렉산드리아 | sand + night sky |
| 02 | 브라마굽타 | 628, 인도 | saffron + indigo |
| 03 | 알콰리즈미 | 820, 바그다드 | gold + teal |
| 04 | 디오판토스 | 250, 알렉산드리아 | parchment + crimson |
| 05~06 | 데카르트 | 1637, 프랑스 | snow + ink |
| 07~12 | (도형 인물군) | 다양 | warm neutrals |

## 5. 진화 단계 (v1~v4)

Nick 원칙: **simple to complex but better**. 일찍 락-인하지 않고 점진 진화.

| 버전 | 시각 수준 | 추가 도구·자산 | 적용 단원 |
|---|---|---|---|
| **v1** | 텍스트 + 단순 SVG 심볼만 | _symbols/ 5~6개 | Unit 01 |
| **v2** | 인물 실루엣 + 시대 배경 SVG | inkscape/sketch SVG | Unit 02~03 |
| **v3** | 컬러 일러스트 (AI 생성→SVG 트레이스) | DALL-E/Imagen + potrace | Unit 04~06 |
| **v4** | 시네마틱 (parallax, particle, sound) | GSAP MotionPath, Howler.js | Unit 07~13 |

각 단계 사이에 **회고 라운드**: Nick과 함께 무엇이 효과적이었는지 정리 후 다음 단계 결정.

## 6. 기술 스택 & 파이프라인

### 6.1 도구

| 단계 | 도구 | 버전 (2026-05 기준) |
|---|---|---|
| TTS | edge-tts | 7.2.8 |
| 컴포지션 | HTML + GSAP 3.14 | (CDN) |
| 렌더 | HyperFrames | 0.4.42 |
| 합성 | FFmpeg | 8.1 |

### 6.2 파이프라인

```
narration.txt  (240~270자)
    │
    ▼ edge-tts --voice ko-KR-SunHiNeural
narration.mp3  (45~55s)
    │
    ▼ ffprobe로 정확한 길이 측정 → AUDIO_DURATION
    │
index.html  (story-master 템플릿 + 단원 데이터 주입)
    │
    ▼ GSAP 타임라인이 AUDIO_DURATION에 정확히 동기화
    │
    ▼ hyperframes render -f 24 -q standard
raw.mp4  (영상만)
    │
    ▼ ffmpeg -map 0:v -map 1:a -c:v copy -c:a aac -shortest
final.mp4  (영상 + 음성)
```

### 6.3 영상-음성 동기 정밀도
- 나레이션 새 문장 = 새 장면 = GSAP 절대 시간값
- TTS 합성 후 실제 길이로 `data-duration` 재계산
- 오디오 길이 < 영상 길이: ffmpeg `-shortest`로 자름
- 오디오 길이 > 영상 길이: 영상 끝에 추가 fade out (대응)

## 8. 임베드 정책

### 8.1 story.html 임베드 방식

```html
<!-- story.html 상단, hero 섹션 직후 -->
<div class="story-video">
  <video controls preload="metadata" poster="../video/unitNN/poster.jpg">
    <source src="../video/unitNN/final.mp4" type="video/mp4">
    이 영상을 재생할 수 없습니다.
  </video>
</div>
```

- 자동 재생 ❌ (학습자 선택권)
- 클릭 재생 ⭕
- poster 이미지: S1 타이틀 화면 (FFmpeg로 추출 가능)

### 8.2 GitHub Pages 배포
- 소스: `mid_eun/90_video/unitNN/final.mp4`
- 배포: `jwj-nick.github.io/mid1/math1/unitNN/video/final.mp4`
- 동기화 스크립트에 video/ 경로 추가 필요 (향후)

### 8.3 영상 크기 정책
- 1280×720 MP4 = 단편당 ~3~8MB 예상
- 13단원 합계 ~50~100MB
- GitHub 100MB 단일 파일 제한 내, 무리 없음

## 9. 품질 체크리스트

영상 완성 후 다음을 확인:

### 9.1 기술
- [ ] 1280×720, 24fps
- [ ] 길이 45~55초
- [ ] 오디오 클리핑 없음 (peak < 0)
- [ ] 영상-음성 sync (±0.3초 이내)
- [ ] 파일 크기 < 10MB

### 9.2 내용
- [ ] 5장면 모두 명확히 구분됨
- [ ] 첫 5초 안에 인물명·시대 노출
- [ ] 핵심 메타포가 직관적
- [ ] 수학 연결이 자연스러움 (강의 톤 X)
- [ ] 마지막 5초에 "단원에서 만남" 멘트

### 9.3 학습자 적합성
- [ ] 중1 어휘 수준
- [ ] 한자어 최소
- [ ] 영문 약어 등장 시 한국어 병기
- [ ] 톤이 따뜻하고 호기심 유발

### 9.4 디자인
- [ ] 단원 팔레트 일관 적용
- [ ] 텍스트와 시각이 한 화면에서 충돌하지 않음
- [ ] 여백 충분 (30%+)
- [ ] 폰트 깨짐 없음

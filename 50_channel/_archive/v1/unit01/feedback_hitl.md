## 2. NCC 제작 방식

### 2.1 사용한 자료(Source)
- `50_units/01_*/story/unit01.md` — 인물 서사 원문
- `50_units/01_*/story.html` — 인터랙티브 서사 (5장 구조 확인)
- `20_research/02_R2-people-map.md` — R2 인물 자료 (있는 경우)
- 일반 수학사 지식 (NCC 학습 기반)

### 2.2 파이프라인
1. `90_video/unit01/storyboard.md` — 5장면 설계
2. `narration.txt` (194자) → edge-tts (ko-KR-SunHiNeural)
3. `config.json` → `build_index.py`로 마스터 템플릿 + 단원 데이터 주입
4. `index.html` (GSAP 5장면 타임라인) → HyperFrames 렌더
5. `raw.mp4` + `narration.mp3` → FFmpeg 합성 → `final.mp4`

### 2.3 시각 자산 (SVG 심볼)
- Scene 2 (인물 등장): `_assets/symbols/scroll.svg`
- Scene 3 (결정적 순간): `_assets/symbols/sieve-grid.svg`
- Scene 4 (수학 연결): `_assets/symbols/star.svg`

### 2.4 5장면 구조 (실제 길이 45.07초 기준 스케일링)

| 장면 | 시간 (50초 기준) | 내용 |
|---|---|---|
| S1 (0~5s) | 타이틀 | "에라토스테네스" / BCE 3세기 · 알렉산드리아 |
| S2 (5~15s) | 인물 등장 | "도서관에서 일하던 한 학자" |
| S3 (15~32s) | 결정적 순간 | 키워드: "체로 거르다" |

GSAP 타임라인은 `data-duration` 기반 비례 스케일링 (마스터 템플릿 자동).

기원전 3세기, 알렉산드리아에서 시작된 이야기.

도서관에서 일하던 한 학자가 있었습니다. 친구들은 그를 베타라 불렀어요. 모든 분야에서 2등이라는 별명.

수학의 원자, 소수. 어디에 어떻게 있을까. 그는 체를 생각했어요. 숫자를 체로 걸러 소수만 남기는 방법. 2000년이 지난 지금도 컴퓨터가 그대로 씁니다.

모든 자연수는 소수들의 곱으로 나타낼 수 있어요. 이것을 소인수분해라고 합니다. 오늘 그가 걸었던 길을 함께 걸어봅시다.

이 단원에서, 에라토스테네스를 만나봅시다.

## 4. 검토 체크리스트

### 4.1 기술 (객관)
- [ ] 영상이 정상 재생됨
- [ ] 한국어 폰트 깨짐 없음
- [ ] 음성-영상 sync 적절 (장면 전환과 음성 흐름 일치)
- [ ] 5장면이 명확히 구분됨
- [ ] 마지막 페이드 아웃 자연스러움

### 4.2 내용 (주관)
- [ ] 첫 5초 안에 인물명·시대 노출
- [ ] 인물의 매력이 전달되는가
- [ ] 핵심 메타포가 직관적인가
- [ ] 수학 연결이 자연스러운가 (강의 톤이 아닌가)
- [ ] 마지막 5초가 "단원 진입"의 기대감을 주는가

### 4.3 학습자 적합성 (중1 딸 기준)
- [ ] 어휘가 너무 어렵지 않음
- [ ] 톤이 따뜻하고 호기심 유발

- [ ] 다시 보고 싶은 마음이 드는가

### 4.4 시각 디자인

- [ ] SVG 심볼이 메시지와 어울림
- [ ] 텍스트가 읽히는 시간이 충분
- [ ] 여백이 충분 (산만하지 않음)

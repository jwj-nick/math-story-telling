## 2. NCC 제작 방식

### 2.1 사용한 자료(Source)
- `50_units/10_*/story/unit10.md` — 인물 서사 원문
- `50_units/10_*/story.html` — 인터랙티브 서사 (5장 구조 확인)
- `20_research/02_R2-people-map.md` — R2 인물 자료 (있는 경우)
- 일반 수학사 지식 (NCC 학습 기반)

### 2.2 파이프라인
1. `90_video/unit10/storyboard.md` — 5장면 설계
2. `narration.txt` (187자) → edge-tts (ko-KR-SunHiNeural)
3. `config.json` → `build_index.py`로 마스터 템플릿 + 단원 데이터 주입
4. `index.html` (GSAP 5장면 타임라인) → HyperFrames 렌더
5. `raw.mp4` + `narration.mp3` → FFmpeg 합성 → `final.mp4`

### 2.3 시각 자산 (SVG 심볼)
- Scene 2 (인물 등장): `_assets/symbols/sun.svg`
- Scene 3 (결정적 순간): `_assets/symbols/circle-sector.svg`
- Scene 4 (수학 연결): `_assets/symbols/scroll.svg`

### 2.4 5장면 구조 (실제 길이 45.26초 기준 스케일링)

| 장면 | 시간 (50초 기준) | 내용 |
|---|---|---|
| S1 (0~5s) | 타이틀 | "아르키메데스" / BCE 3세기 · 시라쿠사 |
| S2 (5~15s) | 인물 등장 | "유레카!" |
| S3 (15~32s) | 결정적 순간 | 키워드: "원주율을 찾아서" |
| S4 (32~45s) | 수학 연결 | "오늘 우리는" |
| S5 (45~50s) | 마무리 | "이 단원에서, 아르키메데스를 만나봅시다" |

GSAP 타임라인은 `data-duration` 기반 비례 스케일링 (마스터 템플릿 자동).

## 2. NCC 제작 방식

### 2.1 사용한 자료(Source)
- `50_units/11_*/story/unit11.md` — 인물 서사 원문
- `50_units/11_*/story.html` — 인터랙티브 서사 (5장 구조 확인)

- 일반 수학사 지식 (NCC 학습 기반)

### 2.2 파이프라인
1. `90_video/unit11/storyboard.md` — 5장면 설계
2. `narration.txt` (210자) → edge-tts (ko-KR-SunHiNeural)
3. `config.json` → `build_index.py`로 마스터 템플릿 + 단원 데이터 주입
4. `index.html` (GSAP 5장면 타임라인) → HyperFrames 렌더
5. `raw.mp4` + `narration.mp3` → FFmpeg 합성 → `final.mp4`

### 2.3 시각 자산 (SVG 심볼)
- Scene 2 (인물 등장): `_assets/symbols/star.svg`
- Scene 3 (결정적 순간): `_assets/symbols/polyhedra.svg`
- Scene 4 (수학 연결): `_assets/symbols/circle-sector.svg`

### 2.4 5장면 구조 (실제 길이 47.52초 기준 스케일링)

## 3. 나레이션 전문

```
17세기. 한 천문학자가 별빛 속에서 도형을 발견합니다.

그는 평생 행성의 움직임을 연구했어요. 그리고 우주가 다섯 정다면체로 설계되어 있다고 믿었지요. 천체와 도형은 그의 마음 속에서 하나였습니다.

정사면체, 정육면체, 정팔면체, 정십이면체, 정이십면체. 오직 다섯 종류만 존재하는 정다면체. 그는 이 다섯 도형을 우주를 떠받치는 기둥으로 보았어요.

다면체와 회전체. 평면 도형을 돌려 입체를 만들고, 면을 모아 다면체를 만듭니다. 그가 사랑한 입체의 세계로 떠나봅시다.

이 단원에서, 케플러를 만나봅시다.
```

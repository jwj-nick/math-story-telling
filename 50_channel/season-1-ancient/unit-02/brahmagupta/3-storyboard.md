## S1 — 우자인 천문대 야경 (18s)

### 시각 (정밀)
- 와이드 샷. 7세기 인도 우자인 석조 천문대, 별이 가득한 밤하늘, 멀리 학자 실루엣 1~2명
- 따뜻한 등불 + 남청 밤하늘 (사프란·황토·남청 대비)
- era-ancient 인도 팔레트

### 카메라 워크
- 정적 와이드(0~6s) → 천천히 push in(6~14s) → 천문대 관측대 클로즈업(14~18s)

### 텍스트 자막
- (없음 — 도입부)

### 나레이션 (95자) → STEP4 dialog 분리
> 7세기 인도, 도시 우자인. 별의 길을 수로 풀어내던 천문대가 있었다. 그 대장의 이름은 브라마굽타. 별을 계산하다 보면, 자연수만으로는 모자란 순간이 온다.

### 음향

- 효과음: 밤 풀벌레, 등불 타는 소리(subtle)

### 전환

## S2 — 빚도 수다 (22s)

### 시각 (정밀)
- 브라마굽타 클로즈업(캐릭터 §0.1), 점토판을 든 손
- 점토판 두 칸: 좌 *재산*(금화 더미, gold) / 우 *빚*(붉은 마이너스)
- 하단에 수직선 페이드 인: 0 기준, 우 +1+2+3, 좌 −1−2−3

### 카메라 워크
- 클로즈업 정적(0~10s) → 천천히 zoom out(10~18s) → 수직선 하단 강조(18~22s)

### 텍스트 자막
- "빚도 수다" (12~18s, 화면 중앙, gold, serif)
- 수직선 숫자 −3…0…+3 (16~22s)

### 나레이션 (120자) → STEP4 dialog
> 그는 추상이 아니라 회계에서 시작했다. 가진 것은 재산, 갚을 것은 빚. 재산은 플러스, 빚은 마이너스. 그런데 그 누구도 빚을 정식 수로 쓴 적이 없었다. 628년, 그가 처음으로 선언한다 — 빚도 수다.

### 음향
- 배경음 계속(잔잔)
- 효과음: 점토판에 첨필로 긁는 소리

### 전환
- 1s cut → S3 규칙판

## S3 — 음수의 규칙, 빚×빚=재산 ★ (28s)

### 시각 (정밀)
- 점토판 배경(브라마굽타 손이 새기는 1~4s), 규칙 4줄 차례 등장:
  - 재산+재산=재산 (＋＋→＋) (5~9s)
  - 빚+빚=더 큰 빚 (−−→−) (9~14s)
  - 재산×빚=빚 (＋×−→−) (14~19s)
  - **빚×빚=재산 (−×−→＋)** ← gold, 가장 크게 (19~25s)
- 마지막 줄 정지 + "음수 × 음수 = 양수" 자막(25~28s)

### 카메라 워크
- 손 클로즈업 → zoom out → 규칙판 정적(줄 내부 fade in 애니)

### 텍스트 자막
- 규칙 4줄 (빚=붉음/재산=gold 아이콘 + 부호식)
- "음수 × 음수 = 양수" (25~28s, gold, 화면 중앙, 큰 폰트)

### 나레이션 (150자) → STEP4 dialog (Q: "음수×음수가 왜 양수야?")
> 그는 음수를 쓰는 데 그치지 않고, 다루는 규칙을 적었다. 인류 최초의 음수 규칙. 재산 더하기 재산은 재산. 빚 더하기 빚은 더 큰 빚. 그리고 — 빚 곱하기 빚은 재산. 음수 곱하기 음수가 양수인 이유, 1400년 전 이미 적혀 있었다. 빚이 사라지는 건 이득이니까.

### 음향
- 배경음: 미세 긴장 증가
- 효과음: 줄 등장마다 "ding"(4회), 마지막 줄 강조음

### 전환
- 1s cut → S4 (0 등장)

## S4 — 0, 그리고 0÷0의 한계 (22s)

### 시각 (정밀)
- 수직선 중앙 *0* 이 빛나며 확대(gold)(1~8s)
- 0+a=a, 0×a=0 짧게(8~13s)
- 화면 어둑해지며 "0 ÷ 0 = ?" 물음표 깜빡임 → 흐려짐(13~20s)
- "후세 수정" 작은 자막(18~22s)

### 카메라 워크
- 0 zoom in(1~8s) → 규칙 표시(8~13s) → 전체 dim + 물음표 페이드(13~22s)

### 텍스트 자막
- "0 + a = a   0 × a = 0" (8~13s, 하단)
- "0 ÷ 0 = ?" (13~20s, 화면 중앙, 흐려지는 효과)
- "후세 수정" (18~22s, 작게, 하단)

### 나레이션 (115자) → STEP4 dialog (Q: "0으로 나누면?")
> 그는 한 걸음 더 갔다. 없음을 뜻하는 0도 정식 수로 다뤘다. 0을 더하면 그대로, 0을 곱하면 0. 그러나 그조차 끝내 풀지 못한 게 있었다. 0으로 나누기. 위대한 발견에도, 아직 끝나지 않은 자리가 있다.

### 음향
- 배경음: 음색 어둑해짐(단조 전환)
- 효과음: 0 빛날 때 chime, 물음표 흐려질 때 reverb

### 전환
- 1s fade → S5 대비

## S5 — 그리스 막힘 vs 인도 돌파 ★ (25s)

### 시각 (정밀)
- 화면 가로 split:
  - 좌 *그리스*(0~13s 강조) — 흰 대리석, 선분/도형(수=길이), "−3cm?" 위 ✕(붉은 금지)
  - 우 *인도*(13~25s 강조) — 따뜻한 황토 점토판, 수직선이 0 왼쪽으로 자연스럽게 뻗음
- 우측이 점점 밝아짐(인도가 더 멀리 간 시각 대비)

### 카메라 워크
- 좌측 정적(0~10s) → 가로 swipe(10~13s) → 우측 정적 + 밝기 증가(13~25s)

### 텍스트 자막
- "그리스 — 수 = 길이" (3~10s, 좌 하단)
- "−3cm 막대는 없다" + ✕ (6~12s, 좌)
- "출발점이 달랐다" (18~25s, 화면 중앙, gold)

### 나레이션 (135자) → STEP4 dialog (Q: "그리스는 왜 못 했어?")
> 같은 시대, 그리스 수학은 정점에 있었다. 그런데 음수가 없었다. 그리스인에게 수는 곧 길이였으니까. 마이너스 3센티미터짜리 막대는 없다. 그래서 멈췄다. 브라마굽타는 길이가 아니라 회계에서 왔다. 출발점이 달랐기에, 더 멀리 갔다.

### 음향
- 배경음: 좌(서양 현악) → swipe → 우(인도 음색) 전환
- 효과음: swipe 효과음

### 전환
- 1s fade → S6 (split 합쳐짐 → 책 이동)

## S6 — 알콰리즈미 카메오 + "발명" 클로징 (25s)

### 시각 (정밀)
- 「브라마스푸타시단타」 필사본이 인도 → 바그다드로 이동하는 지도 애니(화살표)(1~10s)
- 바그다드에서 책을 펴는 학자 실루엣(알콰리즈미, 얼굴 X)(10~16s)
- 화면 중앙 큰 **발명** 자막(16~23s, gold, 자주 악센트)
- 부제 "음수는 발견이 아니라, 필요해서 만든 발명"(19~23s)
- 페이드 아웃(23~25s)

### 카메라 워크
- 지도 pan(인도→바그다드)(1~10s) → 학자 실루엣(10~16s) → "발명" fade in(16~23s) → fade out(23~25s)

### 텍스트 자막
- "인도 → 바그다드" (3~8s, 지도 위)
- **발명** (16~23s, gold, 화면 중앙, 큰 폰트 serif)
- 부제 "음수는 발견이 아니라, 필요해서 만든 발명" (19~23s, 작게, 하단)

### 나레이션 (95자) → STEP4 dialog (클로징)
> 150년 뒤, 그의 책은 바그다드로 건너간다. 그 책을 읽은 사람이 알콰리즈미 — 다음 이야기의 주인공이다. 음수는 원래 있던 게 아니다. 필요해서 만든 것. 필요하면, 새로운 수를 발명해도 된다.

### 음향
- 배경음: 클로징 톤(인도 현악 마무리, fade out 100→0%)
- 효과음: 책장 넘기는 소리

### 전환
- 페이드 아웃 → 채널 outro

## S1 — 지혜의 집 + 책 유입 (20s)

### 시각 (정밀)
- 와이드. 9세기 바그다드 지혜의 집 내부/외관 — 말굽 아치, 기하 타일 문양, 돔, 책 더미, 천구의, 번역하는 학자 2~3 실루엣
- 따뜻한 황금 등불 + 청록 타일. 한쪽에 동방(인도)에서 온 책 한 권 강조(빛)
- era-medieval 팔레트

### 카메라
- 정적 와이드(0~7s) → push in(7~16s) → 책 클로즈업(16~20s)

### 자막
- (없음 — 도입)

### 나레이션 (105자) → STEP4 dialog
> 9세기 바그다드, 세계의 지식이 모이던 지혜의 집. 지난 이야기 기억나? 인도 브라마굽타의 책도 이곳으로 왔어. 그 책을 읽은 학자가 있었지. 이름은 알콰리즈미.

### 음향
- 중동 현악(우드) fade in / 책장·펜 소리

### 전환
- 1s fade → S2

## S2 — 상속 + 알지브르·알무카발라 (22s)

### 시각 (정밀)
- 알콰리즈미 클로즈업(§0.1), 책상에 양피지, 곁에 청동 천칭 저울
- 상속 분배 도식(재산이 여러 몫으로 갈리는 흐름, 숫자 X — 도형/접시로)
- 책 「al-jabr w'al-muqābala」 = 기하 문양 표지(글자 X)

### 카메라
- 클로즈업 정적(0~10s) → zoom out(10~18s) → 책·저울(18~22s)

### 자막
- "알지브르 → 대수 (algebra)" (12~20s, gold, 중앙)

### 나레이션 (120자) → STEP4 dialog (Q: "무슨 문제를 풀었어요?")
> 그가 푼 건 현실 문제였어. 복잡한 재산 상속 계산. 그래서 825년, 책을 한 권 썼지. 제목이 곧 두 기술이야. 알지브르는 복원, 알무카발라는 균형. 이 알지브르에서 영어 단어 대수, 알지브라가 나왔어.

### 음향
- 배경 계속 / 양피지 소리

### 전환
- 1s cut → S3

---

## S3 — 균형, 저울 ★ (28s)

### 시각 (정밀)
- 큰 청동 천칭이 화면 중앙. 양접시 수평(1~6s)
- 왼접시에 추 추가 → 기울기(6~12s) → 오른접시에 같은 추 → 다시 수평(12~20s)
- 양접시 = 방정식 양변 암시(추 = 항). 균형 강조(20~28s)

### 카메라
- 저울 정적, 접시 기울기 애니(내부 모션). ken burns subtle

### 자막
- "양변을 늘 균형있게" (21~28s, gold, 중앙, 큰 폰트)

### 나레이션 (150자) → STEP4 dialog (Q: "왜 양쪽에 똑같이 더해요?")
> 저울을 떠올려 봐. 한쪽에 뭘 더하면 기울지? 그럼 반대쪽에도 똑같이 더해야 다시 수평이 돼. 방정식도 똑같아. 양쪽을 늘 균형 있게 맞추면서 답을 찾는 거야. 지금 우리가 양변에 같은 수를 더한다고 배우는 그 원리. 1200년 전, 알콰리즈미가 균형이라는 한 단어로 붙잡았어.

### 음향
- 긴장 미세 증가 / 저울 추 ding(2회), 수평 복귀 chime

### 전환
- 1s cut → S4

## S4 — 0~9 전파 + 두 단어 (22s)

### 시각 (정밀)
- 동(인도)→서(유럽) 지도 흐름. 숫자 0~9가 물결처럼 서진(1~12s)
- 로마 숫자(Ⅰ Ⅴ Ⅹ)가 0~9로 바뀌는 전환(12~17s)
- 책이 라틴어로 번역되는 암시(17~22s)

### 카메라
- 지도 pan 동→서 / zoom

### 자막
- "algebra · algorithm" (6~14s, white, 하단)
- "그의 이름 → 알고리즘" (15~22s, gold, 중앙)

### 나레이션 (120자) → STEP4 dialog (Q 감탄)
> 알콰리즈미는 또 큰 일을 했어. 인도에서 온 숫자 0부터 9까지를 정리해서 세계로 퍼뜨렸지. 유럽은 불편한 로마 숫자를 버렸어. 그리고 그의 이름은, 우리가 매일 쓰는 단어가 됐어. 알고리즘. 컴퓨터의 그 알고리즘이, 이 사람 이름이야.

### 음향
- 배경 변화(서진 시 음색 밝아짐) / swipe

### 전환
- 1s fade → S5

## S5 — 글자 없이 글로만 ★ 축 C (25s)

### 시각 (정밀)
- 좌: 알콰리즈미가 방정식을 *긴 문장*으로 적은 양피지(글자 x 없음, 빽빽한 문단)(1~10s)
- 우: 같은 식을 현대식 한 줄(x 포함)로 — split 대비(10~18s)
- 긴 문단 ↔ 한 줄. 문자의 힘 강조(18~25s)

### 카메라
- 좌 정적 → swipe → 우 강조

### 자막
- "글자 없이, 글로만" (4~12s, white, 좌)
- "문자 x = 발명품" (16~25s, gold, 중앙)

### 나레이션 (140자) → STEP4 dialog (Q: "글자를 안 썼다고요?")
> 근데 놀라운 게 있어. 대수학의 아버지인데, 정작 글자를 안 썼어. x 같은 문자가 없었거든. 방정식을 전부 말과 글로 풀어 적었지. 한 문단으로. 우리가 너무 당연하게 쓰는 문자 x는, 훨씬 나중에 온 발명품이야. 글자가 없던 시대가, 글자가 얼마나 강한 도구인지 거꾸로 보여줘.

### 음향
- 배경 / 펜 긁는 소리(좌) → 가벼운 chime(우)

### 전환
- 1s fade → S6

## S6 — 이어달리기 + "균형" 클로징 (25s)

### 시각 (정밀)
- 700년 시간 점프(연표/모래시계)(1~6s)
- 비에트(16C 프랑스) → 데카르트(x,y) 짧은 카메오(얼굴 흐릿, 6~13s)
- 이어달리기 시각: 브라마굽타→알콰리즈미→데카르트(13~17s)
- 화면 중앙 큰 **균형** + 청동 천칭 아이콘(17~23s)
- 부제 "저울처럼 양변을 맞추는 일"(20~23s) → 페이드(23~25s)

### 카메라
- 정적 → "균형" fade in → fade out

### 자막
- "비에트 · 데카르트" (8~13s, white, 하단)
- **균형** (17~23s, gold, 중앙, 큰 폰트)
- 부제 "저울처럼 양변을 맞추는 일" (20~23s, white, 하단)

### 나레이션 (110자) → STEP4 dialog (클로징)
> 글자가 들어오기까진 700년이 더 걸렸어. 프랑스의 비에트, 그리고 데카르트가 x, y로 정리했지. 데카르트는 이 시즌 마지막에 다시 만나. 음수를 만든 브라마굽타, 대수로 묶은 알콰리즈미, 글자를 입힌 데카르트. 수학은 시대를 건너온 이어달리기야. 알콰리즈미가 남긴 한 단어, 균형.

### 음향
- 클로징 톤(우드 마무리, fade out)

### 전환
- 페이드 아웃 → outro

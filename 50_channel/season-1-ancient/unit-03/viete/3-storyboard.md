## S1 — 산문 가득한 수학 + 알콰리즈미 callback (20s)

### 시각 (정밀)
- 와이드. 산문(긴 문장)으로 빽빽이 채워진 옛 필사본·양피지 더미 — 식이 *문장으로만* 적힌 텍스처(글자 X, 빽빽한 손글씨 질감)
- 한쪽에 짧은 기호 한 줄이 빛으로 떠오르는 암시(자막은 drawtext)
- 촛불 금색 + 양피지 크림 + 잉크 흑. era-modern 팔레트
- 알콰리즈미 시대(글로만 풀던)에서 이어지는 분위기

### 카메라
- 정적 와이드(0~7s) → push in(7~16s) → 짧은 한 줄 클로즈업(16~20s)

### 자막
- (없음 — 도입)

### 나레이션 (105자) → STEP4 dialog
> 수백 년 동안 수학책은 문장으로 가득했어. "어떤 수에 다섯을 더하면 여덟이 되는 그 수" 이런 식으로. 지난 편 알콰리즈미도 방정식을 전부 말로 풀어 적었지. 식을 한눈에 볼 방법이 없었어.

### 음향
- 차분한 르네상스 현악(류트) fade in / 책장·깃펜 소리

### 전환
- 1s fade → S2

## S2 — 변호사·암호 해독자 비에트 (22s)

### 시각 (정밀)
- 비에트 클로즈업(§0.1), 16C 프랑스 서재, 손에 깃펜, 책상에 봉인된 암호 편지와 알파벳 표
- 촛불 조명, 차분하고 명민한 표정, 잉크병·필사본
- 암호 편지 = 알 수 없는 기호들(읽을 수 없는 문양, 실제 글자 X)

### 카메라
- 클로즈업 정적(0~10s) → zoom out(10~18s) → 책상·편지(18~22s)

### 자막
- (없음/소개 — drawtext 없이 인물 소개에 집중하거나 짧은 이름 자막 옵션)

### 나레이션 (120자) → STEP4 dialog (Q: "수학자가 아니었어요?")
> 그때 비에트라는 사람이 있었어. 16세기 프랑스의 변호사였지. 유명한 건 따로 있었어. 스페인이 프랑스로 보내던 암호를, 비에트가 풀어버렸거든. 스페인 왕이 악마랑 손잡았다고 할 정도였어. 수학은 그냥 취미였는데, 식이 글자로 안 적힌 게 답답했던 거야.

### 음향
- 배경 계속 / 봉랍 뜯는 소리·깃펜 소리

### 전환
- 1s cut → S3

## S3 — 모음=미지수·자음=아는수 ★ (28s)

### 시각 (정밀)
- 비에트의 깃펜이 양피지에 글자를 적는 클로즈업(1~8s)
- 알파벳 표가 둘로 갈림: 왼쪽 모음(A E I O U) 영역 = 따뜻하게 빛남(미지수) / 오른쪽 자음(B C D…) 영역 = 차분한 톤(아는 수)(8~18s)
- 긴 산문 한 문단이 → 짧은 기호 한 줄로 압축되는 시각(18~28s)
- 1591 「Isagoge」 책 = 문양 표지(글자 X)

### 카메라
- 깃펜 정적 → 알파벳 표 내부 모션(좌/우 강조) → ken burns subtle

### 자막
- "수를 글자로 적다 (1591)" (10~18s, white, 상단)
- "모음 = 미지수 · 자음 = 아는 수" (20~28s, gold, 중앙, 큰 폰트)

### 나레이션 (150자) → STEP4 dialog (Q: "수를 글자로 적었다고요?")
> 1591년, 비에트가 큰 결정을 했어. 모르는 수, 미지수는 모음으로. 아는 수는 자음으로 적기로 한 거야. 처음으로 수를 글자로 적은 거지. "어떤 수"라는 긴 말 대신, 그냥 에이 한 글자. 산문 한 문단이 기호 한 줄이 됐어. 이게 기호 대수의 시작이야. 드디어 식을 눈으로 보게 된 거지.

### 음향
- 깃펜 긁는 소리 → 글자 자리잡는 chime / 류트 배경

### 전환
- 1s cut → S4

## S4 — 기호=발명된 약속 ★ 축 C (25s)

### 시각 (정밀)
- 모음/자음 글자들이 손에 의해 *정해지는* 시각(약속·선택)(1~9s)
- "x y a b" 글자가 처음엔 무겁고 어둡게 떠 있다가 → 가볍고 따뜻하게 바뀜(9~18s)
- 자연 법칙이 아니라 사람의 약속 = 깃펜·손·봉인 도장 모티프(저울/자물쇠 X)(18~25s)

### 카메라
- slow zoom in, 글자 톤 변화 강조

### 자막
- "자연 법칙이 아니라" (5~13s, white, 상단)
- "기호 = 발명된 약속" (15~25s, gold, 중앙, 큰 폰트)

### 나레이션 (140자) → STEP4 dialog (Q: "기호가 그냥 약속이라고요?" 축 C Q)
> 근데 중요한 게 있어. 비에트가 모음을 고른 건, 무슨 자연 법칙이 아니야. 그냥 한 사람의 약속이었어. 자음을 골랐으면 우리가 지금 다른 글자를 쓰고 있겠지. 그러니까 엑스, 와이, 이런 기호도 사실은 사람이 편하려고 만든 약속일 뿐이야. 무서워할 게 아니라, 누가 정한 약속인 거지.

### 음향
- 글자 톤 바뀔 때 따뜻한 chime / 배경

### 전환
- 1s fade → S5

## S5 — 거듭제곱은 아직 (A quadratus) (22s)

### 시각 (정밀)
- 좌: 비에트가 "A의 제곱"을 *라틴어 단어* 로 길게 적은 양피지(작은 ² 없음, 긴 단어)(1~9s)
- 우: 미래의 "A²" 작은 위첨자가 흐릿하게 예고(split 대비)(9~17s)
- 한 사람이 다 못 함 = 바통(이어달리기) 모티프(17~22s)

### 카메라
- 좌 정적 → swipe → 우 예고

### 자막
- "A의 제곱을 단어로" (4~12s, white, 좌)
- "A의 제곱 → A²" (14~22s, gold, 중앙)

### 나레이션 (120자) → STEP4 dialog (Q: "제곱은 어떻게 적었어요?")
> 근데 비에트가 다 끝낸 건 아니야. 제곱을 아직 글자로 못 적었거든. "에이의 제곱"을 라틴어 단어로 길게 썼어. 우리가 쓰는 작은 2는 아직 없었지. 한 사람이 다 하는 게 아니야. 비에트가 글자를 가져왔으면, 다음 사람이 그걸 더 다듬을 차례였어.

### 음향
- 펜 긁는 소리(좌) → 가벼운 chime(우)

### 전환
- 1s fade → S6

## S6 — 데카르트 카메오 + "기호" 클로징 (25s)

### 시각 (정밀)
- 약 50년 시간 점프(연표/모래시계)(1~6s)
- 데카르트(17C 유럽) 짧은 카메오(얼굴 흐릿, 다음 예고)(6~13s)
- 이어달리기 시각: 알콰리즈미 → 비에트 → 데카르트(13~17s)
- 화면 중앙 큰 **기호** + 깃펜·알파벳 표 아이콘(17~23s)
- 부제 "수를 글자로 적는 약속"(20~23s) → 페이드(23~25s)

### 카메라
- 정적 → "기호" fade in → fade out

### 자막
- "알콰리즈미 → 비에트 → 데카르트" (8~16s, white, 상단)
- **기호** (18~24s, gold, 중앙, 큰 폰트)
- 부제 "수를 글자로 적는 약속" (21~24s, white, 하단)

### 나레이션 (110자) → STEP4 dialog (클로징, "기호" 강조)
> 약 50년 뒤, 데카르트가 등장해. 비에트의 약속을 다시 정리했지. 아는 수는 에이 비 씨, 모르는 수는 엑스 와이 제트. 제곱도 작은 2로. 지금 우리 교과서 그대로야. 데카르트는 이 시즌 마지막에 다시 만나. 알콰리즈미, 비에트, 데카르트. 수학은 시대를 건너온 이어달리기야. 비에트가 남긴 한 단어, 기호.

### 음향
- 클로징 톤(류트 마무리, fade out)

### 전환
- 페이드 아웃 → outro

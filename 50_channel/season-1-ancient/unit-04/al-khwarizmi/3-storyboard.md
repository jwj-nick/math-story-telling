## S1 — 지혜의 집 + 디오판토스 callback (20s)
### 시각
- 와이드. 9세기 바그다드 지혜의 집, 말굽 아치·청록 기하 타일·돔, 번역하는 학자들, 황금 램프 빛
- 한쪽에 동(알렉산드리아)에서 막 들어온 그리스 두루마리 한 권이 은은히 빛남 (디오판토스 책 = 같은 단원 primary 연결)
- era-medieval + 테라코타 악센트
### 카메라: 정적 와이드(0~7) → push in(7~16) → 빛나는 두루마리(16~20)
### 자막: (없음)
### 나레이션 (110자) → dialog
> 지난 편 디오판토스, 기억나? 모르는 나이를 엑스로 놓아 푼 사람. 근데 그는 문제마다 새로 머리를 굴렸어. 정해진 방법이 없었지. 600년 뒤 바그다드에, 다른 질문을 던진 학자가 있었어. 알콰리즈미.
### 음향: 잔잔한 현악 fade in / 책장 넘기는 소리
### 전환: cut → S2

## S2 — 알지브르 = 옮김(이항) ★ (25s)
### 시각
- 가운데 등호(=) 추상 표현. 한쪽의 음수 항 블록이 **반대쪽으로 날아가 건너감**(이항 모션, 5~15s)
- 알콰리즈미 상반신 클로즈업(u03 ref 동일 인물, 책상·아스트롤라베 배경 blur)
- "빼던 것 → 옮기면 더하는 것" 부호 변화는 drawtext 로
### 카메라: ken_burns, 항 이동 강조
### 자막
- "옮기면 부호가 바뀐다" (10~18s, white, 상단 y=0.26)
- "이항 (al-jabr)" (20~25s, gold, 중앙 y=0.44)
### 나레이션 (130자) → dialog (Q: "옮기면 어떻게 돼요?")
> 그가 팔백이십오 년에 책을 썼어. 알지브르 와 알무카발라. 알지브르는 복원이라는 뜻이야. 한쪽에서 빼고 있던 걸, 반대쪽으로 옮겨서 되살리는 거지. 엑스에서 셋을 뺀 게 다섯이면, 셋을 옮겨서 엑스는 다섯에 셋을 더한 것. 빼던 게 옮기면 더하는 게 돼. 바로 이항이야.
### 음향: 항 이동 swoosh / 결정 chime
### 전환: cut → S3

## S3 — 알무카발라 = 상쇄(동류항) (25s)
### 시각
- 등호 양쪽에 똑같은 블록 한 쌍 → 동시에 사라짐(상쇄, 3~12s)
- 옮김 + 상쇄 반복 → 식이 점점 짧아져 깨끗한 표준형으로 줄어듦(12~25s)
- "엑스가 몇 개 + 얼마 = 얼마" 같은 모양으로
### 카메라: zoom_out (식 전체가 줄어드는 느낌)
### 자막
- "양쪽의 같은 것을 지운다" (8~16s, white, 상단 y=0.26)
- "동류항 정리 (al-muqabala)" (18~25s, gold, 중앙 y=0.44)
### 나레이션 (130자) → dialog (Q: "그건 뭐가 달라요?")
> 두 번째 기술은 알무카발라. 대조, 균형이라는 뜻이야. 등호 양쪽에 똑같이 들어 있는 걸 서로 지우는 거지. 지금 우리가 동류항 정리라고 부르는 거야. 옮기고, 지우고. 이 두 동작을 반복하면, 아무리 복잡한 식도 점점 깨끗한 한 모양으로 줄어들어.
### 음향: 블록 사라지는 pop / 정리되는 톤
### 전환: fade → S4

## S4 — 6유형 + algorithm 어원 (24s)
### 시각
- 흩어진 여러 식 덩어리가 화살표를 따라 **몇 개의 정해진 모양(유형)** 으로 모임(1~12s)
- 유형마다 정해진 단계(순서도/계단 느낌, 글자 없이 추상, 12~18s)
- 그의 이름이 라틴어로 옮겨져 한 단어로 퍼지는 흐름 암시(글자 X, 빛의 흐름만, 18~24s)
### 카메라: pan_right
### 자막
- "모든 식을 정해진 유형으로" (4~12s, white, 상단 y=0.28)
- "정해진 단계 = 알고리즘" (15~24s, gold, 중앙 y=0.44)
### 나레이션 (125자) → dialog (Q: "그럼 외울 필요가 없네요?")
> 알콰리즈미는 한 걸음 더 갔어. 풀 수 있는 모든 방정식을 여섯 가지 유형으로 나눴지. 유형마다 정해진 단계를 붙였어. 어떤 문제든, 먼저 어느 유형인지 가린 뒤 단계대로만 따라가면 답이 나와. 이게 바로 알고리즘. 그 단어가, 알콰리즈미라는 이름에서 왔어.
### 음향: 분류되는 ding / 빛 퍼짐
### 전환: fade → S5

## S5 — 글자 없이 단계로 풀다 ★ 축 C (24s)
### 시각
- 좌: 절차를 문장으로 길게 적은 양피지(글자 x 없음, 긴 문단 = 절차서, 1~12s)
- 우: 같은 절차를 현대식 x로 짧게(대비, 12~24s)
- "절차가 먼저, 문자는 나중" — 긴 문단 ↔ 짧은 한 줄
### 카메라: slow_zoom
### 자막
- "절차가 먼저, 문자는 나중" (6~14s, white, 상단 y=0.26)
- "문자 x = 발명품" (16~24s, gold, 중앙 y=0.44)
### 나레이션 (135자) → dialog (Q: "글자 없이 어떻게요?")
> 진짜 놀라운 건 이거야. 이 모든 옮김과 상쇄를, 글자 하나 없이 해냈어. 엑스 같은 문자가 없던 시대였거든. 그 양에서 얼마를 빼서 옮기고, 양쪽에서 같은 걸 덜어 내라. 전부 말과 글로, 단계를 문장으로 적었지. 방법이 먼저 있었고, 그걸 짧게 적는 문자 엑스는 한참 뒤에 온 발명품이야.
### 음향: 펜 소리 / 대비 톤
### 전환: fade → S6

## S6 — 데카르트 카메오 + "옮김" (24s)
### 시각
- 700년 시간 점프(모래시계/연표, 1~6s)
- 이어달리기: 동→서 세 학자 실루엣 — 디오판토스(알렉산드리아)→알콰리즈미(바그다드, u03 ref 동일 인물)→데카르트(유럽), 얼굴 흐림(6~14s)
- 화면 중앙 큰 **옮김** + 등호 양쪽으로 항이 건너가는 화살표 아이콘(14~22s)
- 부제 "음항을 옮기고 같은 것을 상쇄하는 일"(20~24s) → 페이드
### 카메라: zoom_in → "옮김" fade in → fade out
### 자막
- "디오판토스 → 알콰리즈미 → 데카르트" (8~16s, white, 상단 y=0.26)
- **옮김** (17~24s, gold, 중앙 y=0.42, 大)
- 부제 "음항을 옮기고 같은 것을 상쇄하는 일" (20~24s, white, 하단 y=0.74)
### 나레이션 (110자) → dialog (클로징)
> 글자가 들어오기까진 700년이 더 걸렸어. 17세기 프랑스의 데카르트가 엑스, 와이로 정리했지. 데카르트는 이 시즌 마지막에 다시 만나. 수수께끼를 세운 디오판토스, 누구나 푸는 절차로 바꾼 알콰리즈미, 글자를 입힌 데카르트. 수학은 시대를 건너온 이어달리기야. 알콰리즈미가 남긴 한 단어, 옮김.
### 음향: 클로징 톤(현악 마무리)
### 전환: 페이드 아웃 → outro

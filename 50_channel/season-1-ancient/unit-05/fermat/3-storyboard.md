## S1 — 낮엔 판사, 밤엔 수학자 (22s)
### 시각: 17세기 툴루즈, 검은 법복 차림 페르마가 일과를 마치고 촛불 켜진 서재 책상에 앉아 수학 책을 펴는 모습. 따뜻하고 차분한 저녁. 청록 톤
### 카메라: 정적(0~7) → push in(7~16) → 얼굴(16~22)
### 자막: (없음)
### 나레이션 (105자) → dialog (Q 도입)
> 데카르트 기억나? 같은 17세기, 프랑스 남쪽 툴루즈에 또 한 사람이 있었어. 피에르 드 페르마. 근데 그의 본업은 수학자가 아니었어. 법원 판사였지. 수학은 그저 일 끝나고 즐기던 취미였어.
### 음향: 잔잔한 바로크 현악 fade in / 촛불·종이
### 전환: fade → S2

## S2 — 책의 여백 (22s)
### 시각: 펼친 옛 책, 본문 옆 좁은 여백에 깃펜으로 메모 적는 손. 여백의 작은 글씨(추상, 읽히지 않음). 조용하고 따뜻한 톤
### 카메라: 여백 zoom in → 펜 끝 → 메모
### 자막: "수학은 취미였다" (10~20s, white, 하단)
### 나레이션 (110자) → dialog (Q: "논문을 안 냈다고요?")
> 페르마는 논문을 거의 안 냈어. 그의 수학은 대부분 편지랑, 책의 여백에 남았지. 특히 디오판토스의 옛 책 여백에 적은 한 줄은, 무려 삼백오십팔 년 동안 안 풀린 수수께끼가 됐어. 취미가 남긴 흔적이야.
### 음향: 펜 사각거림 / 잔잔
### 전환: fade → S3

## S3 — 따로, 같은 좌표 (26s)
### 시각: 좌우 분할 화면 — 왼쪽 데카르트 실루엣, 오른쪽 페르마. 각자 책상에서 똑같은 좌표축이 떠오름 → 가운데서 두 좌표축이 겹침. "두 번 도달"
### 카메라: ken_burns, 두 좌표축 fade in → 겹침
### 자막: "따로, 같은 발견" (16~26s, white, 중앙)
### 나레이션 (125자) → dialog (Q: "데카르트랑 똑같이요?")
> 놀라운 건 여기야. 페르마는 데카르트를 모른 채, 거의 같은 시기에 똑같은 발견을 했어. 1636년쯤 평면 위 곡선을 방정식으로 적는 원고를 썼거든. 이듬해 데카르트도 좌표법을 냈고. 서로 상의한 적도 없이, 인류가 같은 답에 두 번 도달한 거야.
### 음향: 신비 톤 / 두 음이 화음으로 겹침
### 전환: cut → S4

## S4 — 두 방향 ★ (28s)
### 시각: 다리 하나를 양쪽에서 건너는 비유. 왼쪽(데카르트) 원→식 화살표, 오른쪽(페르마) 식→모양 화살표. 두 화살표가 가운데서 만나 양방향 ↔
### 카메라: ken_burns, 양쪽 화살표 순차 등장
### 자막
- "데카르트: 그림 → 식 / 페르마: 식 → 그림" (8~18s, white, 상단)
- "식 ↔ 그림, 양방향" (21~28s, gold, 중앙)
### 나레이션 (145자) → dialog (Q: "방향이 달랐어요?")
> 근데 두 사람, 방향이 달랐어. 데카르트는 도형을 식으로 옮겼어. 동그란 원을 보고 식으로 적은 거지. 그림에서 식으로. 페르마는 반대였어. 식을 먼저 적어 놓고, 이 식을 만족하는 점을 찍으면 어떤 모양이 될까 물었어. 식에서 그림으로. 같은 다리를, 양쪽에서 건넌 거야.
### 음향: 두 모티프가 좌우에서 만남
### 전환: cut → S5

## S5 — 식 → 점 → 직선 ★ (26s)
### 시각: 식 y=2x 위에 떠 있고 → 표(엑스 1·2 / 와이 2·4) → 점 (1,2)(2,4) 좌표에 찍힘 → 직선 연결. 식이 점들을 지시(빛이 점으로 떨어짐)
### 카메라: ken_burns, 점→선 애니
### 자막
- "y = 2x  →  (1, 2), (2, 4)" (8~17s, white, 상단)
- "식이 그림이 된다" (20~26s, gold, 중앙, 大)
### 나레이션 (135자) → dialog (Q: "식을 어떻게 그려요?")  ← 딸 약점 핵심 Q
> 페르마의 방향이, 사실 우리가 학교에서 배우는 방식과 더 가까워. 식 와이는 2 곱하기 엑스. 엑스가 1이면 와이는 2, 엑스가 2면 와이는 4. 그 점들을 좌표에 찍어 봐. (1, 2), (2, 4). 그럼 직선 한 줄이 나타나. 식이 명령어가 되고, 그림이 저절로 나온 거야.
### 음향: 점 찍힐 때 ding → 직선 그어질 때 chime
### 전환: fade → S6

## S6 — 두 언어 = 번역 + "번역" (24s)
### 시각: 좌측 '식' / 우측 '그림' 두 패널이 ↔ 화살표로 오감(번역기) → 페르마가 여백에 펜을 놓는 마무리 → 중앙 큰 **번역** + 식↔그림 양방향 아이콘 → 페이드
### 카메라: zoom in → "번역" fade in → fade out
### 자막
- "식도 언어, 그림도 언어" (8~15s, white, 하단)
- **번역** (16~23s, gold, 중앙, 大)
- 부제 "식과 그림은 같은 말" (18~23s, white, 하단)
### 나레이션 (110자) → dialog (A 클로징, "번역")
> 그래서 둘이 함께 우리한테 준 건, 번역기야. 식도 언어, 그림도 언어. 둘은 다르게 생겼지만 같은 뜻이야. 데카르트는 그림을 식으로, 페르마는 식을 그림으로 번역했어. 낮엔 판사였던 아마추어가 남긴 한 단어. 번역.
### 음향: 클로징 톤(현악 마무리)
### 전환: 페이드 아웃 → outro

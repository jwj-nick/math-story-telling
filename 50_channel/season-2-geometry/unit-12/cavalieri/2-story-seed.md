# unit-12 카발리에리 — 스토리 시드 (6장면)

> 한 단어 **단면**. 약속 3겹: 시대(17C 볼로냐·1635 / 3세기 류후이 1400년) / 정서(통풍 수도사가 빵 썰며·스승 갈릴레오 잇기·12년 망설임) / 필연성(단면=불가분량 → 카발리에리 원리 → 적분).
> 같은 단원 아르키메데스(쌓기·2:3)와 **보완**: 모양은 달라도 *단면*만 같으면 부피가 같다는 적분적 직관 각도.

| 장면 | 한 줄 | 매체 의도 | 자막 키 |
|---|---|---|---|
| S1 | 수도사 카발리에리가 빵을 똑바로/비스듬히 쌓다 — 양은 같다 | 정서 hook. 신규 캐릭터 등장(ref) | 모양이 달라도 부피는 같다 |
| S2 | 무엇이 같은가 — 단면(불가분량) ★ | 입체→무수한 얇은 단면 다이어그램 | 입체는 단면이 쌓인 것 |
| S3 | 카발리에리의 원리 (1635) ★ | 두 다른 입체 같은 높이 단면 비교 | 단면이 같으면 부피도 같다 |
| S4 | 스승 갈릴레오를 잇다 — 12년 망설임 끝 출판 | 책 「Geometria」 + 카발리에리(ref) | 스승의 길을 잇다 |
| S5 | 1400년 앞선 류후이 — 동서양 같은 통찰 | 동(죽간)/서(양피지) 대칭 구도 | 동양에 1400년 앞서 |
| S6 | 그 단면이 적분이 되다 | 단면 슬라이스 엠블럼(좌측) | 단면 |

- 길이 ≤150s / 30 turn. voice **Q=Kanna(여) / A=Mike(남)** — 아르키메데스(Q=Kyle/A=Mina)와 성별 교차 pairing.
- 숫자 발화 = 한글(천육백삼십오/천사백/삼십오). filler 0 (bare 단독필러 회피, voice-pool §0.5).
- 개념 peak: S3 "단면 같으면 부피 같다". 정서 peak: S1 빵 hook → S4 스승 잇기.

# 중2 실전 모의고사 — exam.json 저작 스펙

> `EXAM_SPEC3.md`(중3판)를 math2(11단원)에 맞춰 이식했다. 목적·구조·검증 흐름은 같고 **할당표·금지 개념·답 표기**만 중2에 맞게 바뀐다.
> 회차 조립 스크립트가 이 풀에서 6회차를 뽑으므로 **할당표의 id·format·level 은 한 글자도 바꾸면 안 된다.**

## 1. 파일 위치와 최상위 구조

`30_content/problem_bank/math2/u{NN}/exam.json` (단원당 1파일. 기존 `practice.json` 은 **읽기 전용 참고용**):

```json
            "note": "중2 전범위 실전 모의고사용 문항 풀. EXAM_SPEC2.md 준수." },
  "problems": [ ...할당표 순서대로... ]
}
```

## 2. 중3판과 달라진 점

| 항목 | 중3판 | **중2판** |
|---|---|---|
| 문항 유형 | cn(신규 선택형) · cv(기존 변환) · sh(기존 복사) · es(신규 서술형) | **전부 신규 저작**. `c1~c9`(선택형) · `s1~s2`(단답) · `e1~e3`(서술형) |
| `source_id` | cv/sh 는 원본 id | **항상 `null`** — practice.json 은 겹치지 않게 확인하는 용도로만 본다 |
| 단원 수 | 12 | 11 |

이렇게 바꾼 이유: 중2 `practice.json` 은 238문항이 이미 유형별로 잘 나뉘어 있어 **연습용으로 그대로 쓰는 편이 낫고**, 모의고사는 처음 보는 문제일 때 값이 있다. 변환(cv)도 결국 보기 5개를 새로 설계해야 해서 비용이 신규 저작과 비슷하다.

## 3. 문항 스키마

| 필드 | 값 |
|---|---|
| `id` | 할당표 그대로. 예 `e03-c1` |
| `format` | `"choice5"` \| `"short"` \| `"essay"` |
| `level` | `"L"`/`"M"`/`"H"` (할당표 고정) |
| `topic` | 무엇을 재는지 짧은 라벨 |
| `source_id` | 항상 `null` |
| `stem_print` | 발문. 시험체(…를 구하시오 / …의 값은?) |
| `answer_print` | 정답 (choice5 는 정답 보기 문자열과 완전히 같게) |
| `answer_accept` | 이렇게 써도 맞는 표현 배열 또는 `null` (choice5 는 `null`) |
| `answer_unit` | 단위 또는 `null` |
| `answer_format` | 답의 형태 안내 (choice5: `"5지선다 — 번호로 답해요"`) |
| `figure` | **항상 `null`** — 도형 문항도 변·각을 문장에 모두 밝혀 말로 서술한다 |
| `hint` | 해요체 한 줄 |
| `solution` | 완전한 풀이 (해요체. 문어체 '~다.' 종결 금지) |
| `work_space` | `"sm"`/`"md"`/`"lg"` (essay 는 `"lg"`) |
| `misconceptions` | dotted 태그 배열 (`deci.*` `poly.*` `ineq.*` `sim2.*` `line.*` `tri.*` `quad2.*` `ratio2.*` `pyth.*` `prob.*`) |

format별 추가 필드
- `choice5`: `choices` 문자열 5개(①~⑤ 기호는 렌더러가 붙이므로 넣지 않음), `answer_choice` 1~5, `distractor_why` 4개(정답을 뺀 보기 순서대로 어떤 실수의 결과인지).
- `essay`: `rubric` `[{step, points}]` 2~3단계, **합계 정확히 8**.

## 4. 표기 규약

- KaTeX·`$` 금지. 거듭제곱 `<sup>`, 분수 `<span class="frac"><b>분자</b><i>분모</i></span>`, 각도 `∠`·`°`, 평행 `∥`, 수직 `⊥`, 합동 `≡`, 닮음 `∽`, 근호 `√`, π 는 문자 `π`.
- 음수 부호는 유니코드 마이너스 `−`(U+2212)로 통일 (stem·choices·answer 전부).
- 순환소수는 순환마디 위에 점을 찍는 대신 **`0.4̇5̇` 형태의 결합 문자 대신 `0.45̇` 같은 표기가 깨질 수 있으므로**, 발문에서는 `0.454545…` 처럼 말줄임표로 쓰고 필요하면 "순환마디가 45인 순환소수"라고 밝힌다.
- 도형 문항은 변·각을 문장에 모두 명시해 그림 없이도 유일하게 정해지게 쓴다.
- 발문은 요구문으로 끝난다: `…를 구하시오.` / `…을 쓰시오.` / `…은?`
- 앱 의존 표현 금지: `□`, 버튼, 슬라이더, 클릭, "위 그림에서".

## 5. 중2 교육과정 경계

- **쓸 수 있는 것**: 순환소수, 지수법칙, 단항식·다항식 계산, 일차부등식, 연립일차방정식, 일차함수와 그래프·직선의 방정식, 삼각형의 성질(이등변·내심·외심), 사각형의 성질과 포함 관계, 닮음과 닮음비(넓이비·부피비), 평행선과 선분의 비, 삼각형의 무게중심, 피타고라스 정리, 경우의 수와 확률.
- **금지**: 이차방정식·이차함수·인수분해·제곱근(√는 피타고라스 계산 결과 표기에만 쓰고 근호 계산 자체를 묻지 않음)·삼각비·원주각·표준편차·순열조합 기호(nPr, nCr).
- 피타고라스 계산 결과가 무리수면 `√13` 처럼 근호로 남기되, 근호끼리 곱하고 나누는 계산은 요구하지 않는다.

## 7. 품질 규칙

- 모든 문항을 **두 번 독립적으로 풀어** 정답을 재확인한다.
- choice5 는 보기 5개를 하나씩 검산해 **정답이 정확히 하나**임을 확인한다. 보기끼리 중복 금지, "정답 없음/모두 고르시오" 금지.
- 오답 보기 4개는 각각 **그럴듯한 실수의 결과**여야 한다(부호 실수, 공식 혼동, 한 단계 빠뜨림, 단위 착각). `distractor_why` 에 근거를 남긴다.
- 수치 보기는 작은 값 → 큰 값 순서. 정답 위치는 단원 안에서 같은 번호가 3회 이상 나오지 않게 한다.
- 한 단원 안에서 **서로 다른 유형 5가지 이상**을 다룬다.
- `practice.json` 과 같은 문제를 내지 않는다(숫자만 바꾼 복제 포함).

## 8. 검증

`verify_exam2.py` 가 이 스펙을 기계적으로 검사한다 — 스키마·할당표 일치·level 합계·정답 위치 분포·금지 표기(KaTeX, ASCII 하이픈 음수, `□`)·보기 중복·rubric 합계 8·해요체 종결. 통과 후 `plan_exam2.py` 로 6회차를 조립하고 `build_exam.py` → `print_pdf.ps1` 로 PDF 를 만든다.

# 중1 2학기 기말 세트 작성 규칙 (교과서 6·7단원)

## 범위 (교과서 단원 번호 기준)
- 6단원 평면도형의 성질
  - 6.1 다각형의 대각선: 한 꼭짓점에서 그은 대각선 n−3, 대각선 수 n(n−3)/2
  - 6.2 삼각형의 내각과 외각: 내각의 합 180°, 한 외각 = 이웃하지 않는 두 내각의 합
  - 6.3 다각형의 내각의 크기의 합: 180°×(n−2), 정n각형의 한 내각
  - 6.4 다각형의 외각의 크기의 합: 360°, 정n각형의 한 외각 360°/n
  - 6.5 부채꼴의 중심각과 호: 한 원에서 호의 길이·부채꼴 넓이는 중심각에 정비례, 현은 정비례하지 않음, 같은 중심각 ↔ 같은 호·현
  - 6.6 부채꼴의 호의 길이와 넓이: l = 2πr×x/360, S = πr²×x/360 = rl/2, 색칠한 부분의 둘레·넓이
- 7단원 입체도형의 성질
  - 7.1 다면체: 각기둥·각뿔·각뿔대의 면·모서리·꼭짓점, 정다면체 5종(면 모양, 한 꼭짓점에 모인 면 수, 전개도)
  - 7.2 회전체: 원기둥·원뿔·원뿔대·구, 회전축에 수직/포함하는 단면, 회전체의 전개도
  - 7.3 기둥의 겉넓이와 부피, 7.4 뿔의 겉넓이와 부피(원뿔 옆넓이 πrl), 7.5 구의 겉넓이 4πr²·부피 (4/3)πr³, 붙이거나 잘라 낸 입체

## 난이도
- 목표: 개념을 정확히 이해하고, **중급 난이도의 변형 문제**까지 푼다. 최상위(H) 문항은 넣지 않는다. level 은 'L' 또는 'M'만.
- 중1 범위 밖 지식(피타고라스 정리, 닮음비 계산 등)이 필요하면 안 된다. 모선 길이 등은 그림에 준다.
- 원주율은 π 그대로 답한다(3.14 계산 문제는 만들지 않는다).

## 그림 원칙 (가장 중요)
- 도형 문제는 **그림 위주**다. 글로만 된 도형 문제를 일부러 만들지 않는다. 그림에 수치를 적고, 본문은 "다음 그림에서 …"처럼 그림을 읽게 한다.
  (대각선 개수처럼 본래 수치 계산인 문제만 글로 둔다. 세트 전체에서 그림 없는 문항은 30% 이하.)
- 그림은 `70_tools/print/figgen.py`의 함수로 **수치에서 계산해** 그린다. 그림의 라벨 수치와 문제의 계산 수치는 같은 파이썬 변수에서 나와야 한다.
- 보기에 작은 그림(SVG 문자열)을 넣어도 된다(예: "다음 중 회전체가 아닌 것은?").
- 해설에 보조선·강조가 필요하면 `figure_sol`에 자홍(ACCENT)으로 표시한 그림을 준다.
- `figgen.py` 는 고치지 않는다(공유 파일). 필요한 그림이 없으면 세트 파일 안에 `@F.autofit` 함수를 만들어 `F.Canvas` 로 그린다(figgen.py 맨 위 설명 참고).
- 색: 면 색은 `fill='y'|'c'|'m'|'g'|'p'|'o'`를 문항마다 돌려 쓴다(잉크가 한 색에 몰리지 않게).

```python
{

  'unit': 6 또는 7,            # 교과서 단원
  'points': 3|4|8,             # 모의고사만 (연습은 생략 가능)
  'format': 'choice5'|'short'|'essay',
  'level': 'L'|'M',
  'topic': '다각형의 외각의 합',   # 짧게(12자 안팎)
  'stem_print': 'HTML 본문',     # 변수는 <i>x</i> 또는 F.X_ITAL, ∠·°·π·² 사용
  'figure': F.fig_...(...),      # SVG 문자열 또는 None
  'figure_sol': ...,             # 선택
  # choice5
  'choices': [5개], 'answer_choice': 1~5, 'distractor_why': [정답 외 4개 보기의 이유, 보기 번호 순서],
  # short / essay
  'answer_unit': 'cm²' 등 또는 None, 'answer_format': '○π 꼴' 등(단답형),
  'answer_print': '정답 HTML',
  'hint': '한 줄 힌트', 'solution': '단계별 풀이 HTML(<br>로 줄바꿈)',
  # essay
  'rubric': [{'step': '...', 'points': 2}, ...]   # 합 = points(8)
}
```

## 품질 기준
- 문장은 교과서 문체("구하시오", "것은?"), 해설은 학생에게 말하는 "~해요" 체.
- 선택형 오답 보기는 실제로 자주 하는 실수에서 만든다(distractor_why 에 그 실수를 쓴다). 보기는 크기 순으로 놓는다.
- 교과서 문제를 그대로 옮기지 않는다(수치·구성을 바꾼다). 앱이 공개 repo 에 올라간다.
- 해설은 그림의 어느 수치를 어디에 쓰는지 단계별로 쓴다. 자주 하는 실수 한 줄을 덧붙인다.
- 서술형 채점 기준은 2점 단위 4단계 정도로, 중간 결과(예: 반구 부피 18π)를 적는다.

# P03 — 수행평가 다단계 Step형

## 발견 맥락

- **출처**: `70_HighSchool/2604_고1_중간고사/수행평가-사회/` — KBS 메가시티 다큐 기반 통합사회 탐구보고서 (2026-05-09~11)
- **과제 구조**: 6차시 수업 안에서 학생이 연속적으로 작성 (Step 1~6), 총 20점
- **트리거**: Step별로 무엇을 써야 하는지, 시간 안에 막연하게 채우다 점수가 빠지는 패턴 발견

## 핵심 구조

### 입력
- 미디어 1편 (다큐·드라마·영화·기사)
- 교과 단원 성취기준 1~2개 (예: 10통사1-05-01, 05-02)
- Step별 평가양식 (보통 ① 장면·② 분석·③ 근거자료 같은 3축)
- 채점 기준 (배점·수준별 기술)

### 산출
- Step별 1 HTML 앱 (총 N개, 메가시티는 6개)
- 각 앱 = 단일 파일, 탭 5~7개

### 페이지 (탭) 구조 — 표준화 가능

| 탭 | 내용 |
|---|---|
| 0. 개요 | 이 Step에서 뭘 써야 하나, 채점 기준, 파일 안내 |
| 1~N. 각 양식 항목별 | 실제 양식 미러 + 생각 질문 + 좋은 예/나쁜 예 + 힌트 토글 |
| 마지막. 양식 전체 | 모범답안 + 암기 체크리스트 |

## 재사용 단위

### 컴포넌트 (30_COMPONENTS 참조)
- `form-mirror` — 실제 양식 박스 (주황·빨강·청록·보라 등 Step별 색)
- `tab-nav` — 가로 스크롤 탭 바
- `hint-toggle` — 정답·심화 펼치기
- `good-vs-bad` — 나쁜 예 / 좋은 예 대조
- `think-box` ⭐ NEW — 본인 생각 끌어내는 자문 박스 (Step 5/6에서 새로 등장)
- `concept-card` — 개념어 클릭 선택

### 콘텐츠 구조
- 각 Step마다 색 톤 변경 (단계 인식성)
- 모범답안은 항상 마지막 탭 (점진적 공개)
- "본인 생각 비중"이 Step 후반으로 갈수록 증가 → think-box 도입

## 일반화 가능 영역

### 모든 과목 적용 가능 (universal)
- 양식 미러 박스
- 탭 + 모범답안 마지막
- "나쁜 예 vs 좋은 예" 대조

### 일부 과목만 (과목-specific)
- 글자수 카운터 (국어·영어 논술)
- 채점 기준 표 (수행평가 일반)
- 사고 가이드 박스 (학생 본인 생각 비중 큰 단계)

### 학년별 변주
- 고등학교: 채점 기준 명시·암기 체크리스트
- 중학교: 더 가볍게, 색·아이콘 더 풍부하게
- 초등학교: 시각 위주, 텍스트 최소화

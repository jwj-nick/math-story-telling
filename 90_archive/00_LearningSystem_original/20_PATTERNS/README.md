# 20_PATTERNS — 도우미 패턴 카탈로그

> 각 패턴 = "이런 종류의 학습 과제에 이런 식으로 도우면 효과적이다"의 추상화

## 패턴이란?

자식 프로젝트(MathTelling, HighSchool)에서 **실제로 만들고 검증된** 도우미 구조 중,
- **다른 과목·다른 학년에도 재사용 가능한** 부분만 추출한 것
- **HTML 앱 구조 + 워크플로우 + 검증 사례**를 묶음
- 일반화될 만큼 성숙하면 → 50_BLUEPRINTS의 skill / agent 후보가 됨

## 패턴 파일 규약

각 `PXX_*.md`는 다음 구조:

```markdown
# PXX — 패턴명

## 발견 맥락
- 출처 프로젝트·과제·날짜
- 어떤 문제가 있어서 이 패턴이 나왔나

## 핵심 구조
- 입력: 학생 / 자료 / 과제
- 산출: 어떤 앱·문서?
- 단계·페이지 흐름

## 재사용 단위
- 사용한 컴포넌트 (30_COMPONENTS 참조)
- 사용한 콘텐츠 구조

## 일반화 가능 영역
- 과목 X에도 적용 가능한가?
- 어떤 부분은 과목-specific?

## 검증 사례
- 실제 만들어진 앱·파일 링크

## 다음 진화
- skill로 묶을 수 있는가?
- 어떤 부분이 더 자동화 가능?
```

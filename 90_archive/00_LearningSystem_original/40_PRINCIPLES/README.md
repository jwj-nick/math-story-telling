# 40_PRINCIPLES — 절대 원칙

> 모든 패턴·skill·agent는 이 원칙을 준수.
> Q06 응답에 따라 **common + 영역별 분리** 구조.

## 파일 구성

| 파일 | 영역 | 적용 대상 |
|---|---|---|
| `common.md` | 모든 앱·작업 공통 | 전체 |
| `math.md` | 수학 한정 | 오답노트·연습·MathTelling |
| `perf_eval.md` | 수행평가 한정 | 다단계 Step형, 인물 3앱형 |
| `writing.md` | 글쓰기 한정 | 논술·견해문·발표문 |
| `deploy.md` | 앱 배포 | jwj-nick.github.io 호스팅 |
| `communication.md` | NCC ↔ Nick 소통 | chatlog 원칙 등 |

## 우선순위

읽는 순서: `common.md` → 영역별 → `deploy.md` → `communication.md`.

영역별 원칙이 `common.md`와 충돌하면 **common 우선**. 영역별은 추가 제약만.

## 새 영역 추가 절차

새 과목·과제 종류가 등장 → 패턴 1~2회 검증 → 영역별 원칙 파일 신규.
검증 전에는 common.md + 기존 영역에서 가장 가까운 것을 적용.

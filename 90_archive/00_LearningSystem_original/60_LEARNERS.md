- (보강 필요) 패턴별 작업 결과에서 추론해 적기

  - 글자수 제약 논술 (120~160자) → 1차 시도에서 부족 → 가이드 앱 필요
  - 본인 개혁안(Q4) → 브레인스토밍 아이디어 5개 제시 후 골라서 자기 언어로 → 작동
- 메가시티 수행평가:
  - Step 5 "본인 해결안" → think-box 가이드 후 진행 가능
  - Step 6 "성찰" → "전·후" 비교 구조 학습 필요

### 학습 스타일 가설 (확정 X)
- 명확한 양식·체크리스트가 있으면 안정적으로 진행
- 본인 생각이 비중 클 때 막연해함 → 사고 가이드 박스가 효과적
- 시각적 대비 (good vs bad) 잘 받아들임

### 흥미 트리거
- "점수 외 의미" 강조 (한국사 정도전 심화 앱 — 평생 4질문)
- 인물·시대 이야기 (storytelling)
- 본인이 직접 답을 만들어가는 단계 (시뮬레이터)

### 디지털 자율도 — 현재 L0 (Q04 응답)
- L0 = 부모·NCC가 만든 앱을 학습용으로 소비
- 학교 아이패드 사용
- 부모 앱 사용 (현재 high1/ 배포 중)
- L1 이상 진입은 Nick이 시기·조건 control. 당분간 L0 유지.

### 다음 과제 (관찰 대상)

## 질문

이 메타 시스템 디렉토리를 어디에 둘 것인가? 이름은?

## NCC 제안 (현재 적용)

- 위치: `C:/Kids/00_LearningSystem/`
- 이유:
  - `30_MiddleSchool`, `70_HighSchool` 처럼 `NN_` prefix 따름
  - 00 = 모든 자식 프로젝트 위에서 메타 역할
  - "LearningSystem"은 영문 — 다른 자식들도 영문 prefix 폴더 (30_MS, 70_HS) 사용

## 대안

| 후보 | 이유 |
|---|---|
| `C:/Kids/_System/` | 언더스코어 = "특수 / 메타" 시각적 신호 |
| `C:/Kids/00_NCC/` | NCC (Nick's Claude Co-worker) 식별 |
| `C:/Kids/00_META/` | 더 일반적 메타 레이어 |
| `C:/Kids/01_System/` | NCC가 00 이미 다른 의미로 쓸 거면 01로 |

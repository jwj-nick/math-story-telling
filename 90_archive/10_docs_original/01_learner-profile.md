# 학습자 프로필

> 살아있는 문서. 프로젝트 진행하며 계속 업데이트.

## 기본 정보

- **학년**: 중학교 1학년
- **언어**: 한국어 (모국어), 영어 양호
- **가용 시간**: 주 4~5일 × 1시간

## 강점

- **국어/영어 강세** — 언어적 사고가 발달
- **글쓰기 강점** — 자기 표현이 가능하고 즐김
- **감성적, 공감 능력 높음** — 인물 서사에 몰입 가능

## 수학 현황

- **성적**: 중하위
- **자기 인식**: "수학도 잘하고 싶은데 너무 어려움"
- **관찰된 패턴**:
  - 개념을 명확히 알면 어렵지 않은 문제도 어려워함
  - 문제 풀 때 속도가 안 남
  - 오답률 높음
- **추정 원인** (가설, 검증 필요):
  1. "안다"가 사실은 "들어봤다" 수준일 가능성
  2. 절차적 유창성(procedural fluency) 부족 — 충분히 안 풀어봐서
  3. 작업 기억(working memory)에서 개념과 절차를 동시 운용하는 부담

## 정서

- 수학에 대한 적극적 거부감은 없음 (중요!)
- "잘하고 싶다"는 의지가 있음 (매우 중요!)
- 부담을 주면 위 두 가지가 무너질 수 있음 → **스트레스 없는 진행이 핵심 KPI**

## 학습 스타일 (관찰·가설)

- **언어 우위형, 시각·서사 친화형 추정** — 이야기와 글로 들어가는 게 효과적일 것
- 숫자·기호 직접 진입은 진입 장벽이 큼
- "왜?"에 답이 있어야 흡수율이 높을 가능성

## 동기 (motivation) 단서

- 글쓰기 강점 → 자기가 잘하는 통로로 들어가면 자존감 보호
- "수학을 잘하고 싶다"는 내적 동기 존재 → 이를 끄지 않는 것이 최우선

## 진단·평가 계획 (예정)

- 최근 학교 시험지 분석 (어떤 유형에서 막히는지)
- 1차 인터뷰: 정서·흥미·자기 인식 파악
- 6개월 단위 정성 회고 (성적 X, 정서·이해도·자기 효능감 O)

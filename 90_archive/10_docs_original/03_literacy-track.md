# 수학 언어 사용 설명서 (Mathematical Literacy Track)

> 단원별 학습("수학의 사람들")과 평행하게 진행되는 별도 트랙.
> 수학의 **표기·기호·관습 자체에 대한 메타 학습**.
> 발견 계기: Round 6, 아빠의 관찰 — 딸이 `y=a/x, a=-2`에서 `y=-2/x`로 변환을 못함.

---

## 왜 이 트랙이 필요한가

### 관찰된 증상

> "y=a/x 이다. a=-2 이다. 그러면 그 그래프는 몇 사분면들에 존재하냐... 이런 문제가 있는 걸 몰라서 내가 옆에서 도와주려는데... a=-2 인데 그러면 원래 수식이 어떻게 되니? 라고 물어보면 y는 마이너스 2 나누기 x 이다 라고 읽어내는 걸 잘 못함."

### 진단

이건 단순한 단원별 문제가 아닙니다. **수학의 언어 시스템 자체에 대한 메타 인식**의 누락입니다. 구체적으로:

1. **"문자(symbol)는 자리(slot)다"** 는 인식 부재
   - `a`라는 글자가 "자리이름표"이고, "값을 넣을 수 있는 빈칸"이라는 인식
   - 이게 잡히면 "a=-2이면 y=a/x의 a 자리에 -2를 끼워넣는다"가 자연스러움

2. **"같은 식을 두 가지 방식으로 쓸 수 있다"** 는 인식 부재
   - `y = a/x` (일반형, 형식)
   - `y = -2/x` (구체형, 값 대입 후)
   - 둘이 같은 식의 두 모습이라는 것

3. **상수와 변수의 역할 구분 부재**
   - `a`는 "이 문제 안에서는 고정된 어떤 값"
   - `x, y`는 "여러 값을 넣어볼 수 있는 자리"
   - 둘 다 문자지만 역할이 다름

4. **"수학은 압축 표현이 가능하다"** 는 메타 인식 부재
   - 왜 굳이 a, x, y 같은 글자를 쓰는가?
   - 글자를 쓰면 무한히 많은 경우를 한 줄로 표현할 수 있다는 마법

### 이게 얼마나 중요한가

이 메타 인식이 잡히지 않으면:
- 단원 3 (문자와 식, 일차방정식): 절반 이해
- 단원 4 (좌표평면, 정비례·반비례): 절반 이해
- **중2 일차함수 → 중3 이차함수 → 고1 함수 → 고2 미적분**: 줄줄이 무너짐

반대로 이 메타 인식이 잡히면 위 모든 것이 "표현 방식이 약간씩 다른 같은 게임"으로 보입니다.

---

## 트랙의 컨셉: "수학자들이 만든 비밀 언어 안내서"

### 한 줄 정의

> 수학자들이 자기 생각을 압축해서 적기 위해 발명한 **약속과 기호의 사용 설명서**. 수학을 외계어가 아니라 인간이 만든 언어로 인식하게 하기.

### 왜 이 컨셉이 딸에게 맞는가

딸은 **언어 우위형**입니다. 국어·영어를 잘한다는 건:
- 단어가 의미를 담는 그릇임을 자연스럽게 안다
- 같은 의미를 여러 표현으로 쓸 수 있음을 안다
- 문법(약속)이 있다는 걸 받아들인다

수학도 똑같이 "언어"라고 프레이밍하면, 딸의 강점이 그대로 전이됩니다.

> 영어에서 "I am a student" → 한국어 "나는 학생이다"로 바꾸듯,
> 수학에서 "y는 a를 x로 나눈 값" → "y = a/x"로 바꾸는 것.
> 둘 다 같은 의미, 다른 표현법.

---

## 핵심 모듈 (잠정 7개)

각 모듈은 단원과 별도로, 5~15분 분량의 짧은 글 + 인터랙티브 예제로 구성.

### 모듈 L1: 글자가 숫자 자리에 앉는다 — 문자의 정체
- **핵심**: 문자는 "값을 넣을 수 있는 자리(슬롯)"다
- **비유**: 식당의 빈 의자. 누가 앉느냐에 따라 의미가 달라짐.
- **연습**:
  - `a + 3`에서 a 자리에 1, 2, 5, -3을 넣어보기
  - "a를 다른 글자로 바꿔도 의미는 같다" 확인 (a→b→★→😀까지 가능)
- **언어 비유**: 영어 대명사 "he/she" — 누구를 가리키는지 문맥에 따라 달라지지만 자리는 같음

### 모듈 L2: 같은 말, 두 가지 쓰는 법 — 일반형과 구체형
- **핵심**: 수학에는 "일반형"과 "구체형" 두 가지 표현이 있다
- **예시**:
  - 일반형: `y = a/x` ← 모든 반비례 그래프 설명
  - 구체형: `y = -2/x`, `y = 5/x`, `y = 1/x` ← 각각 하나의 그래프
- **딸의 사례 정확 처치**: `a = -2`라는 정보는 "이번엔 a 자리에 -2를 넣어줘"라는 지시
- **연습**:
  - `y = ax`에서 a를 1, 2, -3, 0.5 등으로 바꿔가며 식 다시 쓰기
  - 반대로 `y = 4x`를 보고 일반형 `y = ax`에서 a는 무엇? 에 답하기

### 모듈 L3: 글자 두 종류 — 상수와 변수
- **핵심**: 같은 식 안의 글자도 역할이 다르다
- **예시**: `y = ax + b` 에서
  - `a`, `b`: **상수** — "이 문제 안에선 고정"
  - `x`, `y`: **변수** — "여러 값이 들어가볼 수 있음"
- **비유**:
  - 상수 = 식당 메뉴의 가격 (오늘 하루 안에선 고정)
  - 변수 = 손님이 주문하는 양 (계속 바뀜)
- **관습**: 보통 a, b, c, k는 상수 / x, y, z, t는 변수
  - 이건 약속일 뿐, 절대 규칙은 아님

### 모듈 L4: 왜 수학자들은 글자를 쓰게 되었나 — 비에트와 데카르트의 발명
- **핵심**: 글자 사용은 발명품이다 (16~17세기)
- **이야기**:
  - 알콰리즈미(9세기)는 글자 없이 말로 방정식을 풀었다
  - 비에트(François Viète, 1540~1603)가 미지수와 상수에 글자를 처음 체계적으로 사용
  - 데카르트(René Descartes, 1596~1650)가 우리가 지금 쓰는 관습을 거의 확정
    - 알파벳 끝(x, y, z) → 변수
    - 알파벳 앞(a, b, c) → 상수
- **결론**: "이 표기법은 누군가 만든 약속이다. 자연 법칙이 아니라."

### 모듈 L5: 곱셈 기호의 실종 — `2x`는 왜 `2 × x`가 아닌가
- **핵심**: 수학에는 "생략 약속"이 있다
- **약속들**:
  - `ax` = `a × x` (곱셈 기호 생략)
  - `2(x+1)` = `2 × (x+1)`
  - `xy` ≠ x곱하기y라는 두 문자, 하나의 곱셈
  - 단, `2 × 3 = 6`은 생략 안 함 (왜? `23`이 되어버림)
- **왜 생략하나**: 적게 쓰고 빨리 읽기 위해. 시간이 흐르며 굳은 관습.

### 모듈 L6: 등호의 두 얼굴 — 같다 vs 항상 같다
- **핵심**: `=`는 두 가지 의미로 쓰인다
- **두 얼굴**:
  - 방정식: `2x + 3 = 7` → "x가 어떤 특정 값일 때만 같다" (해가 있다)
  - 항등식·정의: `(x+1)² = x² + 2x + 1` → "x가 무엇이든 항상 같다"
- **딸의 직관 활용**: 한국어 "이다"의 두 가지 사용처
  - "오늘은 일요일이다" (특정 날만 참)
  - "1더하기 1은 2이다" (항상 참)

### 모듈 L7: 식 읽기 5단계 절차 — 오답률을 줄이는 결정적 무기
- **핵심**: 식을 보면 무작정 풀지 말고, 먼저 "읽는다"
- **5단계**:
  1. **무슨 변수가 있는가?** (x? y? a? b?)
  2. **어떤 게 상수, 어떤 게 변수인가?**
  3. **연산은 무엇인가?** (덧셈? 곱셈? 나눗셈?)
  4. **이 식을 한국어로 옮기면?** ("y는 a를 x로 나눈 값이다")
  5. **이 문제에서 묻는 것은?**
- **딸의 사례에 정확한 처방**:
  - 시작: `y = a/x`, `a = -2`
  - 1단계: 변수 a, x, y 등장
  - 2단계: a는 -2로 고정 → 상수, x·y는 변수
  - 3단계: 나눗셈
  - 4단계: "y는 -2를 x로 나눈 값이다" 또는 "y = -2/x"
  - 5단계: 이 그래프가 어느 사분면에 있는지

## 이 트랙의 진행 방식

### 빈도와 분량
- 본 학습(인물 단원) 사이사이에 끼워넣는 형태
- 한 모듈당 5~15분, 한 주에 1개 정도 권장
- 전체 7개 모듈을 약 2~3개월에 걸쳐

### 형태
- **짧은 글 + 작은 인터랙션** 조합 권장
- 모듈 L1, L2, L3는 **반드시 인터랙티브 도구**가 있어야 효과
  - 예: 슬라이더로 a를 움직이면 식이 자동으로 다시 써지는 도구
  - HTML+JS로 간단히 구현 가능 (Claude Code로 만들기 좋은 첫 결과물)

### 단원과의 연결
- 단원 1 (소인수분해) 끝나고 → L1 (문자의 정체) 도입
- 단원 2 (정수와 유리수) 진행 중 → L5 (곱셈 기호 생략) 빠르게
- 단원 3 (문자와 식) 진입 직전 → L2, L3 (일반형/구체형, 상수/변수) 집중
- 단원 4 (좌표평면) 진입 직전 → L7 (식 읽기 5단계) 강조

이 매핑은 R1과 결합되어 작동.

## 첫 시범 모듈 후보: L2

이유:
- 딸의 실제 사례(`y=a/x, a=-2`)를 정확히 정조준
- 인터랙티브 슬라이더 하나로 강력한 효과
- 우리 프로젝트의 "AI로 만드는 인터랙티브 학습 도구" 첫 결과물로 적합
- 만들기도 쉬움 (단원 1 시범 제작과 병렬 가능)

L2 시범 제작 시 체크리스트:
- [ ] `y = a/x` 슬라이더로 a를 -3 ~ 3까지 변화
- [ ] 식이 자동으로 `y = -2/x` 등으로 다시 써짐
- [ ] 그래프가 함께 그려짐 (사분면 표시)
- [ ] 딸이 직접 a 값을 바꾸며 식과 그래프의 변화 관찰
- [ ] 끝에 "이번 a로 식을 다시 써보세요" 짧은 글쓰기 칸

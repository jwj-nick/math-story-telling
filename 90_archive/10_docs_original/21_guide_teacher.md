# MathTelling — 수학선생님 관점 가이드

> 대상: 기술을 몰라도 되는 수학선생님 (또는 수학 콘텐츠 검토자)
> "이 시스템으로 어떤 자료가 만들어지고, 어떻게 검토하면 되는가?"

---

## 이 시스템이 만드는 것

중1 딸을 위해 각 단원마다 다음 자료들을 자동으로 만들어냅니다:

### 단원마다 만들어지는 자료

**[이야기 자료]**
- 해당 단원과 연결된 수학자 이야기 (중1 수준 텍스트)
- 예: 소인수분해 → 에라토스테네스 이야기

**[인터랙티브 학습 앱 — 웹 브라우저에서 열기]**
- `index.html`: 단원 소개 페이지
- `story.html`: 인물 이야기 인터랙티브 버전
- `concepts.html`: 핵심 개념 설명 (클릭하면 단계별 학습)

**[문제 연습 앱 — 웹 브라우저에서 열기]**
- `basic_app.html`: 기본 문제 8~10개 (단원 전 개념 고루 포함)
- `type_NN_app.html`: 유형별 연습 (각 유형당 L/M/H 3단계 × 3문제)
- `deep_유형명_app.html`: 특정 유형이 어려울 때 쓰는 심화 자료

---

## 각 자료는 이렇게 만들어집니다

**개념 검수** → 중1 수학 교육과정 기준으로 정확성 확인 후 사용  
**스토리 작성** → 역사적 사실 기반 초안 생성 후 검토  
**문제 생성** → AI가 만들고, AI가 직접 다시 풀어서 정답 확인  
**앱 제작** → 디자인 원칙에 맞게 자동 제작 후 검토

---

## 수학 선생님이 확인하면 좋은 것들

### 1. 개념 정의가 교과서와 일치하는지

`40_BaseDocs/` 폴더의 MD 파일들에 개념이 정리되어 있습니다.

확인 포인트:
- 정의가 교과서 표현과 일치하는가?
- 예시가 올바른가?
- 중1 범위를 벗어난 내용이 없는가?

### 2. 문제 정답이 맞는지

`50_units/NN/problems/basic_app.html`을 브라우저로 열면:
- 문제 목록 확인 가능
- "정답 보기" 클릭 시 정답과 풀이 확인

AI가 검증했지만, 수학 전문가 확인이 가장 확실합니다.

### 3. 문제 난이도가 딸에게 맞는지

AI는 중1 교육과정 기준으로 난이도를 설정하지만,
"이 딸 학생에게 이게 어렵지 않을까?" 판단은 Nick과 선생님이 가장 잘 할 수 있습니다.

### 4. 유형 목록이 시험에 실제로 나오는 것인지

`50_units/NN/problems/types.md`에 시험 출제 유형 목록이 있습니다.
실제 시험 경향과 비교해서 추가/삭제할 유형을 알려주면 좋습니다.

---

## 수정이 필요할 때

수정 방법은 두 가지입니다:

**방법 1: Nick에게 전달**
"Q3 정답이 틀렸어요" → Nick이 AI에게 수정 요청

**방법 2: 직접 수정**
텍스트 파일(.md)은 메모장으로 직접 수정 가능합니다.
HTML 앱은 브라우저에서 확인만 하고, 수정은 Nick이 처리합니다.

---

## 문제 품질 체크리스트 (선생님용)

각 단원의 기본 문제에 대해:

- [ ] 정의 확인 문제가 포함되어 있는가?
- [ ] 계산 과정 문제가 포함되어 있는가?
- [ ] 정답이 모두 맞는가?
- [ ] 너무 어렵거나 너무 쉬운 문제가 없는가?
- [ ] 중1 과정에서 나오지 않는 개념이 사용되지 않는가?

각 유형별 연습 문제에 대해:
- [ ] 유형 명칭이 실제 시험 유형과 일치하는가?
- [ ] L(기본)-M(중간)-H(응용) 구분이 적절한가?

## 딸의 학습 진행 확인

딸이 공부한 뒤 `50_units/NN/feedback/` 폴더에 글을 남깁니다.
(형식 없음 — 자유롭게)

이 글은 **절대 수정하지 않습니다.** 있는 그대로 보존됩니다.

선생님이 이 글을 보면 딸이 어떤 부분을 어렵게 느꼈는지, 어떤 게 재미있었는지 파악할 수 있습니다.

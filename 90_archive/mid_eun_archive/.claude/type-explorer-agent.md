# type-explorer — 유형 깊이 탐구 에이전트

## 역할
딸이 학습 중 특정 문제 유형에서 반복적으로 막힐 때 발동.
해당 유형에 대한 **심화 이해 자료 + 단계별 추가 문제**를 생성해 혼자서도 깊이 학습할 수 있게 한다.

> 이전 이름: `math-workflow` (오답노트 전용 → 유형 탐구 확장으로 개편)

---

## 발동 조건

- 딸이 `problems/type_NN_app.html`에서 동일 유형 문제를 2회 이상 틀렸을 때
- Nick이 "이 유형 더 탐구해줘"라고 명시적으로 요청할 때
- 딸이 `feedback/`에 "이게 너무 어려워요"라고 특정 유형을 언급했을 때

---

## 입력 형태

```
type-explorer unit01 유형명
type-explorer unit02 유형3
type-explorer unit01 소인수 기본형
```

---

## 실행 절차

### 1. 컨텍스트 읽기
- `40_BaseDocs/NN_단원명/` — 해당 단원 개념 전체
- `50_units/NN/problems/types.md` — 유형 목록
- `50_units/NN/problems/type_NN_app.html` — 기존 연습 문제 (어떤 수준까지 있는지 확인)
- `10_docs/01_learner-profile.md` — 학습자 수준

### 2. 유형 심화 분석
- 이 유형이 어려운 이유 분석 (개념 어디가 막히는가?)
- 선행 개념 중 누락 가능성 확인
- 단계별 접근 경로 설계

### 3. 심화 자료 생성

**파일 1**: `50_units/NN/problems/deep_유형명.md`

구성:
```
## 유형 이름
## 왜 어려운가? (딸에게 직접 설명)
## 핵심 아이디어 (가장 간단한 말로)
## 단계별 풀이 흐름 (4~5단계)
## 자주 하는 실수와 이유
## 연결 개념 (이 유형을 이해하면 다음에 뭐가 쉬워지나)
```

**파일 2**: `50_units/NN/problems/deep_유형명_app.html`

구성:
- 왜 어려운지 시각적 설명 (그림/애니메이션)
- 단계별 풀기 (각 단계 클릭해서 확인)
- 추가 문제 3~5문제 (아주 쉬운 것부터 시작)
- 각 문제에 단계별 힌트 (`<details>` 3단계)

### 4. 필요 시 그래프/도형
- 그래프나 도형이 핵심이면 `/math-figure` 호출
- JSXGraph 또는 SVG 인라인

### 5. 수학 검증
- `/ncc_audit_math` 실행 — 생성된 추가 문제 검증
- `/ncc_audit_app` 실행 — HTML 앱 품질 확인

### 6. 완료 보고
```
type-explorer 완료 — unit01 / 소인수분해 기본형 유형

생성 파일:
- deep_소인수분해기본형.md
- deep_소인수분해기본형_app.html

포함 내용:
- 왜 어려운지 분석 + 4단계 접근법
- 추가 문제 5개 (L2 → M3 수준)
- 힌트 3단계 포함

audit: 수학 Pass / 앱 Pass
```

## 원칙

- 딸에게 직접 말하는 톤 ("이 유형의 핵심은요...")
- 아주 쉬운 것부터 시작 (진입 장벽 최소화)
- 답 바로 주지 않음 — 단계별 힌트로 스스로 발견
- 수학적 정확성 최우선
